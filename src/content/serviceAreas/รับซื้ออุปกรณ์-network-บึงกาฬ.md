## แนวทางคัดกรองSwitch Router Firewall และ Networkจากบึงกาฬก่อนเสนอราคา

สินค้า Network มี License และ Cloud Account ที่อาจโอนไม่ได้ ร้านไม่รับประกันข้ามระบบล็อกของเจ้าของเดิม ผู้ขายจากบึงกาฬสามารถส่งข้อมูลมาเพื่อขอพิจารณาออนไลน์ได้ก่อน ไม่ควรนำของไปส่งหรือจ่ายค่าขนส่งจนกว่าจะยืนยันประเภทและวิธีตรวจรับตามจริง การรับพิจารณาไม่ใช่คำยืนยันว่าจะซื้อสินค้าทุกรุ่นหรือชนะประมูลใด

## สามจุดตรวจที่ช่วยแยกสภาพและความครบชุด

### 1. Cloud Managed Hardware

ถ้าบัญชีเดิมยังผูกอยู่ให้เจ้าของจัดการก่อน ไม่รับประกันข้าม Lock ในการขอราคาเบื้องต้นควรแสดงภาพรุ่นและสถานะที่ตรวจได้จริง หากมีอาการเสียหรือขาดชิ้นส่วนให้ระบุแยกจากเครื่องพร้อมใช้ ข้อมูลที่ไม่แน่ใจไม่ควรกรอกเป็นสเปกยืนยัน เพราะราคาสุดท้ายอาจเปลี่ยนหลังตรวจสินค้า

### 2. Enterprise NAS

อย่าปน NAS Storage เข้ากับ Switch และระบุดิสก์ที่รวมขาย ในการขอราคาเบื้องต้นควรแสดงภาพรุ่นและสถานะที่ตรวจได้จริง หากมีอาการเสียหรือขาดชิ้นส่วนให้ระบุแยกจากเครื่องพร้อมใช้ ข้อมูลที่ไม่แน่ใจไม่ควรกรอกเป็นสเปกยืนยัน เพราะราคาสุดท้ายอาจเปลี่ยนหลังตรวจสินค้า

### 3. Serial/Asset Tag

อย่าส่งข้อมูลลูกค้าหรือความลับของระบบองค์กรในรูปภาพ ในการขอราคาเบื้องต้นควรแสดงภาพรุ่นและสถานะที่ตรวจได้จริง หากมีอาการเสียหรือขาดชิ้นส่วนให้ระบุแยกจากเครื่องพร้อมใช้ ข้อมูลที่ไม่แน่ใจไม่ควรกรอกเป็นสเปกยืนยัน เพราะราคาสุดท้ายอาจเปลี่ยนหลังตรวจสินค้า

## เตรียมข้อมูลการส่งมอบและการจัดการสิทธิ์

- ระบุผู้มีสิทธิ์จำหน่ายสินค้าจริง โดยเฉพาะทรัพย์สินบริษัทหรืออุปกรณ์ที่อาจผูกบัญชี
- ถ่ายรูปสินค้าทั้งชุดและรอยเสียหายโดยไม่เปิดเผยรหัสผ่าน OTP หรือข้อมูลลูกค้า
- แยกสินค้าเปิดติด เครื่องเสีย ไม่ทดสอบ และชุดไม่ครบก่อนเสนอราคารวม
- หากเป็นเครื่องไฟฟ้าแรงสูง แบตบวม หรืออุปกรณ์มีรอยไหม้ ให้หยุดทดสอบและสอบถามแนวทางปลอดภัยก่อนเคลื่อนย้าย
- อุปกรณ์ใหญ่หรือของเปราะบางต้องคุยค่าแพ็ก น้ำหนัก ข้อจำกัดผู้ขนส่ง และผู้รับผิดชอบค่าใช้จ่ายก่อนตกลง

## คำถามที่พบก่อนส่งรูป

### ขอราคาเบื้องต้นจากบึงกาฬต้องส่งข้อมูลใด?

ส่งภาพป้ายรุ่น สภาพจริง อุปกรณ์ที่รวมและอาการที่ทดสอบได้ผ่าน LINE @webuy ก่อน โดยร้านรับพิจารณาตามประเภทและตลาดจริง

### ถ้ายังไม่ได้ทดสอบครบจะขอประเมินได้ไหม?

ได้สำหรับขอข้อมูลเบื้องต้น แต่ต้องแจ้งว่าไม่ได้ทดสอบครบ ไม่ถือว่าเป็นเครื่องสมบูรณ์

### มีทีมรับสินค้าประจำจังหวัดบึงกาฬหรือไม่?

ไม่มีการยืนยันสาขาหรือทีมรับสินค้าประจำจังหวัดนี้ หน้าร้านจริงอยู่ที่อุบลราชธานีและวิธีส่งมอบต้องตกลงรายกรณี

อ่านรายละเอียดรุ่นและเกณฑ์ตรวจได้ที่ [หน้าบริการSwitch Router Firewall และ Network](/บริการ/รับซื้ออุปกรณ์-network) และ [พื้นที่ให้บริการบึงกาฬ](/พื้นที่ให้บริการ/บึงกาฬ)

*เนื้อหานี้เป็นคำแนะนำเตรียมรายการ ไม่ใช่หลักฐานว่า AMPHON เคยรับซื้อสินค้าในจังหวัดบึงกาฬ หรือได้สัญญาประมูลจากหน่วยงานใด*

## Access Point ที่ผูก Controller เดิมกับการย้ายเจ้าของ

Access Point ที่ผูก Controller เดิมอาจเปิดติดได้แต่ยังไม่พร้อมใช้ในระบบใหม่ การขายต่อจึงควรระบุสถานะ Unclaim/Adoption ที่ผู้ดูแลตรวจได้จริง ไม่ถือว่า Factory Reset จะทำให้สิทธิ์การจัดการ Cloud ย้ายไปผู้ซื้อได้เสมอ

### รายละเอียดที่ต้องตรวจและส่งให้ร้านก่อนเสนอราคา

- แจ้งรหัสรุ่น Access Point และวิธีจ่ายไฟ PoE หรือ Adapter ตามสติกเกอร์/คู่มือ
- แยกอุปกรณ์ Cloud Managed จากรุ่น Standalone แล้วแจ้งว่าปลดบัญชีเดิมแล้วหรือยังไม่ทราบ
- ให้ฝ่าย IT ของเจ้าของเครื่องสำรอง Config ที่จำเป็นและจัดการข้อมูลเครือข่ายภายในก่อนส่งมอบ ไม่ส่ง VPN Key

ตัวอย่างนี้เป็นเกณฑ์ช่วยจัดข้อมูลและตรวจความเหมาะสมเท่านั้น ไม่ใช่ประวัติรับซื้อสินค้าในจังหวัดที่กล่าวถึง และไม่ได้หมายความว่ามีทีมรับของประจำพื้นที่ การตัดสินใจซื้อและค่าเดินทางขึ้นกับสินค้าและข้อตกลงจริง
