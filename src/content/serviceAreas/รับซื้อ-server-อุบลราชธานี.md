## รับซื้อ Server และตู้ Rack อุบลราชธานี นัดรับหรือประสานขนส่งตามข้อตกลง

เมื่อองค์กรในอุบลราชธานีอัปเกรดระบบหรือปลดระวางห้องไอที อำพล เทรดดิ้งรับประเมิน **Server และตู้ Rack** โดยดูประเภทเครื่อง (Rack/Tower) รุ่น สเปก CPU RAM สตอเรจ แหล่งจ่ายไฟ แผ่นยึดราง และสภาพการเปิดเครื่อง

ล็อตองค์กรในเมืองอุบลมักเริ่มจากส่งรายการและรูปทาง Line แล้วค่อยนัดตรวจหน้างาน ส่วนชิ้นเล็กหรือตัวอย่างเครื่องสามารถนำมาตรวจที่หน้าร้านได้

> ส่งรายการและรูปได้ที่ Line [@webuy](https://line.me/ti/p/~@webuy) หรือโทร [064-257-9353](tel:+66642579353)
> ประเภทที่รับพิจารณา: [รับซื้อ Server](/บริการ/รับซื้อ-server)

### สเปกและรูปที่ควรส่งตอนประเมิน Server

- รุ่นเครื่องและแบรนด์ (เช่น Dell PowerEdge, HP ProLiant) จากป้ายหน้าหรือสติกเกอร์
- จำนวน CPU socket, RAM, Drive tray และว่า Drive ยังครบหรือถอดออกแล้ว
- รูปตัวเครื่อง ด้านหลังพอร์ต และอาการถ้าเปิดไม่ติด/POST ไม่ผ่าน
- หากมีตู้ Rack: ขนาด U แบรนด์ และสภาพประตู/ล้อ
- สถานะข้อมูล: จะ Secure Erase หรือถอด Drive ก่อนส่งมอบ

ราคาจากรายการ/รูปเป็นราคาเบื้องต้น ราคาสุดท้ายยืนยันหลังตรวจฮาร์ดแวร์ และชำระเงินหลังผู้ขายยอมรับราคาสุดท้าย

### ตรวจที่หน้าร้านอุบลหรือนัดถอดจาก Rack

หน้าร้านอยู่ที่ **740/8 ถนนชยางกูร อำเภอเมืองอุบลราชธานี** เหมาะกับการตรวจตัวอย่างเครื่องหรือล็อตที่ไม่ใหญ่เกินไป

Server ที่ยังอยู่ในตู้ Rack น้ำหนักมาก หรือมีหลายเครื่อง ทีมงานจะนัดตรวจรับและหารือวิธีถอด/ขนตามข้อตกลง ไม่รับประกันเข้ารับทุกพื้นที่ทุกวัน
