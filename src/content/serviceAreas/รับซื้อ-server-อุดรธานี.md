## รับซื้อ Server อุดรธานี | ประเมินล็อตหลายเครื่องแยกรุ่น

การเสนอขาย Server หลายเครื่องจากสำนักงานในอุดรธานีอาจมีรุ่นและความครบของอุปกรณ์ไม่เท่ากัน การส่งแค่รูปกองเครื่องทำให้ไม่สามารถแยกเครื่องที่ยังเปิดติดกับเครื่องที่ถอดอะไหล่ได้ แนะนำทำตารางสั้น ๆ ต่อเครื่องก่อนขอราคา

## ตัวอย่างการจัด Asset List ที่ช่วยไม่ให้ประเมินเหมาทั้งล็อตผิด

ให้ใช้รหัสภายในเช่น A01–A05 แทนเลขทะเบียนทรัพย์สินที่เป็นความลับ ระบุรุ่นเครื่อง จำนวน CPU, RAM, PSU, HDD/SSD และสถานะทดสอบแยกบรรทัด หากมีเครื่องเสียหรือใช้เป็นอะไหล่ให้เขียนแยกหมวด ไม่กล่าวว่าทุกเครื่องใช้งานได้เพียงเพราะอยู่ในตู้เดียวกัน

### รายการข้อมูลที่ช่วยให้ประเมินตรงกับเครื่องจริง

| ข้อมูลที่ควรแจ้ง | เหตุผลที่ต้องตรวจ |
| --- | --- |
| รหัสรายการและจำนวน | A01 / A02 ใช้แยกรุ่นและรูปแต่ละเครื่องโดยไม่เผยแพร่ข้อมูลภายในองค์กร |
| CPU และ ECC/RDIMM | นับจำนวนชิปและความจุ RAM จริง ไม่ใช้คำว่า Xeon อย่างเดียว |
| PSU, NIC, Controller | ระบุพอร์ตเครือข่ายและการ์ดแยกที่ติดตั้ง รวมจำนวน PSU ที่ทำงานได้ |
| Drive และสถานะเครื่อง | แยกเครื่องที่มีดิสก์ เครื่องถอดดิสก์ และเครื่องที่ยังไม่ผ่านการทดสอบ |

## ความเป็นเจ้าของและความปลอดภัยก่อนขาย

ควรให้ผู้มีอำนาจอนุมัติการตัดจำหน่ายอุปกรณ์ก่อนเสนอขาย และตัดสินใจเรื่องสื่อบันทึกข้อมูลร่วมกับฝ่าย IT ลูกค้าไม่จำเป็นต้องส่งรหัส iDRAC/iLO, Credential หรือไฟล์ธุรกิจมาให้ร้านเพื่อขอราคา

## คำถามจากผู้ที่ต้องการขายServerในอุดรธานี

### เครื่อง 10 ตัวต่างรุ่นส่งครั้งเดียวได้หรือไม่

ได้ ส่ง Asset List หนึ่งชุดพร้อมภาพป้ายรุ่นที่สัมพันธ์กับรหัสแต่ละเครื่อง ระบบประเมินจะได้ไม่ปะปนเครื่องที่สเปกต่างกัน

### ไม่มีอุปกรณ์ราง Rack จะรับพิจารณาไหม

รับพิจารณาเป็นรายกรณี กรุณาแจ้งรางที่ขาด รวมถึง Tray และ PSU ที่ไม่ครบเพื่อป้องกันความเข้าใจผิด
