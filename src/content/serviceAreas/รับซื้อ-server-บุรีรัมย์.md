## รับซื้อ Server บุรีรัมย์ | เช็กแร็ค ราง และสเปกก่อนขาย

หากคุณกำลังปลดระวาง Server ที่ติดตั้งอยู่ในตู้ Rack หรือมี Server หลายชิ้นในจังหวัดบุรีรัมย์ ยังไม่จำเป็นต้องถอดเครื่องหรือขนส่งมาก่อน ให้เริ่มด้วยภาพหน้าตู้ ภาพป้ายรุ่น และภาพด้านหลังเพื่อทราบจำนวนและความพร้อมของอุปกรณ์ ข้อเสนอเบื้องต้นขึ้นอยู่กับสเปก สภาพ และสิ่งที่ส่งมอบจริง ไม่ใช่เพียงจำนวน U ของตู้

## ตู้ Rack ยังมีเครื่องติดตั้งอยู่ ควรแยกรายการอย่างไร

แยกจำนวน Server, ตู้ Rack, PDU, รางยึดและสายไฟเป็นรายการคนละส่วน แสดงว่ารางสไลด์อยู่ครบหรือหาย และบันทึกว่ามีชุดคีย์หรือฝาหน้าตู้หรือไม่ หากยังไม่สามารถถอดเครื่องได้ ให้ถ่ายระยะที่ยกขนได้และแจ้งข้อจำกัดทางเข้าอาคารเพื่อประเมินความเป็นไปได้ของการส่งมอบ ไม่ควรรับปากว่ามีรถหรือช่างไปรับทันทีโดยไม่ตกลงกันก่อน

### รายการข้อมูลที่ช่วยให้ประเมินตรงกับเครื่องจริง

| ข้อมูลที่ควรแจ้ง | เหตุผลที่ต้องตรวจ |
| --- | --- |
| รุ่นเครื่องและ Service Tag | ถ่ายรุ่นเต็มจากป้ายเครื่องให้เห็นชัด ใช้แยก Tower/Rack และรุ่นย่อย |
| ราง Rack / ตู้ / PDU | นับแยกว่าครบชุดหรือเป็นของคนละรุ่น ไม่ใช้ราคายกตู้เหมารวม |
| CPU / RAM / Storage | ส่งภาพหน้าสเปกที่ไม่เปิดเผยข้อมูลส่วนตัว พร้อมจำนวนดิสก์ที่รวมขาย |
| Power Supply / พัดลม | แจ้งจำนวน PSU ที่ติดตั้งและสถานะการเปิดเครื่อง ไม่เดาว่าระบบทำงานสมบูรณ์ |

## ความเป็นเจ้าของและความปลอดภัยก่อนขาย

ก่อนขายอุปกรณ์จากบริษัท ให้ผู้มีอำนาจอนุมัติการจำหน่ายและกำหนดแนวทางจัดการ HDD/SSD ขององค์กร หากดิสก์มีข้อมูลสำคัญ ควรถอดเก็บหรือลบตามนโยบายของเจ้าของข้อมูล หลีกเลี่ยงการส่งรหัสผ่าน รูปข้อมูลลูกค้า หรือเลข Service Tag ที่เป็นความลับลงบนโพสต์สาธารณะ

## คำถามจากผู้ที่ต้องการขายServerในบุรีรัมย์

### ถ้ามีตู้ Rack แต่ไม่มี Server ขายแยกได้หรือไม่

ส่งขนาด U ความลึก สภาพประตู ล้อ กุญแจและภาพรอบตู้มาให้ประเมินก่อน ตู้หนักหรือขนาดใหญ่ต้องยืนยันวิธีรับมอบ

### ถอด HDD ออกจาก Server ไปแล้วประเมินได้ไหม

ได้สำหรับการประเมินเบื้องต้น แต่แจ้งจำนวน Bay, Tray และส่วนที่ถูกถอดให้ครบ เพราะเครื่องไม่พร้อมใช้งานมีมูลค่าต่างจากชุดครบ
