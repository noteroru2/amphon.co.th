## ประเมิน Switch และ Network จากยโสธร: ดูพอร์ตและสิทธิ์บัญชีให้ครบ

อุปกรณ์ Network หน้าตาเหมือนกันอาจมีมูลค่าและความเสี่ยงต่างกันมาก เช่น Switch 24 พอร์ตแบบ Unmanaged กับ Managed PoE หรือ Firewall ที่ยังติด License และ Cloud Account ผู้ขายจากยโสธรควรเริ่มที่รหัสรุ่นจริงและสถานะสิทธิ์การโอน **ไม่ใช่สรุปว่าของทุกชิ้นพร้อมใช้งานเพียงเพราะไฟติด** และไม่รับประกันว่าจะรับซื้อหรือปลดบัญชีอุปกรณ์ทุกประเภท

## เช็กรายละเอียดที่จะทำให้ราคาต่างกัน

| กลุ่มอุปกรณ์ | ข้อมูลที่ควรส่ง |
| --- | --- |
| Managed/Unmanaged Switch | รุ่นเต็ม จำนวนพอร์ต RJ45 ความเร็ว 1G/2.5G/10G และระบบจัดการ |
| PoE Switch | ค่า PoE Budget ตามรุ่น มาตรฐานและจำนวนพอร์ตที่จ่ายไฟได้ ไม่ใช้คำว่า PoE 24 พอร์ตอย่างเดียว |
| SFP/SFP+ Uplink | จำนวนช่องและโมดูลที่รวมขายจริง แยกโมดูลที่ถอดออกแล้ว |
| Access Point | รุ่น Controller/Cloud ที่ใช้ สถานะผูกองค์กร และอะแดปเตอร์หรือ PoE Injector |
| Firewall/Router | รุ่น Port, License ที่โอนสิทธิ์ได้หรือไม่ได้ และสถานะ Config โดยไม่เปิดเผยข้อมูลเครือข่าย |
| อุปกรณ์ติดตั้ง | Rack Ears, ขาแขวน, แหล่งจ่ายไฟ, Console Cable และเสาอากาศ |

ถ่ายภาพด้านหน้า ด้านหลัง ป้าย Model และอุปกรณ์ที่ให้มาจริง หากพอร์ตบางช่องยังไม่ทดสอบให้ระบุว่า “ไม่ได้ทดสอบครบ” ไม่ควรยืนยันว่าทุกพอร์ตทำงาน

## การส่งต่ออุปกรณ์องค์กรต้องจัดการบัญชีโดยเจ้าของ

อุปกรณ์ที่เคยอยู่ในระบบสำนักงานอาจมีค่า VLAN, VPN, Wi-Fi Password, Site-to-Site Config หรือบัญชี Cloud ของบริษัทเดิม ผู้มีสิทธิ์ควรสำรองการตั้งค่าที่จำเป็นและ Reset/Unclaim ตามคู่มือผู้ผลิตก่อนส่งมอบ โดยไม่ส่งรหัสผ่านผู้ดูแล, VPN Key หรือข้อมูลภายในผ่านแชต **ไม่ควรขอวิธีข้าม Cloud Lock** และอย่าอ้างว่า License โอนได้ทุกกรณี

## ตรวจข้อจำกัดก่อนเสนอราคาเหมาล็อต

หากมี Switch, AP และ Firewall หลายรุ่น ให้จัดรายการแยกจำนวน สถานะทดสอบ อุปกรณ์ขาดและสิทธิ์ที่ยังผูกอยู่ อุปกรณ์ Rack จำนวนมากต้องตกลงค่าแพ็กและการป้องกันพอร์ตขณะขนส่ง การรับสินค้าจากยโสธรขึ้นกับการตรวจข้อมูลและข้อตกลง ไม่ใช่มีจุดรับประจำจังหวัดที่ยืนยันแล้ว
