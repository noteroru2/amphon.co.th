## วิธีประเมิน Networkในยโสธร: Managed Switch PoE และอุปกรณ์ที่ผูก Cloud

Switch 24 พอร์ตแบบ PoE และแบบไม่มี PoE ไม่ใช่อุปกรณ์เดียวกัน อีกทั้ง Access Point หรือ Firewall อาจติดบัญชี Cloud ของบริษัทเดิม จึงต้องแจ้งสถานะสิทธิ์ก่อนตีราคา

## เช็กรุ่นและสถานะตามที่เห็นจริง

- รุ่นเต็ม RJ45/SFP/SFP+ และความเร็ว Uplink
- PoE Budget ตามสเปกรุ่น ไม่ใช้คำว่า 24 พอร์ตอย่างเดียว
- Cloud/Controller ยังผูก หรือ Unclaim แล้วโดยเจ้าของ
- Rack Ears, Adapter, โมดูล SFP ที่รวมขาย

การให้ข้อมูลรุ่น อาการ จำนวน และสิ่งที่ส่งมอบจริงสำคัญกว่าการแจ้งราคาที่คาดหวัง ถ้าไม่ได้ทดสอบเครื่องให้ระบุว่า **ยังไม่ทดสอบ** ไม่ต้องเปิดเครื่องเสียหรือดัดแปลงอุปกรณ์เพื่อถ่ายรูป

## ข้อควรระวังก่อนตกลงขาย

ผู้มีสิทธิ์ต้องถอนบัญชีและจัดการ Config ตามคู่มือ ไม่ส่ง Admin Password, VPN Key หรือข้อมูลระบบภายใน และไม่ขอวิธีข้าม Cloud Lock

## ส่งรูปและวางแผนส่งมอบจากยโสธร

เริ่มส่งรูป Network จากยโสธรได้ แต่ต้องยืนยันความเป็นเจ้าของและวิธีส่งมอบจริงก่อน

ร้านดำเนินการโดย **บริษัท อำพล เทรดดิ้ง จำกัด** มีหน้าร้านจริงเฉพาะอุบลราชธานี 740/8 ถนนชยางกูร ติดปากซอยชยางกูร 32 เปิด 09:00–19:00 น. ติดต่อขายผ่าน [LINE @webuy](https://line.me/ti/p/~@webuy) ได้ตลอด 24 ชั่วโมง เจ้าหน้าที่ตอบตามคิวงาน การเสนอราคาจากรูปไม่ใช่ราคายืนยันก่อนตรวจสภาพจริงและตกลงส่งมอบ

## วิธีเตรียม Managed Switch / Access Point ที่ผูก Cloud ก่อนเสนอขาย

อุปกรณ์ Network ที่เปิดไฟติดไม่ได้ยืนยันว่านำไปใช้ต่อได้ทันที หากเป็น **Managed Switch, Access Point หรือ Firewall** ให้ส่ง Model/Part Number ที่อ่านได้ พร้อมภาพพอร์ตและสถานะของอุปกรณ์ที่รวม เช่น SFP, PoE Injector, AC Adapter หรือขาแขวน

ควรแยกสามสถานะในรายการเดียวกัน: **1) ยืนยันรุ่นฮาร์ดแวร์แล้ว 2) ยังไม่ทราบสถานะ License/Cloud Controller 3) เจ้าขององค์กรเตรียม Factory Reset หรือ Unbind ได้หรือไม่** การไม่ทราบข้อ 2–3 ไม่ได้แปลว่าเครื่องปลดผูกบัญชีแล้ว และร้านไม่ขอรหัสผ่านสำหรับการประเมินราคาเบื้องต้น

ตัวอย่างข้อมูลที่ใช้ได้: “Switch 24 พอร์ต มี PoE จำนวน 2 ตัว, ไม่มี SFP จำนวน 1 ชุด, อุปกรณ์อยู่ยโสธร, เจ้าของยังไม่ถอน Cloud Management” โดยนี่เป็น **ตัวอย่างรูปแบบรายการ ไม่ใช่ล็อตที่ร้านเคยซื้อ** หากยังทำงานในระบบจริงไม่ควรดึงสายหรือปิดอุปกรณ์เพื่อสาธิตโดยไม่มีผู้ดูแลรับผิดชอบ การส่งมอบต้องตกลงหลังตรวจสิทธิ์และวิธีลบข้อมูล Config ที่เหมาะสม

## คำถามที่ควรแจ้งก่อนรับราคา
