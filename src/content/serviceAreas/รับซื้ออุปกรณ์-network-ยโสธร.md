## วิธีประเมิน Networkในยโสธร: Managed Switch PoE และอุปกรณ์ที่ผูก Cloud

Switch 24 พอร์ตแบบ PoE และแบบไม่มี PoE ไม่ใช่อุปกรณ์เดียวกัน อีกทั้ง Access Point หรือ Firewall อาจติดบัญชี Cloud ของบริษัทเดิม จึงต้องแจ้งสถานะสิทธิ์ก่อนตีราคา

## เช็กรุ่นและสถานะตามที่เห็นจริง

- รุ่นเต็ม RJ45/SFP/SFP+ และความเร็ว Uplink
- PoE Budget ตามสเปกรุ่น ไม่ใช้คำว่า 24 พอร์ตอย่างเดียว
- Cloud/Controller ยังผูก หรือ Unclaim แล้วโดยเจ้าของ
- Rack Ears, Adapter, โมดูล SFP ที่รวมขาย

การให้ข้อมูลรุ่น อาการ จำนวน และสิ่งที่ส่งมอบจริงสำคัญกว่าการแจ้งราคาที่คาดหวัง ถ้าไม่ได้ทดสอบเครื่องให้ระบุว่า **ยังไม่ทดสอบ** ไม่ต้องเปิดเครื่องเสียหรือดัดแปลงอุปกรณ์เพื่อถ่ายรูป

## ข้อควรระวังก่อนตกลงขาย

ผู้มีสิทธิ์ต้องถอนบัญชีและจัดการ Config ตามคู่มือ ไม่ส่ง Admin Password, VPN Key หรือข้อมูลระบบภายใน และไม่ขอวิธีข้าม Cloud Lock

## ส่งรูปและวางแผนส่งมอบจากยโสธร

เริ่มส่งรูป Network จากยโสธรได้ แต่ต้องยืนยันความเป็นเจ้าของและวิธีส่งมอบจริงก่อน
