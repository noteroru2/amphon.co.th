## รับพิจารณางานล็อตบริษัทและประมูลในชัยภูมิ

บริษัทในชัยภูมิที่เปลี่ยนรอบเครื่องอาจมีคอมจากหลายแผนกปะปนกัน และอาจใช้คำว่า “ประมูล” ทั้งที่เป็นการขอใบเสนอซื้อเพื่อเปรียบเทียบราคาภายใน การขอราคาเริ่มได้ด้วยข้อมูลจริง แต่ผู้ติดต่อควรแยกกระบวนการอนุมัติจำหน่ายออกจากการขายทอดตลาดที่มีประกาศและระเบียบเป็นทางการ

## สินทรัพย์ IT จากหลายสำนักงานและสิทธิ์เสนอขาย

| รายการตรวจ | ข้อมูลที่ควรส่ง |
| --- | --- |
| ประเภทและจำนวน | Desktop, Notebook, Monitor, Server, UPS และ Network แยกรายการต่อหมวด |
| ผู้มีอำนาจจำหน่าย | หลักฐานอนุมัติภายใน และระบุทรัพย์สินเช่า/ลีสซิ่งที่ยังขายไม่ได้ |
| สภาพและข้อมูล | CPU/Gen, RAM, SSD ที่รวม/ถอด, MDM, Domain และสถานะทดสอบ |
| การเข้าถึงและส่งมอบ | จำนวนจุดเก็บ ชั้นอาคาร วันส่งคืนสถานที่ ผู้รับผิดชอบการยกขน |

### กระบวนการประมูลกับการเสนอซื้อไม่ใช่สิ่งเดียวกัน

หากมีประกาศขายทอดตลาดจากหน่วยงาน ให้ตรวจเอกสารเข้าร่วม คุณสมบัติผู้เสนอราคา เงินประกัน และวันดูทรัพย์สินก่อน ไม่มีข้อยืนยันว่าร้านจะเข้าร่วมทุกงาน การซื้อขายทรัพย์สินที่ผู้มีอำนาจอนุมัติแล้วต่างจากการเข้าร่วมประมูลจริง

การประเมินราคาสินค้าเริ่มจากรุ่น CPU/Generation, RAM/SSD, จำนวน, สภาพ และสิ่งที่ส่งมอบจริง ราคาเบื้องต้นจากรูปไม่ใช่รายงานมูลค่าทรัพย์สินโดยผู้ประเมินที่ได้รับแต่งตั้ง และไม่อ้างว่าเคยชนะการประมูลหรือซื้อของจากหน่วยงานใด

## ข้อมูลความปลอดภัยและสิทธิ์จำหน่าย

องค์กรต้องตรวจว่าผู้ขายมีสิทธิ์และได้รับอนุมัติจำหน่ายสินทรัพย์จริง แยกอุปกรณ์เช่าและของบุคคลอื่น ห้ามส่ง Password, OTP, ข้อมูลลูกค้า หรือเอกสารลับในแชท ฝ่าย IT ควรจัดการ Storage, MDM และ Cloud Account ตามนโยบายก่อนส่งมอบ; **Factory Reset ไม่ใช่ใบรับรอง Data Destruction**

## การส่งรายการและนัดรับมอบจากชัยภูมิ

ลูกค้าชัยภูมิส่งรูปและ Asset List ผ่าน LINE @webuy ได้ตลอด 24 ชั่วโมง การลงพื้นที่หรือรับมอบพิจารณาตามจำนวน มูลค่ารวม น้ำหนัก ระยะทาง และข้อตกลง ไม่มีหน้าร้านหรือทีมงานประจำจังหวัดชัยภูมิ

บริษัทผู้ดำเนินการคือ **บริษัท อำพล เทรดดิ้ง จำกัด** มีหน้าร้านจริงเฉพาะจังหวัดอุบลราชธานี ลูกค้าจากพื้นที่อื่นเริ่มขอราคาได้ออนไลน์ โดยตรวจรับ ชำระเงิน และจัดขนส่งตามที่ตกลงรายกรณี ไม่รับประกันรับถึงบ้านหรือเข้าประมูลทุกงาน

## คำถามก่อนส่งล็อตบริษัท

### ส่งเงื่อนไขประมูลให้ตรวจได้ไหม

ส่งเอกสารประกาศที่เปิดเผยได้พร้อมรายการสินค้าเพื่อพิจารณาความเหมาะสมก่อน ร้านยังไม่รับรองว่าจะยื่นข้อเสนอหรือชนะประมูล

### เครื่องถูกถอด SSD ไปแล้วต้องแจ้งอะไร

บอกจำนวนเครื่องที่ไม่มี SSD และระบุว่าไม่มี Storage รวมขาย ไม่ตีราคาเหมือนเครื่องชุดครบ
