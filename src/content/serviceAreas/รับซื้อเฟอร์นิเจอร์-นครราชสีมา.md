## ขายเฟอร์นิเจอร์สำนักงานจากนครราชสีมา: ต้องตรวจความคุ้มค่าการขนย้ายก่อน

AMPHON เน้นสินค้าไอทีและพิจารณาอุปกรณ์สำนักงานที่เกี่ยวข้องเป็นรายกรณี ไม่ใช่การรับรองว่าจะรับเฟอร์นิเจอร์บ้านทุกประเภทหรือรื้อถอนสำนักงานได้ทุกแห่ง สิ่งสำคัญไม่ใช่แค่ราคาต่อโต๊ะ แต่คือความครบชุด จำนวนและต้นทุนเคลื่อนย้ายออกจากอาคาร

## แยกสินค้าตามวิธีตรวจ ไม่รวมเป็น “ของออฟฟิศหนึ่งล็อต”

| รายการ | ภาพ/ข้อมูลที่ใช้ตรวจ |
| --- | --- |
| โต๊ะทำงานและโต๊ะประชุม | กว้าง×ยาว×สูง วัสดุ รอยบวมน้ำ ขาโต๊ะ และชิ้นส่วนสำหรับถอดประกอบ |
| เก้าอี้สำนักงาน | ระบบโช้ก ล้อ ที่วางแขน พนักพิง สภาพเบาะ และจำนวนที่ชำรุด |
| ตู้เอกสาร/ตู้เหล็ก | ความสูง น้ำหนักโดยประมาณ ลิ้นชัก/ราง กุญแจ และจุดสนิม |
| ตู้แร็กและชั้นวางห้อง IT | ขนาดโครง ถาด/เสา/น็อต ความครบชุด และจุดยึดกับพื้นหรือผนัง |
| แขนจับจอและพาร์ทิชั่น | VESA mount ข้อต่อ แคลมป์ น็อต รางยึด และความจำเป็นต้องรื้อก่อนขน |

ส่งทั้งภาพมุมกว้างของห้องและภาพระยะใกล้ของตำหนิ ไม่ควรใช้รูปสินค้ารุ่นใหม่แทนสภาพของที่จะขายจริง

## ตรวจพื้นที่ก่อนประเมินราคาเหมาล็อต

- **ชั้นและลิฟต์:** ตู้เหล็กชั้นบนที่ไม่มีลิฟต์ต้องจัดแผนยกต่างจากโต๊ะชั้นล่าง
- **ระยะทางถึงจุดจอดรถ:** ระบุว่าขนผ่านบันได ทางเดินแคบ หรือพื้นที่ห้ามจอดหรือไม่
- **งานถอดประกอบ:** แยกตู้และพาร์ทิชั่นที่ยึดถาวรกับอาคาร ห้ามเริ่มรื้อก่อนตกลงผู้รับผิดชอบ
- **สิทธิ์จำหน่าย:** ตรวจว่าทรัพย์สินเป็นของบริษัทจริง ไม่ใช่อุปกรณ์ของผู้ให้เช่าพื้นที่
- **กำหนดคืนพื้นที่:** แจ้งวันและเวลาที่อาคารอนุญาตให้ขน แต่ไม่ถือเป็นการรับประกันว่าร้านจะขนเสร็จทันเวลา
