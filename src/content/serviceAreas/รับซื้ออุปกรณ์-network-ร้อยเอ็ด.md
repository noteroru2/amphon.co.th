## รับซื้อ Switch Network ร้อยเอ็ด | พอร์ต SFP และความเร็วลิงก์

Switch จากระบบสำนักงานในร้อยเอ็ดอาจดูเหมือนกันแต่มีความเร็วลิงก์และประเภทพอร์ตต่างกัน เช่น รุ่นที่มี Uplink 10GbE หรือ SFP+ ไม่ควรถูกอธิบายรวมกับ Switch 100Mbps รุ่นเก่า เมื่อขอราคาควรแนบรูปพอร์ตด้านหน้าและป้ายรุ่นให้ครบก่อน

## อ่านชนิดพอร์ตให้ตรงก่อนประเมิน Switch

นับพอร์ต RJ45 ปกติแยกจาก SFP/SFP+ และพอร์ต Management ตรวจรุ่นที่รองรับ 1GbE, 10GbE หรือ PoE ตามป้ายหรือ Datasheet รุ่นนั้น หากมี Optical Module หรือ DAC Cable รวมอยู่ให้ถ่ายแยก พร้อมแจ้งว่ามี Power Adapter หรือใช้ไฟในตัว

### รายการข้อมูลที่ช่วยให้ประเมินตรงกับเครื่องจริง

| ข้อมูลที่ควรแจ้ง | เหตุผลที่ต้องตรวจ |
| --- | --- |
| ความเร็วและ Port Count | จำนวนพอร์ต RJ45 และ Uplink, 100M/1G/10G ตามรุ่นที่ยืนยันได้ |
| SFP / SFP+ | ระบุโมดูลที่ให้มาด้วย หรือแจ้งว่าพอร์ตว่าง |
| Managed Switch | แจ้งสถานะ Config, Reset และบัญชีที่ยังผูกอยู่ตามข้อมูลที่ทราบ |
| ความสมบูรณ์ของพอร์ต | แจ้งพอร์ตหลวม พอร์ตเสีย ไฟสถานะที่ผิดปกติและพัดลมดัง |

## ความเป็นเจ้าของและความปลอดภัยก่อนขาย

สำหรับ Switch ของหน่วยงาน ต้องขออนุมัติการขายตามขั้นตอนองค์กร และให้ฝ่าย IT สำรองค่าคอนฟิกและลบข้อมูลบัญชีหรือระบบบริหารจัดการที่ผูกอยู่ การถ่ายภาพเพื่อขอราคาควรหลีกเลี่ยงป้ายหมายเลขเครือข่ายภายในและรายละเอียดระบบที่เป็นความลับ
