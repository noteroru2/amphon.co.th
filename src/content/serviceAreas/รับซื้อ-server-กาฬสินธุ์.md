## แนวทางคัดกรอง Server และชิ้นส่วน Enterprise จาก กาฬสินธุ์ ก่อนเสนอราคา

ระบบ Server อาจมีข้อมูลและบัญชีองค์กร ผู้ขายต้องมีสิทธิ์และจัดการ Storage/Management Account ก่อนส่งมอบ ผู้ขายจากกาฬสินธุ์สามารถส่งข้อมูลมาเพื่อขอพิจารณาออนไลน์ได้ก่อน ไม่ควรนำของไปส่งหรือจ่ายค่าขนส่งจนกว่าจะยืนยันประเภทและวิธีตรวจรับตามจริง การรับพิจารณาไม่ใช่คำรับรองว่าจะรับซื้อสินค้าทุกประเภทหรือทุกสภาพ

## สามจุดตรวจที่ช่วยแยกสภาพและความครบชุด

### 1. รหัสรุ่น Server

แยก Rack กับ Tower และรุ่น PowerEdge ProLiant ThinkSystem ไม่อิงเพียงยี่ห้อ

### 2. ราง Rack

ตรวจ Rails Ears และขนาดตู้ที่ใช้ เพราะอุปกรณ์ติดตั้งอาจไม่รวมขาย

### 3. RAM Slot/Drive Blank

นับฝาปิดและชิ้นส่วนเล็กที่มีผลต่อการติดตั้งตู้

## เตรียมข้อมูลการส่งมอบและการจัดการสิทธิ์

- ระบุผู้มีสิทธิ์จำหน่ายสินค้าจริง โดยเฉพาะทรัพย์สินบริษัทหรืออุปกรณ์ที่อาจผูกบัญชี
- ถ่ายรูปสินค้าทั้งชุดและรอยเสียหายโดยไม่เปิดเผยรหัสผ่าน OTP หรือข้อมูลลูกค้า
- แยกรุ่น Server ตัวเครื่อง RAM PSU Drive Tray และ Storage ที่รวมขายจริงกับเครื่องไม่มี Storage
- หาก Server ยังติดตั้งใน Rack หรือมีข้อมูลบน HDD/SSD ให้ผู้ดูแลระบบที่มีสิทธิ์ปลดออกจากงานและจัดการข้อมูลก่อนเคลื่อนย้าย
- อุปกรณ์ใหญ่หรือของเปราะบางต้องคุยค่าแพ็ก น้ำหนัก ข้อจำกัดผู้ขนส่ง และผู้รับผิดชอบค่าใช้จ่ายก่อนตกลง

## ช่องทางติดต่อที่ถูกต้องสำหรับผู้ขายในกาฬสินธุ์

ผู้ดำเนินการคือ **บริษัท อำพล เทรดดิ้ง จำกัด** มีหน้าร้านจริงแห่งเดียวที่ **740/8 ถนนชยางกูร อำเภอเมืองอุบลราชธานี** จุดสังเกตปากซอยชยางกูร 32 เปิด **09:00–19:00 น.** ส่งรูปรุ่นและสภาพผ่าน [LINE @webuy](https://line.me/ti/p/~@webuy) ได้ **24 ชั่วโมง** แต่เจ้าหน้าที่ตอบตามคิว ไม่ใช่มีทีมรับของหรือหน้าร้านประจำจังหวัดกาฬสินธุ์ การชำระเงินขึ้นกับการตรวจรับและข้อตกลง ไม่รับประกันราคา/รับถึงบ้านทุกกรณี

## คำถามที่พบก่อนส่งรูป

### ขอราคาเบื้องต้นจากกาฬสินธุ์ต้องส่งข้อมูลใด?

ส่งภาพป้ายรุ่น สภาพจริง อุปกรณ์ที่รวมและอาการที่ทดสอบได้ผ่าน LINE @webuy ก่อน โดยร้านรับพิจารณาตามประเภทและตลาดจริง

### ถ้ายังไม่ได้ทดสอบครบจะขอประเมินได้ไหม?

ได้สำหรับขอข้อมูลเบื้องต้น แต่ต้องแจ้งว่าไม่ได้ทดสอบครบ ไม่ถือว่าเป็นเครื่องสมบูรณ์

### มีทีมรับสินค้าประจำจังหวัดกาฬสินธุ์หรือไม่?

ไม่มีการยืนยันสาขาหรือทีมรับสินค้าประจำจังหวัดนี้ หน้าร้านจริงอยู่ที่อุบลราชธานีและวิธีส่งมอบต้องตกลงรายกรณี
