## วิธีประเมิน Serverในร้อยเอ็ด: Server ถอด HDD/SSD แล้วและการนับ Drive Tray

Server ปลดระวางจากองค์กรในร้อยเอ็ดบางเครื่องไม่มี HDD/SSD เพราะฝ่าย IT ถอดเก็บข้อมูลแล้ว แต่จำนวน Drive Tray, RAID Controller, PSU และ RAM ที่เหลือมีผลต่อการใช้งานต่อ จึงไม่ควรเหมาราคาเหมือนชุดพร้อมใช้

## เช็กรุ่นและสถานะตามที่เห็นจริง

- Server Tower/Rack รุ่นเต็มและ CPU จำนวนจริง
- RAM ECC/RDIMM จำนวนแผงและความจุ
- Drive Bay/Tray, RAID และ HDD/SSD ที่รวมจริง
- Power Supply ราง Rack และผล POST ที่ทดสอบได้

การให้ข้อมูลรุ่น อาการ จำนวน และสิ่งที่ส่งมอบจริงสำคัญกว่าการแจ้งราคาที่คาดหวัง ถ้าไม่ได้ทดสอบเครื่องให้ระบุว่า **ยังไม่ทดสอบ** ไม่ต้องเปิดเครื่องเสียหรือดัดแปลงอุปกรณ์เพื่อถ่ายรูป

## ข้อควรระวังก่อนตกลงขาย

บริษัทต้องตรวจสิทธิ์จำหน่ายและจัดการข้อมูล Storage ก่อนขาย ไม่ส่งรหัส iDRAC/iLO, Backup หรือข้อมูลลูกค้า

## ส่งรูปและวางแผนส่งมอบจากร้อยเอ็ด

Server หนักและมีรางต้องตกลงวิธีขนส่งจากร้อยเอ็ดตามจำนวนและสภาพ ไม่รับประกันรับถึงบ้าน

## การถอด HDD/SSD ออกจาก Server ไม่ได้แปลว่าเครื่องไม่มีมูลค่า

หากองค์กรในร้อยเอ็ดเก็บ HDD/SSD ไว้เพราะนโยบายข้อมูล ให้แยก **Drive Media ที่ถอดออก** กับ **Drive Tray/Caddy ที่ยังติดตั้ง** และนับจำนวน Bay ที่มีจริง CPU, RAM ECC/RDIMM, RAID Controller, PSU และ Rail Kit ยังต้องตรวจแยก เพราะเครื่องที่ไม่มี Storage ไม่สามารถใช้ราคาเท่าชุดที่มี SSD/HDD ครบตามสเปกได้

**ชุดภาพที่ควรส่ง:** ป้าย Service Tag หรือ Model ที่ไม่เปิดเผยข้อมูลอ่อนไหว, ด้านหน้า Drive Bay, ด้านหลัง PSU, ภาพ RAM/CPU เท่าที่เห็นได้โดยไม่ถอดชิ้นส่วนที่ยังใช้งาน และสถานะ POST ที่เคยตรวจ ถ้าเปิดไม่ติดหรือไม่ได้ทดลองให้แจ้งตรง ๆ อย่าแต่งรายการว่าผ่านการทดสอบแล้ว

สำหรับล็อตของบริษัท ให้ผู้มีอำนาจจัดการสิทธิ์จำหน่ายและสื่อเก็บข้อมูลก่อนนัดตรวจ อย่าส่งรหัส iDRAC/iLO, IP ภายใน, รหัสผ่าน หรือไฟล์สำรองผ่านแชท หากเป็น Server ยังติดตั้งในตู้ Rack ต้องคุยขั้นตอนถอดและการขนส่งแยกจากการประเมินมูลค่าฮาร์ดแวร์

## คำถามที่ควรแจ้งก่อนรับราคา

### ถอด HDD ไปแล้วแต่มี CPU/RAM ให้ประเมินได้ไหม

ได้ในขั้นตรวจฮาร์ดแวร์จากรายการจริง แต่ราคา final ต้องตรวจสภาพ
