## วิธีประเมิน Serverในร้อยเอ็ด: Server ถอด HDD/SSD แล้วและการนับ Drive Tray

Server ปลดระวางจากองค์กรในร้อยเอ็ดบางเครื่องไม่มี HDD/SSD เพราะฝ่าย IT ถอดเก็บข้อมูลแล้ว แต่จำนวน Drive Tray, RAID Controller, PSU และ RAM ที่เหลือมีผลต่อการใช้งานต่อ จึงไม่ควรเหมาราคาเหมือนชุดพร้อมใช้

## เช็กรุ่นและสถานะตามที่เห็นจริง

- Server Tower/Rack รุ่นเต็มและ CPU จำนวนจริง
- RAM ECC/RDIMM จำนวนแผงและความจุ
- Drive Bay/Tray, RAID และ HDD/SSD ที่รวมจริง
- Power Supply ราง Rack และผล POST ที่ทดสอบได้

การให้ข้อมูลรุ่น อาการ จำนวน และสิ่งที่ส่งมอบจริงสำคัญกว่าการแจ้งราคาที่คาดหวัง ถ้าไม่ได้ทดสอบเครื่องให้ระบุว่า **ยังไม่ทดสอบ** ไม่ต้องเปิดเครื่องเสียหรือดัดแปลงอุปกรณ์เพื่อถ่ายรูป

## ข้อควรระวังก่อนตกลงขาย

บริษัทต้องตรวจสิทธิ์จำหน่ายและจัดการข้อมูล Storage ก่อนขาย ไม่ส่งรหัส iDRAC/iLO, Backup หรือข้อมูลลูกค้า

## ส่งรูปและวางแผนส่งมอบจากร้อยเอ็ด

Server หนักและมีรางต้องตกลงวิธีขนส่งจากร้อยเอ็ดตามจำนวนและสภาพ ไม่รับประกันรับถึงบ้าน
