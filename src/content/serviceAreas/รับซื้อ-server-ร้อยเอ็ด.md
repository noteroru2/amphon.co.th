## Server ปลดระวางจากร้อยเอ็ด: สเปกที่ขายได้จริงไม่เท่ากับป้ายหน้าตู้

Server Tower กับ Rack Server มีต้นทุนและมูลค่าต่างกัน โดยเฉพาะเครื่ององค์กรที่ถอด Storage เก็บไว้ก่อนจำหน่าย การส่งรูปเครื่องด้านหน้าภาพเดียวไม่พอสำหรับตีราคาเหมาล็อต ผู้ขายจากร้อยเอ็ดควรส่งรายการให้ร้านคัดกรองเบื้องต้นก่อนขนย้าย **ไม่ได้รับประกันว่า AMPHON จะรับซื้อ Server ทุกรุ่น**

## ตรวจ 6 ส่วนที่ทำให้รุ่นเดียวกันมีสภาพไม่เท่ากัน

| ส่วน | ระบุอย่างไรให้ตรวจสอบได้ |
| --- | --- |
| CPU | รุ่น Xeon/EPYC หรือรุ่นจริงจากระบบ จำนวนตัวที่ติดตั้ง ไม่สรุปจากจำนวนช่อง CPU |
| RAM | ECC RDIMM/LRDIMM ความจุต่อแผง จำนวนแผงและรุ่นตามที่อ่านได้ |
| Storage | มี HDD/SSD กี่ลูก รวม Drive Tray/Caddy และฝาปิดช่องครบหรือไม่ |
| RAID / Backplane | รุ่น RAID Controller และจำนวนช่องที่ตรวจได้ ไม่อ้างว่าทุกช่องใช้งานปกติ |
| PSU / พัดลม | จำนวน PSU ติดตั้งจริง ค่า Watt และแจ้งอาการ Error หรือพัดลมหาย |
| Rack accessories | Rails, Rack Ears, ฝาหน้า, Power Cable และสายเฉพาะรุ่นที่รวมขาย |

**ตัวอย่างสถานะที่ต้องแยก:** เครื่องที่เปิดเข้า POST ได้แต่ถอด HDD ทั้งหมด, เครื่องที่ยังไม่ทดสอบ, และเครื่องที่ POST Error ต้องไม่ถูกระบุเป็นสภาพเดียวกัน หากไม่มั่นใจรุ่น RAM/RAID ให้ถ่ายภาพป้ายชิ้นส่วนโดยไม่ถอดอุปกรณ์ที่เสี่ยงเสียหาย

## จัดการข้อมูลและสิทธิ์องค์กรก่อนส่งเครื่อง

Server ที่ใช้ในบริษัทอาจมีข้อมูลลูกค้า บัญชีบริหารเครื่อง หรือไดรฟ์ที่ยังไม่ผ่านขั้นตอนลบข้อมูล ฝ่าย IT ของเจ้าของต้องกำหนดว่าจะถอดไดรฟ์ ส่งมอบแบบมีไดรฟ์ หรือจัดการข้อมูลตามนโยบายอย่างไร ไม่ส่ง Password ของ iDRAC/iLO, Backup Key, รายชื่อลูกค้าหรือข้อมูลภายในผ่าน LINE

ถ้า Server อยู่ภายใต้สัญญาเช่าหรืออยู่ในตู้ Rack ของอาคารเช่า ต้องตรวจสิทธิ์ในการจำหน่ายและการถอดออกจากสถานที่ก่อน การขายตัวเครื่องไม่ได้แปลว่าสามารถโอนสิทธิ์ซอฟต์แวร์ทุกชนิดไปพร้อมกันได้
