## แนวทางคัดกรองServer และชิ้นส่วน Enterpriseจากหนองคายก่อนเสนอราคา

ระบบ Server อาจมีข้อมูลและบัญชีองค์กร ผู้ขายต้องมีสิทธิ์และจัดการ Storage/Management Account ก่อนส่งมอบ ผู้ขายจากหนองคายสามารถส่งข้อมูลมาเพื่อขอพิจารณาออนไลน์ได้ก่อน ไม่ควรนำของไปส่งหรือจ่ายค่าขนส่งจนกว่าจะยืนยันประเภทและวิธีตรวจรับตามจริง การรับพิจารณาไม่ใช่คำยืนยันว่าจะซื้อสินค้าทุกรุ่นหรือชนะประมูลใด

## สามจุดตรวจที่ช่วยแยกสภาพและความครบชุด

### 1. Server อายุมาก

ประเมินตลาดอะไหล่ตามรุ่นและสภาพ ไม่รับประกันรุ่นเก่าทุกเครื่องมีราคา ในการขอราคาเบื้องต้นควรแสดงภาพรุ่นและสถานะที่ตรวจได้จริง หากมีอาการเสียหรือขาดชิ้นส่วนให้ระบุแยกจากเครื่องพร้อมใช้ ข้อมูลที่ไม่แน่ใจไม่ควรกรอกเป็นสเปกยืนยัน เพราะราคาสุดท้ายอาจเปลี่ยนหลังตรวจสินค้า

### 2. จำนวน CPU และรุ่น Xeon

ระบุจำนวน Socket ที่ติดตั้งจริงกับซีพียูรุ่นเต็มเพื่อไม่คาดเดาสเปก ในการขอราคาเบื้องต้นควรแสดงภาพรุ่นและสถานะที่ตรวจได้จริง หากมีอาการเสียหรือขาดชิ้นส่วนให้ระบุแยกจากเครื่องพร้อมใช้ ข้อมูลที่ไม่แน่ใจไม่ควรกรอกเป็นสเปกยืนยัน เพราะราคาสุดท้ายอาจเปลี่ยนหลังตรวจสินค้า

### 3. สถานะ Boot/POST

รายงาน Error หรือไฟสถานะที่เห็นจริง ไม่เปิดเครื่องแรงดันสูงผิดปกติเพื่อถ่ายรูป ในการขอราคาเบื้องต้นควรแสดงภาพรุ่นและสถานะที่ตรวจได้จริง หากมีอาการเสียหรือขาดชิ้นส่วนให้ระบุแยกจากเครื่องพร้อมใช้ ข้อมูลที่ไม่แน่ใจไม่ควรกรอกเป็นสเปกยืนยัน เพราะราคาสุดท้ายอาจเปลี่ยนหลังตรวจสินค้า

## เตรียมข้อมูลการส่งมอบและการจัดการสิทธิ์

- ระบุผู้มีสิทธิ์จำหน่ายสินค้าจริง โดยเฉพาะทรัพย์สินบริษัทหรืออุปกรณ์ที่อาจผูกบัญชี
- ถ่ายรูปสินค้าทั้งชุดและรอยเสียหายโดยไม่เปิดเผยรหัสผ่าน OTP หรือข้อมูลลูกค้า
- แยกสินค้าเปิดติด เครื่องเสีย ไม่ทดสอบ และชุดไม่ครบก่อนเสนอราคารวม
- หากเป็นเครื่องไฟฟ้าแรงสูง แบตบวม หรืออุปกรณ์มีรอยไหม้ ให้หยุดทดสอบและสอบถามแนวทางปลอดภัยก่อนเคลื่อนย้าย
- อุปกรณ์ใหญ่หรือของเปราะบางต้องคุยค่าแพ็ก น้ำหนัก ข้อจำกัดผู้ขนส่ง และผู้รับผิดชอบค่าใช้จ่ายก่อนตกลง

## คำถามที่พบก่อนส่งรูป

### ขอราคาเบื้องต้นจากหนองคายต้องส่งข้อมูลใด?

ส่งภาพป้ายรุ่น สภาพจริง อุปกรณ์ที่รวมและอาการที่ทดสอบได้ผ่าน LINE @webuy ก่อน โดยร้านรับพิจารณาตามประเภทและตลาดจริง

### ถ้ายังไม่ได้ทดสอบครบจะขอประเมินได้ไหม?

ได้สำหรับขอข้อมูลเบื้องต้น แต่ต้องแจ้งว่าไม่ได้ทดสอบครบ ไม่ถือว่าเป็นเครื่องสมบูรณ์

### มีทีมรับสินค้าประจำจังหวัดหนองคายหรือไม่?

ไม่มีการยืนยันสาขาหรือทีมรับสินค้าประจำจังหวัดนี้ หน้าร้านจริงอยู่ที่อุบลราชธานีและวิธีส่งมอบต้องตกลงรายกรณี
