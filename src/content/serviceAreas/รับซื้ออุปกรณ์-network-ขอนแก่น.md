## รับซื้อ Wi-Fi AP และ Network ขอนแก่น | ตรวจ Cloud Lock

สำหรับการอัปเกรด Wi-Fi ภายในสำนักงานหรืออาคารในขอนแก่น อุปกรณ์ที่ถอดออกอาจมีทั้ง Access Point ที่ยังผูก Controller เดิม, Switch PoE และ Router เก่า การพิจารณาราคารวมกันควรเริ่มจากรุ่นที่แน่นอนและสิทธิ์การบริหารจัดการ ไม่ใช่ยึดชื่อยี่ห้อเพียงอย่างเดียว

## ระบบ Wi-Fi แบบ Cloud-managed ต้องปลดสิทธิ์อย่างไร

ผู้มีสิทธิ์ในระบบเดิมควรตรวจว่าต้อง Unclaim/Remove Device หรือโอน Organization ก่อนขายหรือไม่ตามคำแนะนำผู้ผลิต การ Factory Reset ตัวเครื่องอาจไม่ปลดการผูกกับ Cloud Account จึงต้องบอกสถานะให้ชัด ไม่ควรส่ง Credentials ของ Cloud Portal หรือข้อมูลผู้ใช้งานภายในมาพร้อมรูปสินค้า

### รายการข้อมูลที่ช่วยให้ประเมินตรงกับเครื่องจริง

| ข้อมูลที่ควรแจ้ง | เหตุผลที่ต้องตรวจ |
| --- | --- |
| AP และ Controller | ระบุรุ่นฮาร์ดแวร์ จำนวนเครื่อง และมี License/Controller แยกหรือไม่ |
| สถานะ Cloud Account | บันทึก Unclaim แล้ว / ยังผูก / ไม่ทราบ โดยไม่เผยรหัสผ่าน |
| Switch PoE สำหรับ AP | แจ้ง Port Count, PoE Budget, พอร์ต Uplink และแหล่งจ่ายไฟ |
| Power Adapter / Mounting | อะแดปเตอร์ ขายึดเพดาน ราง Rack และสายไฟที่รวมอยู่ |

## ความเป็นเจ้าของและความปลอดภัยก่อนขาย

ก่อนส่งมอบอุปกรณ์จากองค์กร ควรได้รับอนุญาตจากเจ้าของทรัพย์สินและให้ผู้ดูแลระบบจัดการบัญชีตามขั้นตอนถูกต้อง ถ้ายังไม่ทราบว่าอุปกรณ์ติด Cloud Lock หรือไม่ให้แจ้งตามจริง ไม่รับรองการปลดล็อกหรือเปลี่ยนสิทธิ์แทนเจ้าของเดิม
