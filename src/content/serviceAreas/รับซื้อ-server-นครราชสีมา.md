## รับซื้อ Server นครราชสีมา | แยก Server, Storage และ Rack

ในกรณีที่มี Server พร้อม Storage หรือ Rack หลายชนิดอยู่ในห้องเดียวกัน การขอราคาทั้งห้องโดยไม่มีรายการแยกอาจทำให้บางชิ้นถูกคิดมูลค่ารวมผิด ลูกค้าในนครราชสีมาเริ่มส่งแผนผังหรือรูปเครื่องจากแต่ละชั้น Rack พร้อมรายการรุ่นเบื้องต้นได้

## Server, NAS/SAN และตู้ Rack ต้องนับเป็นสินค้าแยกกลุ่ม

Server ที่ประมวลผลและ Storage ที่เน้นดิสก์จำนวนมากใช้ปัจจัยประเมินต่างกัน จึงควรแยกชื่อรุ่น Controller, จำนวน Bay, ความจุดิสก์ที่รวมขาย และรางติดตั้ง ชิ้นที่เป็น KVM, UPS หรือ Switch ก็แจ้งแยกแทนเขียนว่า Server ทั้งหมดเพื่อไม่ให้ขาดรายการ

### รายการข้อมูลที่ช่วยให้ประเมินตรงกับเครื่องจริง

| ข้อมูลที่ควรแจ้ง | เหตุผลที่ต้องตรวจ |
| --- | --- |
| Server Tower/Rack | รุ่น CPU แรม จำนวน Power Supply และสถานะ Boot |
| NAS/SAN/Drive shelf | รุ่น Controller จำนวน Bay, ดิสก์พร้อมส่งหรือถอดเก็บ |
| Rack / Rail / KVM | ขนาดและความลึก Rack อุปกรณ์ยึดและอุปกรณ์เสริมที่แยกขายได้ |
| อุปกรณ์ไฟและ Network | UPS, PDU, Switch แยกจำนวนและเงื่อนไขทดสอบ |

## ความเป็นเจ้าของและความปลอดภัยก่อนขาย

หากเป็นระบบองค์กรในโคราช ต้องเตรียมเอกสารการเป็นเจ้าของหรือหนังสืออนุมัติขายเมื่อจำเป็น ข้อมูลบนดิสก์ควรถูกสำรองและจัดการก่อนส่งมอบ สินค้าที่มีรหัสผ่านและบัญชีภายในไม่ควรถูกนำเสนอเป็นเครื่องพร้อมใช้งานจนกว่าจะปลดและตรวจสอบโดยผู้มีสิทธิ์

## ประเมินออนไลน์จากนครราชสีมาและตกลงวิธีส่งมอบ

แจ้งว่าของอยู่ชั้นใด มีลิฟต์หรือทางขนย้ายอย่างไร และมีชิ้นหนักหรือแบต UPS รวมอยู่หรือไม่ เพื่อคุยวิธีส่งมอบที่ปลอดภัยหลังประเมินเบื้องต้น อำพล เทรดดิ้งไม่มีหน้าร้านประจำจังหวัดนครราชสีมา

## คำถามจากผู้ที่ต้องการขายServerในนครราชสีมา

### มีทั้ง Server และ UPS ในล็อตเดียวจะตีราคาอย่างไร

แยกรายการและสภาพ UPS รวมถึงแบตเตอรี่ก่อนประเมิน ไม่ใช้ราคาต่อชิ้นเดียวกับ Server

### ต้องถอดเครื่องออกจาก Rack ก่อนส่งรูปไหม

ไม่ต้องถอดเพื่อขอราคาเบื้องต้น ถ่ายรูปป้ายรุ่นด้านหน้าและหลังพร้อมจำนวนก่อน แล้วค่อยหารือการถอด/ขนย้าย
