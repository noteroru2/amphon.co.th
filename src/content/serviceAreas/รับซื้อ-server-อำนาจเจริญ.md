## แนวทางคัดกรองServer และชิ้นส่วน Enterpriseจากอำนาจเจริญก่อนเสนอราคา

ระบบ Server อาจมีข้อมูลและบัญชีองค์กร ผู้ขายต้องมีสิทธิ์และจัดการ Storage/Management Account ก่อนส่งมอบ ผู้ขายจากอำนาจเจริญสามารถส่งข้อมูลมาเพื่อขอพิจารณาออนไลน์ได้ก่อน ไม่ควรนำของไปส่งหรือจ่ายค่าขนส่งจนกว่าจะยืนยันประเภทและวิธีตรวจรับตามจริง การรับพิจารณาไม่ใช่คำยืนยันว่าจะซื้อสินค้าทุกรุ่นหรือชนะประมูลใด

## สามจุดตรวจที่ช่วยแยกสภาพและความครบชุด

### 1. การแพ็กขนส่ง

Server Rack หนักต้องป้องกันรางและ Drive Tray รวมถึงตกลงผู้รับผิดชอบยกขน ในการขอราคาเบื้องต้นควรแสดงภาพรุ่นและสถานะที่ตรวจได้จริง หากมีอาการเสียหรือขาดชิ้นส่วนให้ระบุแยกจากเครื่องพร้อมใช้ ข้อมูลที่ไม่แน่ใจไม่ควรกรอกเป็นสเปกยืนยัน เพราะราคาสุดท้ายอาจเปลี่ยนหลังตรวจสินค้า

### 2. Drive Bay และ Caddy

เครื่องไม่มี HDD แต่ถาดยังครบต่างจากเครื่องขาดถาดและ Backplane ในการขอราคาเบื้องต้นควรแสดงภาพรุ่นและสถานะที่ตรวจได้จริง หากมีอาการเสียหรือขาดชิ้นส่วนให้ระบุแยกจากเครื่องพร้อมใช้ ข้อมูลที่ไม่แน่ใจไม่ควรกรอกเป็นสเปกยืนยัน เพราะราคาสุดท้ายอาจเปลี่ยนหลังตรวจสินค้า

### 3. Network Card/SFP

ตรวจจำนวนพอร์ต 1G/10G/25G และโมดูลที่รวมขายจริง ในการขอราคาเบื้องต้นควรแสดงภาพรุ่นและสถานะที่ตรวจได้จริง หากมีอาการเสียหรือขาดชิ้นส่วนให้ระบุแยกจากเครื่องพร้อมใช้ ข้อมูลที่ไม่แน่ใจไม่ควรกรอกเป็นสเปกยืนยัน เพราะราคาสุดท้ายอาจเปลี่ยนหลังตรวจสินค้า

## เตรียมข้อมูลการส่งมอบและการจัดการสิทธิ์

- ระบุผู้มีสิทธิ์จำหน่ายสินค้าจริง โดยเฉพาะทรัพย์สินบริษัทหรืออุปกรณ์ที่อาจผูกบัญชี
- ถ่ายรูปสินค้าทั้งชุดและรอยเสียหายโดยไม่เปิดเผยรหัสผ่าน OTP หรือข้อมูลลูกค้า
- แยกสินค้าเปิดติด เครื่องเสีย ไม่ทดสอบ และชุดไม่ครบก่อนเสนอราคารวม
- หากเป็นเครื่องไฟฟ้าแรงสูง แบตบวม หรืออุปกรณ์มีรอยไหม้ ให้หยุดทดสอบและสอบถามแนวทางปลอดภัยก่อนเคลื่อนย้าย
- อุปกรณ์ใหญ่หรือของเปราะบางต้องคุยค่าแพ็ก น้ำหนัก ข้อจำกัดผู้ขนส่ง และผู้รับผิดชอบค่าใช้จ่ายก่อนตกลง

## ช่องทางติดต่อที่ถูกต้องสำหรับผู้ขายในอำนาจเจริญ

ผู้ดำเนินการคือ **บริษัท อำพล เทรดดิ้ง จำกัด** มีหน้าร้านจริงแห่งเดียวที่ **740/8 ถนนชยางกูร อำเภอเมืองอุบลราชธานี** จุดสังเกตปากซอยชยางกูร 32 เปิด **09:00–19:00 น.** ส่งรูปรุ่นและสภาพผ่าน [LINE @webuy](https://line.me/ti/p/~@webuy) ได้ **24 ชั่วโมง** แต่เจ้าหน้าที่ตอบตามคิว ไม่ใช่มีทีมรับของหรือหน้าร้านประจำจังหวัดอำนาจเจริญ การชำระเงินขึ้นกับการตรวจรับและข้อตกลง ไม่รับประกันราคา/รับถึงบ้านทุกกรณี

## คำถามที่พบก่อนส่งรูป

### ขอราคาเบื้องต้นจากอำนาจเจริญต้องส่งข้อมูลใด?

ส่งภาพป้ายรุ่น สภาพจริง อุปกรณ์ที่รวมและอาการที่ทดสอบได้ผ่าน LINE @webuy ก่อน โดยร้านรับพิจารณาตามประเภทและตลาดจริง

### ถ้ายังไม่ได้ทดสอบครบจะขอประเมินได้ไหม?

ได้สำหรับขอข้อมูลเบื้องต้น แต่ต้องแจ้งว่าไม่ได้ทดสอบครบ ไม่ถือว่าเป็นเครื่องสมบูรณ์

### มีทีมรับสินค้าประจำจังหวัดอำนาจเจริญหรือไม่?

ไม่มีการยืนยันสาขาหรือทีมรับสินค้าประจำจังหวัดนี้ หน้าร้านจริงอยู่ที่อุบลราชธานีและวิธีส่งมอบต้องตกลงรายกรณี
