## รับซื้อ Network อุดรธานี | Firewall และ Router องค์กร

Firewall มือสองมีรายละเอียดสำคัญเรื่อง License, Firmware และสิทธิ์การโอนบัญชี เจ้าของอุปกรณ์ในอุดรธานีควรแจ้งรุ่นฮาร์ดแวร์กับสิทธิ์ Software แยกจากกัน เพราะอุปกรณ์ที่เปิดติดไม่ได้แปลว่าสามารถรับบริการ Security Subscription ต่อได้ทันที

## Firewall ที่หมด Subscription กับเครื่องที่ย้ายสิทธิ์ได้ต้องแยกกัน

ระบุ Vendor, Model, Serial ที่ไม่ต้องเผยแพร่สาธารณะ, ระยะเวลาหมดอายุ Support ถ้าทราบ และสถานะการโอนสิทธิ์กับเจ้าของบัญชีเดิม ไม่ควรสัญญาว่าจะต่อ License หรือสมัครบริการให้ผู้ซื้อได้โดยไม่ตรวจนโยบายของผู้ผลิต กรณีซื้อเป็นล็อตรวม Switch และ Access Point ให้แยกประเภทต่อบรรทัด

### รายการข้อมูลที่ช่วยให้ประเมินตรงกับเครื่องจริง

| ข้อมูลที่ควรแจ้ง | เหตุผลที่ต้องตรวจ |
| --- | --- |
| Firewall Appliance | รุ่นและ Firmware ที่อ่านได้จากอุปกรณ์โดยไม่เปิดเผย Config |
| License / Support | ระบุหมดอายุหรือยังไม่ทราบ ไม่ถือว่า License ติดมากับตัวเครื่องอัตโนมัติ |
| Router / VPN Gateway | แจ้งจำนวนพอร์ต WAN/LAN, SFP และ Power Supply |
| Switch / SFP Module | แยกอุปกรณ์ Optical Transceiver ที่รวมอยู่กับตัว Switch |

## ความเป็นเจ้าของและความปลอดภัยก่อนขาย

ก่อนขายต้องให้ผู้มีสิทธิ์ Export Config ที่ต้องเก็บไว้ในระบบขององค์กร แล้ว Factory Reset หรือปลดทะเบียนอุปกรณ์ตามขั้นตอนถูกต้อง ไม่ส่งรหัส Admin, Private Key, Site-to-site VPN, IP ขององค์กร หรือฐานข้อมูลผู้ใช้งานทางแชท
