## ขายล็อตไอทีบริษัทจากขอนแก่น: เริ่มที่ประเภททรัพย์สินและสิทธิ์จำหน่าย

การขายอุปกรณ์ของบริษัทกับการเข้าร่วมประมูลตามประกาศเป็นคนละกระบวนการ การส่งรูปหรือเอกสารให้ AMPHON พิจารณา **ไม่เท่ากับร้านรับรองว่ามีสิทธิ์เข้าประมูล จะชนะประมูล หรือซื้อสินค้าทุกชิ้น** ผู้ขายจากขอนแก่นควรคัดข้อมูลก่อนยกเครื่องออกจากสถานที่ เพราะต้นทุนขนส่งและความปลอดภัยของข้อมูลอาจทำให้ราคาสุทธิต่างจากการประเมินด้วยรูป

## ตารางรายการที่ช่วยให้แยกราคาต่อสภาพได้

| ช่องข้อมูล | รายละเอียดที่ควรกรอก |
| --- | --- |
| ประเภทและรุ่น | Desktop, Workstation, จอ, Notebook, Network ระบุยี่ห้อและ Model ไม่ใช่แค่ชื่อบริษัทผู้ผลิต |
| สเปกที่ตรวจสอบได้ | CPU, RAM, SSD/HDD, การ์ดจอ และอุปกรณ์ที่รวมจริง |
| จำนวนและเกรด | แยกเปิดติด / ทดสอบบางส่วน / ไม่ได้ทดสอบ / ชำรุด ห้ามถือว่าไม่ได้ทดสอบเท่ากับใช้งานปกติ |
| อุปกรณ์ประกอบ | จอ สายไฟ อะแดปเตอร์ กล่อง และชิ้นส่วนที่ไม่มี ต้องระบุแยก |
| หลักฐาน | ภาพป้ายรุ่นและรูปสภาพตัวอย่างแต่ละกลุ่ม โดยปิดข้อมูลส่วนตัวหรือหมายเลขทรัพย์สินที่เป็นความลับ |

ตัวอย่างเช่น หากมี Desktop 80 เครื่องกับ Workstation 5 เครื่อง ควรแยกบัญชีและสถานะของแต่ละชนิด ไม่รวมเป็น “คอม 85 เครื่องสภาพดี” โดยยังไม่ได้ตรวจ เพราะต้นทุนซ่อมและการขายต่อไม่เหมือนกัน

## สิทธิ์ในทรัพย์สินและความปลอดภัยข้อมูล

ผู้มีอำนาจขายต้องตรวจว่าทรัพย์สินเป็นของบริษัทจริง ไม่ใช่ทรัพย์สินเช่า/ลีสซิ่งหรือรายการติดสัญญา อุปกรณ์ที่มีข้อมูลภายในต้องให้เจ้าของจัดการสิทธิ์และนโยบายสำรองหรือลบข้อมูลก่อนส่งมอบ แจ้งสถานะ BIOS password, BitLocker, MDM หรืออุปกรณ์ติดบัญชีองค์กรอย่างตรงไปตรงมา ร้านไม่ควรได้รับรหัสผ่านหรือ OTP ผ่านแชต

หากเป็นประกาศประมูล ให้ตรวจวิธีเข้าดูของ การวางหลักประกัน (ถ้ามี) ผู้มีสิทธิ์เสนอราคา วันชำระเงิน และวันรับทรัพย์จากเงื่อนไขผู้จัดโดยตรง **การเสนอซื้อทั่วไปไม่ใช่หลักฐานการเข้าร่วมประมูล**
