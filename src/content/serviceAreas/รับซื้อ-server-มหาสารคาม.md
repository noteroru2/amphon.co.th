## รับซื้อ Server มหาสารคาม | เครื่องบริษัทและข้อมูลในดิสก์

Server ที่เลิกใช้งานในสำนักงาน ห้องเรียนหรือหน่วยงานไม่ได้มีมูลค่าจากตัวถังอย่างเดียว สิ่งสำคัญคือรุ่น CPU จำนวน RAM การ์ด RAID และดิสก์ที่ยังอยู่ในเครื่อง เจ้าของ Server ในมหาสารคามสามารถเริ่มด้วยรายการอุปกรณ์ ไม่ต้องส่งข้อมูลที่เก็บอยู่ภายในดิสก์

## Server ปลดระวางที่ยังมีข้อมูลใน RAID ต้องเตรียมอะไร

ขอให้ฝ่าย IT หรือผู้มีสิทธิ์ดูแลระบบตรวจว่ามีข้อมูลธุรกิจหรือข้อมูลส่วนบุคคลอยู่หรือไม่ แล้วกำหนดว่าจะขายพร้อมดิสก์ที่ลบอย่างเหมาะสม หรือขายแบบถอดเก็บดิสก์ทั้งหมด ห้ามตีความว่า RAID ทำให้ข้อมูลถูกลบอัตโนมัติ และไม่ควรแจกบัญชีผู้ดูแลระบบเพื่อใช้เป็นหลักฐานประเมินราคา

### รายการข้อมูลที่ช่วยให้ประเมินตรงกับเครื่องจริง

| ข้อมูลที่ควรแจ้ง | เหตุผลที่ต้องตรวจ |
| --- | --- |
| Tower หรือ Rack และรุ่นเต็ม | รุ่นหน้าตาใกล้กันอาจใช้ CPU คนละ Generation จึงต้องถ่ายป้ายรุ่น |
| RAID Controller / Tray | แจ้งการ์ดและถาดใส่ดิสก์ที่มี แม้จะถอด HDD ออกทั้งหมด |
| CPU Socket / จำนวน RAM | ระบุจำนวน CPU, ชนิด ECC/RDIMM และแผง RAM ที่เสียบอยู่จริง |
| สถานะ Boot / POST | ถ่ายผลการทดสอบที่อนุญาตโดยองค์กร หรือระบุว่าไม่ได้ทดสอบ |

## ความเป็นเจ้าของและความปลอดภัยก่อนขาย

ข้อมูลระบบของมหาวิทยาลัย โรงเรียน สำนักงานหรือหน่วยงานถือเป็นข้อมูลของเจ้าของระบบ ไม่ควรส่งไฟล์ Backup, Snapshot, ข้อมูลนักเรียนหรือข้อมูลบัญชีผู้ใช้งานทางแชทเพื่อยืนยันสภาพเครื่อง ใช้ภาพฮาร์ดแวร์และหน้าสเปกที่ปิดบังข้อมูลได้ การขายต้องได้รับอนุญาตจากผู้มีสิทธิ์

## คำถามจากผู้ที่ต้องการขายServerในมหาสารคาม

### Server ไม่มีดิสก์เลยจะประเมินได้ไหม

ประเมินจากเมนบอร์ด CPU RAM Controller PSU และ Tray ที่เหลือได้ แต่ต้องระบุชัดว่าไม่รวมดิสก์

### จำเป็นต้องเปิดเครื่องที่มีระบบเก่าทำงานเพื่อถ่ายรูปไหม

ไม่จำเป็นต้องเข้าถึงข้อมูลภายใน เพียงแจ้งสถานะเปิดติดหรือ POST และถ่ายภาพชิ้นส่วนที่ไม่เปิดเผยข้อมูลสำคัญก็เริ่มประเมินได้
