## รับซื้ออุปกรณ์ Network สุรินทร์ | Switch PoE และ Wi-Fi AP

หากมี Switch และ Access Point เหลือจากปรับปรุงระบบเครือข่ายในสุรินทร์ สิ่งที่สำคัญกว่านับจำนวนกล่องคือระบุรุ่นและระบบที่ผูกใช้งานอยู่ อุปกรณ์ Wi-Fi หรือ Switch ที่ยังติดบัญชี Cloud ของเจ้าของเดิมอาจนำไปตั้งค่าให้คนใหม่ใช้ไม่ได้จนกว่าจะโอนสิทธิ์อย่างถูกต้อง

## แยก Switch PoE กับ Access Point อย่างไรจึงไม่เหมาราคา

Switch ที่มี 24 Port เหมือนกันอาจมี PoE Budget, พอร์ต SFP, ความเร็ว Uplink และสถานะ Managed ต่างกัน ส่วน Access Point รุ่นเดียวกันอาจใช้ Controller หรือ Cloud Portal ที่ยังผูกบัญชีองค์กรอยู่ ตรวจชื่อรุ่นจากป้ายและบันทึกว่าใครมีสิทธิ์ถอดออกจากระบบเดิม ไม่จำเป็นต้องส่งรหัส Login ให้ร้าน

### รายการข้อมูลที่ช่วยให้ประเมินตรงกับเครื่องจริง

| ข้อมูลที่ควรแจ้ง | เหตุผลที่ต้องตรวจ |
| --- | --- |
| จำนวน RJ45 / PoE | ระบุ 8/24/48 Port, PoE/PoE+ หรือไม่มี PoE ตามสเปกจริง |
| พอร์ต Uplink | แจ้ง SFP/SFP+ พร้อมรูปพอร์ตและอุปกรณ์ Optical Module ที่รวม |
| Access Point / Controller | ระบุรุ่น AP และมีบัญชีบริหารจัดการหรือ Controller เดิมอยู่หรือไม่ |
| อุปกรณ์ประกอบ | Power Adapter, Rack Ears, ฝาครอบ, สาย Console รวมขายหรือไม่ |

## ความเป็นเจ้าของและความปลอดภัยก่อนขาย

สำหรับอุปกรณ์องค์กร ควรสำรองการตั้งค่าที่จำเป็นกับฝ่าย IT จากนั้น Reset/Unclaim ตามขั้นตอนของผู้ผลิตโดยผู้มีสิทธิ์ อย่าส่งรหัสผ่าน ระบบ VPN หรือ Configuration ที่มีข้อมูลลูกค้าทาง LINE และอย่าพยายามข้ามระบบล็อกเพื่อขาย

## คำถามจากผู้ที่ต้องการขายNetworkในสุรินทร์

### Access Point ติด Cloud Account เดิมขายได้ไหม

ต้องให้เจ้าของหรือผู้ดูแลระบบเดิมปลด/โอนสิทธิ์ตามขั้นตอนผู้ผลิตก่อนยืนยันสภาพพร้อมใช้งาน

### Switch 24 Port แต่บางพอร์ตเสียประเมินอย่างไร

แจ้งพอร์ตที่ใช้งานไม่ได้และผลทดสอบเท่าที่มี ไม่ควรขายเป็นเครื่องสมบูรณ์โดยไม่เปิดเผยอาการ
