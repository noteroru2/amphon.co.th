## ทำไมแรมมือสองถึงยังขายได้

RAM หรือ Random Access Memory เป็นหน่วยความจำหลักของคอมพิวเตอร์และโน๊ตบุ๊ค ซึ่งเป็นอุปกรณ์ชิ้นส่วนที่ไม่มีชิ้นส่วนเคลื่อนไหว (Solid-state component) ทำให้ RAM เป็นหนึ่งในอุปกรณ์คอมพิวเตอร์ที่มีอัตราการเสียต่ำเมื่อเทียบกับฮาร์ดดิสก์หรือการ์ดจอ

ความต้องการในตลาดมือสองจึงมีสูงอย่างต่อเนื่อง ไม่ว่าจะเป็นผู้ที่ต้องการอัปเกรดคอมพิวเตอร์เครื่องเดิมให้ทำงานได้เร็วขึ้น ร้านประกอบคอมพิวเตอร์มือสอง หรือองค์กรที่ต้องการอะไหล่แรมสำหรับเซิร์ฟเวอร์รุ่นเก่า ดังนั้น RAM เก่าหรือแรมที่ไม่ใช้แล้วจึงสามารถนำมาเปลี่ยนเป็นเงินสดได้ หากเข้าใจปัจจัยที่มีผลต่อราคาและส่งข้อมูลให้ประเมินอย่างถูกต้อง

## ปัจจัยที่มีผลต่อราคาแรมมือสอง

ราคาขายของ RAM มือสองไม่ได้วัดจากความจุเพียงอย่างเดียว แต่ขึ้นอยู่กับรายละเอียดเชิงเทคนิคหลายประการรวมกัน ได้แก่

1. **DDR Generation**: เทคโนโลยีของ RAM เป็นตัวกำหนดหลัก โดย DDR5 และ DDR4 จะเป็นรุ่นที่ได้รับความนิยมสูงในตลาดปัจจุบัน ส่วน DDR3 ยังมีตลาดเฉพาะกลุ่ม
2. **ความจุ (Capacity)**: แรมความจุสูงต่อแถว เช่น 16GB, 32GB หรือ 64GB มักได้ราคาต่อหน่วยดีกว่าแถวความจุต่ำ
3. **ความเร็ว Bus (Bus Speed / MHz)**: บัสยิ่งสูง ยิ่งเป็นที่ต้องการของสายเกมมิ่งและงานประมวลผล เช่น DDR4 3200MHz หรือ DDR5 6000MHz+
4. **ค่า Latency และ Timing (CL)**: แรมที่มีค่า Timing ต่ำ (CL ต่ำ) มักเป็นแรมเกรด High-Performance ที่มีราคาสูงกว่าแรมมาตรฐาน
5. **ยี่ห้อและรุ่น (Brand & Model)**: แรมจากแบรนด์ชั้นนำ เช่น Corsair, G.Skill, Kingston, TeamGroup, Crucial หรือ Samsung
6. **ซิงค์ระบายความร้อน (Heat Spreader) & ไฟ RGB**: แรมที่มีซิงค์ระบายความร้อนรูปทรงสวยงามหรือมีไฟ RGB มักได้ราคาสูงกว่าแรมเปลือย (Bare PCB)
7. **สถานะประกัน (Warranty)**: แรมหลายแบรนด์มีประกัน Lifetime ในไทย หากมีสติกเกอร์รับประกันของผู้นำเข้าชัดเจน (เช่น Synnex, Ingram, Ascenti) จะช่วยเพิ่มความมั่นใจและมูลค่าในการขาย
8. **สภาพหน้าสัมผัส (Gold Finger)**: แรมที่ไม่มีรอยไหม้ คราบไหม้ หรือลายวงจรลอก จะประเมินราคาง่ายและได้ราคาเต็มตามสภาพ

หากต้องการส่งแรมประเมินราคา สามารถดูรายละเอียดบริการเพิ่มเติมได้ที่หน้าบริการ [รับซื้อแรม](/บริการ/รับซื้อแรม) เพื่อตรวจสอบขั้นตอนการประเมิน

## DDR รุ่นใดมีมูลค่าและเป็นที่ต้องการในตลาด

การประเมินราคา RAM มือสองจะแบ่งตามยุคของเทคโนโลยีดังนี้

### DDR5 RAM
แรมยุคใหม่ล่าสุดสำหรับแพลตฟอร์ม Intel Gen 12+ และ AMD Ryzen 7000+ มีความเร็วสูงตั้งแต่ 4800MHz ถึง 7200MHz+ เป็นกลุ่มที่มีราคาสูงที่สุดในตลาดมือสอง หากเป็น Kit 32GB (16GBx2) หรือ 64GB (32GBx2) บัสสูง จะยิ่งเป็นที่ต้องการอย่างมาก

### DDR4 RAM
รุ่นยอดนิยมที่สุดในปัจจุบันที่ใช้กันแพร่หลาย แรม DDR4 บัส 2666MHz, 3200MHz และ 3600MHz ยังคงขายได้ง่ายและรวดเร็ว โดยความจุ 8GB และ 16GB ต่อแถวถือเป็นมาตรฐานหลักของตลาด

### DDR3 / DDR3L RAM
แม้จะเป็นเทคโนโลยียุคเก่า แต่ DDR3 (PC) และ DDR3L (สำหรับโน๊ตบุ๊คประหยัดพลังงาน) ความจุ 4GB และ 8GB ยังขายได้สำหรับคนที่ต้องการอัปเกรดคอมพิวเตอร์สำนักงานหรือโน๊ตบุ๊ครุ่นเก่า

### SO-DIMM (แรมโน๊ตบุ๊คและ Mini PC)
แรมขนาดเล็กสำหรับ Laptop, Mac mini รุ่นเก่า หรือ Mini PC มีราคาและปัจจัยการประเมินคล้ายแรม Desktop โดย DDR4 และ DDR5 SO-DIMM ยังเป็นที่ต้องการสูง

## แรมคู่ (Kit) กับ แรมเดี่ยว (Single Stick) ขายต่างกันอย่างไร

ในการซื้อขายแรมมือสอง รูปแบบการจับคู่ส่งผลต่อการประเมินราคาอย่างมีนัยสำคัญ

- **Matched Kit (2 แถว หรือ 4 แถว จากโรงงาน)**: แรมที่มาเป็นแพ็กคู่ เช่น 16GB Kit (8GBx2) หรือ 32GB Kit (16GBx2) ที่มี Part Number เดียวกัน ผลิตจาก Lot เดียวกัน และผ่านการทดสอบ Dual Channel จากโรงงาน จะได้ราคาดีกว่าการขายแรมเดี่ยวแยกชิ้น
- **Single Stick (แรมแถวเดียว)**: สามารถขายได้ตามปกติ แต่หากผู้ขายมีแรมแถวเดียว 2 ตัวที่เป็นรุ่นเดียวกัน แนะนำให้แจ้งร้านค้าว่ามีเป็นคู่ เพื่อให้ประเมินราคารวมได้เหมาะสมยิ่งขึ้น

## Server RAM และ ECC RAM ขายได้ไหม

แรมเซิร์ฟเวอร์เป็นกลุ่มเฉพาะทางที่ผู้ขายหลายคนสงสัยว่าขายได้หรือไม่ คำตอบคือ **ขายได้** แต่ต้องดูประเภทของแรมให้ชัดเจน

- **ECC Unbuffered (UDIMM)**: แรมที่มีระบบตรวจจับข้อผิดพลาด แต่ไม่มี Register Chip สามารถใช้กับเมนบอร์ดบางรุ่นได้
- **ECC Registered (RDIMM / LRDIMM)**: แรมสำหรับ Server และ Workstation โดยเฉพาะ ไม่สามารถนำไปใส่ในคอมพิวเตอร์บ้านทั่วไปได้

ราคาของ Server RAM ขึ้นอยู่กับความต้องการของตลาดองค์กรและศูนย์ข้อมูล (Data Center) หากคุณมี Server RAM ปริมาณมากจากการปลดระเบียบอุปกรณ์ไอทีบริษัท สามารถส่งรูป Part Number มาตรวจเช็กได้ที่ [รับซื้ออุปกรณ์คอมพิวเตอร์](/บริการ/รับซื้ออุปกรณ์คอมพิวเตอร์) หรือดูหน้ารับซื้อชิ้นส่วนคอมพิวเตอร์ประกอบที่ [รับซื้อ RAM และ SSD](/บริการ/รับซื้อ-ram-ssd)

## สิ่งที่ต้องทดสอบและเช็กสภาพก่อนนำแรมมาขาย

เพื่อให้การประเมินราคาแม่นยำและไม่เสียเวลาทั้งสองฝ่าย ผู้ขายควรรู้จุดตรวจเบื้องต้นดังนี้

1. **BIOS & Windows Detect Complete**: เครื่องมองเห็นความจุ RAM ครบถ้วนตามสเปกหรือไม่ (เช่น ใส่ 16GB ต้องเห็น 16GB ไม่ใช่เห็นแค่ 8GB)
2. **ความเสถียร (Stability)**: เปิดเครื่องติด เข้า Windows ได้ปกติ ไม่มีอาการจอฟ้า (BSOD) รหัส `MEMORY_MANAGEMENT`
3. **สภาพพินทองเหลือง**: ไม่มีคราบออกไซด์ดำ รอยขูดขีดรุนแรง หรือรอยไหม้บริเวณขาพิน
4. **ตัวซิงค์ระบายความร้อน**: ไม่หลุด ไม่หลวม และสติกเกอร์ Part Number / Serial Number ไม่ถูกลบหรือฉีกขาด

หากคุณมีคอมพิวเตอร์ทั้งเครื่องที่ต้องการขายร่วมกับแรม สามารถอ่านวิธีตรวจเช็กสเปกคอมพิวเตอร์เพิ่มเติมได้ที่บทความ [วิธีเช็กสเปกคอมก่อนขาย](/blog/วิธีเช็กสเปกคอมก่อนขาย)

## ไม่มีกล่องหรือหมดประกันแล้ว ยังขายได้หรือไม่

หลายคนกังวลว่าหากไม่มีกล่องเดิม หรือใบเสร็จหาย จะทำให้ขายแรมไม่ได้ คำตอบคือ **ขายได้ตามปกติ**

- **ไม่มีกล่องเดิม**: ร้านรับซื้อสามารถจัดเก็บในซอง Anti-Static หรือกล่องพลาสติกสำหรับใส่แรมได้ จึงไม่เป็นอุปสรรคในการขาย
- **หมดประกันแล้ว / ประกันนอก**: แรมที่หมดประกันศูนย์ไทยยังคงมีมูลค่าตามสภาพและการใช้งาน เพียงแต่แรมที่มีประกันศูนย์ไทยเหลืออยู่จะมีราคาสูงกว่าเล็กน้อย

หากมีชิ้นส่วนอื่นอย่าง SSD ที่ต้องการขายพร้อมกัน สามารถศึกษาข้อมูลสภาพ SSD ได้ที่บทความ [SSD สุขภาพเหลือน้อย เขียนข้อมูลเยอะ ขายได้ไหม](/blog/ssd-สุขภาพเหลือน้อย-เขียนข้อมูลเยอะ-ขายได้ไหม)

## วิธีถ่ายรูป Part Number ส่งประเมินราคาให้ได้ราคาเร็ว

ขั้นตอนที่สำคัญที่สุดในการขายแรมมือสองคือการถ่ายรูปข้อมูลสติกเกอร์บนตัวแรมให้ชัดเจน โดยถ่ายดังนี้

1. **ถ่ายสติกเกอร์ Part Number**: ควรถ่ายโฟกัสข้อความบนสติกเกอร์ เช่น `CMK16GX4M2B3200C16` หรือ `HX432C16FB3/8` ให้เห็นรหัสชัดเจน
2. **ถ่ายหน้าสัมผัสพินทองเหลือง**: ทั้งสองด้าน เพื่อยืนยันว่าไม่มีรอยไหม้
3. **ถ่ายรูปคู่ (ถ้ามีเป็น Kit)**: ให้เห็นสติกเกอร์ของแรมทั้งสองแถวพร้อมกัน
4. **ถ่ายรูปหน้าจอ BIOS หรือ CPU-Z (ถ้าทำได้)**: ในหน้า Memory และ SPD เพื่อยืนยันบอร์ดและค่า Bus
