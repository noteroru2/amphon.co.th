## สเปก Mac mini M4 และ M4 Pro

Mac mini รุ่นปี 2024 มีขนาดกว้างและลึกประมาณ **12.7 ซม.** สูงประมาณ **5 ซม.** รุ่น M4 หนักประมาณ 0.67 กก. และรุ่น M4 Pro หนักประมาณ 0.73 กก. ด้านหน้ามีพอร์ต USB-C จำนวน 2 พอร์ตและช่องหูฟัง 3.5 มม. ส่วนด้านหลังจะแตกต่างกันระหว่างรุ่น M4 กับ M4 Pro

ตารางนี้สรุปคอนฟิกจากโรงงานของ Mac mini รุ่นปี 2024 ตามข้อมูลทางเทคนิคของ Apple:

| รายการ | Mac mini M4 | Mac mini M4 Pro |
|---|---|---|
| CPU / GPU มาตรฐาน | CPU 10-core / GPU 10-core | CPU 12-core / GPU 16-core |
| ตัวเลือกชิปเพิ่มเติม | ไม่มีตัวเลือกจำนวนคอร์อื่นในรุ่น M4 | CPU 14-core / GPU 20-core |
| Unified Memory มาตรฐาน | 16GB | 24GB |
| ตัวเลือก Unified Memory | 24GB หรือ 32GB | 48GB หรือ 64GB |
| SSD มาตรฐาน | 256GB | 512GB |
| ตัวเลือก SSD | 512GB, 1TB หรือ 2TB | 1TB, 2TB, 4TB หรือ 8TB |
| พอร์ตด้านหลัง | Thunderbolt 4 จำนวน 3 พอร์ต | Thunderbolt 5 จำนวน 3 พอร์ต |
| ความเร็ว Thunderbolt สูงสุดตามสเปก | 40Gb/s | 120Gb/s |
| Ethernet | Gigabit Ethernet หรือสั่ง 10Gb Ethernet | Gigabit Ethernet หรือสั่ง 10Gb Ethernet |
| HDMI | มี | มี |
| Wi‑Fi / Bluetooth | Wi‑Fi 6E / Bluetooth 5.3 | Wi‑Fi 6E / Bluetooth 5.3 |

ตัวเลือกคอนฟิกที่ยังมีจำหน่ายในแต่ละช่วงเวลาอาจเปลี่ยนได้ แต่ตลาดมือสองสามารถพบเครื่อง CTO หรือ Build-to-Order ที่เคยสั่งจากโรงงานได้หลายแบบ ดังนั้นควรตรวจสเปกจากตัวเครื่องจริง ไม่ควรเดาจากกล่อง สี หรือปีที่ซื้อเพียงอย่างเดียว

### Mac mini M4 เหมาะกับใคร

รุ่น M4 มักตอบโจทย์งานทั่วไป งานสำนักงาน ตัดต่อภาพและวิดีโอระดับหนึ่ง งานพัฒนาเว็บไซต์ และการใช้งานหลายจอ โดยราคามือสองจะต่างกันมากระหว่างเครื่อง 16GB/256GB กับเครื่องที่สั่ง Unified Memory หรือ SSD สูงขึ้น

### Mac mini M4 Pro เหมาะกับใคร

รุ่น M4 Pro มี CPU/GPU สูงกว่า มีแบนด์วิดท์หน่วยความจำมากกว่า และใช้ Thunderbolt 5 จึงมักอยู่ในกลุ่มผู้ใช้งานที่ต้องเชื่อมต่อ Storage ความเร็วสูง จอหลายตัว หรืองานประมวลผลหนัก อย่างไรก็ตาม คำว่า “M4 Pro” อย่างเดียวยังไม่พอ ต้องดูว่าเป็น CPU/GPU รุ่นมาตรฐานหรือรุ่น 14-core/20-core รวมถึง Memory และ SSD ด้วย

## ราคา Mac mini M4 มือสองขึ้นอยู่กับอะไร

ไม่แนะนำให้ใช้ตารางราคาตายตัวเป็นเนื้อหาหลัก เพราะราคาสินค้ามือสองเปลี่ยนตามราคาของใหม่ โปรโมชั่น สินค้าในตลาด ประกัน และความต้องการ ณ วันที่ประเมิน ปัจจัยสำคัญมีดังนี้

### 1. รุ่นชิปและจำนวนคอร์

Mac mini M4 Pro มีราคาตั้งต้นและกลุ่มผู้ใช้ต่างจาก M4 แต่ภายใน M4 Pro ยังมีทั้ง CPU 12-core/GPU 16-core และตัวเลือก CPU 14-core/GPU 20-core ผู้ขายจึงควรถ่ายหน้า About This Mac และ System Information ให้เห็นข้อมูลชัดเจน

### 2. Unified Memory

Unified Memory เป็นส่วนหนึ่งของสถาปัตยกรรม Apple Silicon และไม่ได้ออกแบบให้ผู้ใช้เพิ่มภายหลังเหมือน RAM แบบแถวในคอมพิวเตอร์ทั่วไป คอนฟิก 24GB, 32GB, 48GB หรือ 64GB จึงเป็นข้อมูลสำคัญในการประเมิน

เครื่อง Memory สูงอาจมีมูลค่ารวมมากกว่า แต่ไม่ได้หมายความว่าส่วนต่างราคามือสองจะเท่ากับส่วนต่างตอนสั่งซื้อใหม่เสมอ ต้องดูว่าตลาดในวันนั้นต้องการคอนฟิกดังกล่าวมากน้อยเพียงใด

หากต้องการเข้าใจความต่างระหว่าง RAM แบบถอดเปลี่ยนได้กับ Unified Memory สามารถอ่าน [แรมมือสองขายได้เท่าไหร่](/blog/แรมมือสองขายได้เท่าไหร่) เพิ่มเติมได้

### 3. ความจุ SSD

ความจุ 256GB, 512GB, 1TB หรือสูงกว่ามีผลต่อราคาขายต่อ เพราะผู้ใช้จำนวนมากต้องการพื้นที่ภายในเครื่องที่เพียงพอสำหรับแอปและงานประจำ

สำหรับการซื้อขาย ควรถือความจุที่ macOS รายงานเป็นคอนฟิกประจำเครื่อง ไม่ควรรับรองการดัดแปลงหรือการเปลี่ยน Storage ภายนอกระบบของ Apple ว่าเทียบเท่าคอนฟิกจากโรงงาน หากเครื่องเคยซ่อมหรือดัดแปลง ควรแจ้งประวัติตามจริง

### 4. Ethernet 1Gb หรือ 10Gb

Mac mini M4 และ M4 Pro สามารถสั่ง 10Gb Ethernet จากโรงงานได้ รุ่นนี้อาจมีมูลค่าเพิ่มสำหรับผู้ใช้ NAS, Server หรือเครือข่ายความเร็วสูง แต่ต้องตรวจจากข้อมูลระบบหรือทดสอบกับอุปกรณ์ที่รองรับ ไม่ควรดูจากหัวต่อ RJ‑45 เพียงอย่างเดียว เพราะลักษณะพอร์ตภายนอกใกล้เคียงกัน

### 5. ประกันและ AppleCare

เครื่องที่ยังมีประกันจำกัดของ Apple หรือแผน AppleCare อาจสร้างความมั่นใจให้ผู้ซื้อ แต่ควรตรวจวันหมดอายุและเงื่อนไขจริงจากหน้า AppleCare และการรับประกัน หรือช่องทางตรวจสอบความคุ้มครองของ Apple

อย่าสรุปว่าแผน AppleCare ทุกประเภทสามารถโอนไปเจ้าของใหม่ได้โดยอัตโนมัติ ควรตรวจเงื่อนไขของแผนและประเทศที่ซื้ออีกครั้ง

### 6. สภาพตัวเครื่องและพอร์ต

ควรตรวจ:

- รอยบุบหรือรอยตกบริเวณขอบ
- รอยขีดข่วนลึก
- คราบน้ำหรือคราบออกซิเดชัน
- พอร์ตหลวมหรือเสียบไม่แน่น
- ฐานเครื่องและปุ่มเปิด/ปิด
- เสียงพัดลมผิดปกติ
- กลิ่นไหม้หรือความร้อนผิดปกติ
- ร่องรอยการแกะหรือซ่อม

### 7. อุปกรณ์และกล่อง

อุปกรณ์มาตรฐานในกล่องของ Mac mini รุ่นนี้คือ **ตัวเครื่องและสายไฟ** ไม่ได้มีคีย์บอร์ด เมาส์ หรือจอภาพมาเป็นอุปกรณ์มาตรฐาน ดังนั้นการไม่มี Magic Keyboard หรือ Magic Mouse ไม่ควรถูกนับว่าอุปกรณ์เดิมขาด เว้นแต่ผู้ขายตกลงขายรวมเป็นชุด

กล่องเดิมและสายไฟช่วยให้จัดเก็บและขายต่อสะดวกขึ้น แต่ไม่ใช่เงื่อนไขว่าต้องมีจึงจะขายได้

### 8. Activation Lock, MDM และสิทธิ์ความเป็นเจ้าของ

เครื่องที่ยังติดบัญชี Apple ของเจ้าของเดิม ติด Find My ติด Activation Lock หรืออยู่ภายใต้การจัดการขององค์กร จะมีความเสี่ยงสูงและอาจไม่สามารถส่งมอบให้เจ้าของใหม่ใช้งานได้ตามปกติ

## วิธีดูสเปก Mac mini M4 ให้ถูกก่อนประเมิน

### ดูจาก About This Mac

ไปที่เมนู Apple  แล้วเลือก **เกี่ยวกับ Mac เครื่องนี้** เพื่อดู:

- ชื่อรุ่น
- ชิป
- Unified Memory
- Serial Number
- เวอร์ชัน macOS

ควรถ่ายภาพหน้าจอส่วนนี้ แต่หากจะโพสต์ในที่สาธารณะให้ปิดบัง Serial Number บางส่วน

### ดูความจุ Storage

ไปที่:

`การตั้งค่าระบบ > ทั่วไป > พื้นที่จัดเก็บข้อมูล`

ตรวจว่าความจุที่ระบบรายงานตรงกับข้อมูลที่ผู้ขายแจ้งหรือไม่

### ดูรายละเอียดเพิ่มเติมจาก System Information

กดปุ่ม Option ค้างไว้ แล้วคลิกเมนู Apple  จากนั้นเลือก **ข้อมูลระบบ (System Information)** เพื่อตรวจข้อมูล Hardware, Thunderbolt/USB, Network และอุปกรณ์ที่เชื่อมต่อ

### ตรวจประกัน

ไปที่:

`การตั้งค่าระบบ > ทั่วไป > AppleCare และการรับประกัน`

หรือใช้บริการตรวจสอบความคุ้มครองของ Apple โดยใช้ Serial Number ผ่านช่องทางส่วนตัว

## เช็กลิสต์ตรวจ Mac mini M4 มือสองก่อนซื้อหรือขาย

การตรวจควรทำกับจอ คีย์บอร์ด เมาส์ และสายเชื่อมต่อที่ทราบว่าใช้งานได้ปกติ เพื่อลดความสับสนว่าอาการเกิดจากตัว Mac หรืออุปกรณ์ภายนอก

### 1. การเปิดเครื่องและ Boot

ตรวจว่า:

- กดเปิดแล้วเครื่องตอบสนอง
- Boot เข้า macOS ได้
- ไม่มีหน้าจอ Error หรือ Restart วน
- ไม่ดับเอง
- ไม่มีเสียงพัดลมหรือเสียงภายในผิดปกติ
- Sleep และ Wake กลับมาใช้งานได้

### 2. ตรวจชิป Memory และ Storage

เปรียบเทียบข้อมูลใน About This Mac กับข้อมูลที่ประกาศขาย ได้แก่:

- M4 หรือ M4 Pro
- จำนวนคอร์ หากเป็น M4 Pro รุ่นอัปเกรด
- Unified Memory
- ความจุ SSD
- เวอร์ชัน macOS

### 3. พอร์ต USB-C ด้านหน้า

ทดสอบทั้งสองช่องด้วยอุปกรณ์ที่ทราบว่าใช้งานได้ เช่น External SSD, Flash Drive หรืออุปกรณ์ USB-C และตรวจว่าระบบมองเห็นอุปกรณ์อย่างสม่ำเสมอ

### 4. Thunderbolt ด้านหลัง

Mac mini M4 ใช้ Thunderbolt 4 ส่วน M4 Pro ใช้ Thunderbolt 5 ควรทดสอบอย่างน้อย:

- การต่อจอ
- การอ่านเขียน External Storage
- การเชื่อมต่อ Hub หรือ Dock
- ความแน่นของพอร์ต

การทดสอบอุปกรณ์ทั่วไปยืนยันได้ว่าพอร์ตทำงาน แต่ไม่จำเป็นต้องพิสูจน์ความเร็วสูงสุด 40Gb/s หรือ 120Gb/s ทุกครั้ง หากไม่มีอุปกรณ์และสายที่รองรับ

### 5. HDMI

ต่อจอผ่าน HDMI และตรวจ:

- ภาพ
- เสียงผ่าน HDMI
- ความเสถียรเมื่อ Sleep/Wake
- ไม่มีภาพกระพริบจากพอร์ต

ปัญหาภาพกระพริบอาจเกิดจากสาย จอ การตั้งค่าความละเอียด หรือพอร์ต จึงควรเปลี่ยนสายหรือจอเพื่อแยกสาเหตุก่อนสรุปว่าเครื่องเสีย

### 6. Ethernet

เสียบสาย LAN และตรวจการเชื่อมต่อ หากผู้ขายระบุว่าเป็นรุ่น 10Gb Ethernet ควรตรวจข้อมูล Hardware และทดสอบกับ Network Adapter, Switch และสายที่รองรับเมื่อจำเป็น

### 7. Wi‑Fi และ Bluetooth

เชื่อมต่อ Wi‑Fi และทดลองใช้งานอินเทอร์เน็ต จากนั้นทดสอบ Bluetooth กับคีย์บอร์ด เมาส์ หรือหูฟัง ตรวจว่าไม่มีอาการหลุดผิดปกติในระยะใช้งานทั่วไป

### 8. ช่องหูฟังและลำโพงในตัว

ทดลองช่องหูฟัง 3.5 มม. และลำโพงในตัว ตรวจเสียงแตก เสียงหาย หรือการสลับอุปกรณ์เสียงผิดปกติ

### 9. การต่อจอภาพ

Mac mini รุ่นนี้รองรับจอหลายตัว แต่การทดสอบก่อนซื้อไม่จำเป็นต้องต่อครบจำนวนสูงสุดทุกครั้ง อย่างน้อยควรทดสอบ:

- HDMI หนึ่งจอ
- USB-C/Thunderbolt หนึ่งจอเมื่อมีอุปกรณ์
- ความละเอียดและ Refresh Rate ที่ผู้ซื้อจำเป็นต้องใช้

### 10. อุณหภูมิและพัดลม

เปิดใช้งานทั่วไปและทดลองงานที่มีภาระระดับหนึ่ง ตรวจว่าเครื่องไม่ดับ ไม่ค้าง ไม่มีเสียงพัดลมเสียดสี และไม่มีความร้อนผิดปกติจนกระทบการทำงาน

ไม่ควรสรุปว่าเครื่องมีปัญหาเพียงเพราะตัวเครื่องอุ่น เพราะอุณหภูมิขึ้นกับงาน อุณหภูมิห้อง และการระบายอากาศ ควรดูอาการร่วมกับความเสถียร

## Activation Lock และบัญชี Apple ต่างจากรหัสเข้าเครื่องอย่างไร

รหัสผ่านผู้ใช้ macOS กับ Activation Lock เป็นคนละเรื่องกัน

- **รหัสเข้าเครื่อง** ใช้เข้าสู่บัญชีผู้ใช้ใน macOS
- **Activation Lock** เชื่อมโยงกับ Find My และบัญชี Apple ของเจ้าของ
- การลบ User Account อย่างเดียวไม่ได้ยืนยันว่า Activation Lock ถูกนำออกแล้ว

### วิธีเตรียมเครื่องก่อนขาย

ควรสำรองข้อมูลก่อน แล้วจึงใช้:

`การตั้งค่าระบบ > ทั่วไป > ถ่ายโอนหรือรีเซ็ต > ลบข้อมูลและการตั้งค่าทั้งหมด`

ฟังก์ชัน Erase All Content and Settings จะเปิดผู้ช่วยลบข้อมูล ซึ่งอาจขอรหัสผู้ดูแลระบบและรหัสผ่านบัญชี Apple เพื่อออกจากบริการและลบข้อมูลอย่างปลอดภัย

หลังลบเสร็จ หากกำลังขายหรือส่งมอบให้ผู้อื่น ไม่ควรตั้งค่าเครื่องต่อด้วยบัญชีของผู้ขาย ให้หยุดที่หน้าผู้ช่วยตั้งค่า แล้วปิดเครื่องตามคำแนะนำของ Apple

### คนซื้อควรตรวจอย่างไร

หลังตกลงซื้อขายแล้ว ควรให้ผู้ขายลบเครื่องและเชื่อมต่ออินเทอร์เน็ตในขั้นตอนตั้งค่า เพื่อดูว่า:

- ไม่ขอรหัสบัญชี Apple ของเจ้าของเดิม
- ไม่แสดง Activation Lock ที่ผู้ขายปลดไม่ได้
- สามารถเข้าสู่ Setup Assistant ตามปกติ
- ไม่ปรากฏหน้าจอ Remote Management ขององค์กรโดยไม่คาดหมาย

ไม่ควรรับเครื่องที่ผู้ขายอ้างว่าจะส่งรหัสบัญชี Apple ให้ภายหลัง หรือขอให้ผู้ซื้อใช้วิธีข้าม Activation Lock

## MDM และ Remote Management คืออะไร

MDM หรือ Device Management ใช้จัดการเครื่องของบริษัท โรงเรียน หรือองค์กร ส่วน Automated Device Enrollment สามารถทำให้ Mac ลงทะเบียนเข้าระบบจัดการโดยอัตโนมัติระหว่าง Setup Assistant

สิ่งสำคัญคือ **การล้างเครื่องไม่ได้รับประกันว่าจะลบการผูกกับองค์กร** หาก Serial Number ยังอยู่ใน Apple School Manager, Apple Business หรือระบบจัดการขององค์กร หน้าจอ Remote Management อาจกลับมาเมื่อเครื่องเชื่อมต่ออินเทอร์เน็ตและเริ่มตั้งค่าใหม่

### วิธีตรวจเครื่ององค์กรก่อนซื้อ

1. ขอหลักฐานที่มาของเครื่อง
2. ตรวจว่ามี Profile หรือ Device Management ใน System Settings หรือไม่
3. หลังตกลงแล้ว ให้ลบเครื่องอย่างถูกต้อง
4. เชื่อมต่ออินเทอร์เน็ตระหว่าง Setup Assistant
5. ตรวจว่าไม่มีหน้าจอ Remote Management บังคับให้ลงทะเบียน
6. หากพบ ให้เจ้าขององค์กรหรือฝ่าย IT ปลดและ Release เครื่องอย่างถูกต้องก่อนซื้อ

ผู้ขายทั่วไปไม่ควรรับรองว่า “ล้างแล้ว MDM หายแน่นอน” และผู้ซื้อไม่ควรพึ่งวิธี Bypass เพราะเครื่องอาจกลับมาติดการจัดการอีกหลังอัปเดตหรือล้างใหม่

### Activation Lock กับ MDM ไม่ใช่เรื่องเดียวกัน

เครื่องหนึ่งอาจ:

- ติด Activation Lock อย่างเดียว
- ติด MDM อย่างเดียว
- ติดทั้งสองระบบ
- ไม่ติดทั้งสองระบบ

จึงควรตรวจทั้งบัญชี Apple และ Remote Management แยกกัน

<span id="faq"></span>

## คำถามที่พบบ่อย

### Mac mini M4 ไม่มีกล่องขายได้ไหม

ขายได้ในหลายกรณี กล่องช่วยให้จัดเก็บและขายต่อสะดวก แต่ปัจจัยหลักคือชิป Unified Memory SSD สภาพ ประกัน และสถานะบัญชี

### ไม่มี Magic Keyboard หรือ Magic Mouse ถือว่าอุปกรณ์ไม่ครบไหม

ไม่ถือว่าขาดจากชุดมาตรฐาน เพราะภายในกล่อง Mac mini มีตัวเครื่องและสายไฟ คีย์บอร์ด เมาส์ และจอภาพเป็นอุปกรณ์ที่ซื้อแยก เว้นแต่ประกาศขายระบุว่าจะรวมอุปกรณ์เหล่านั้นด้วย

### Mac mini M4 เพิ่ม RAM ภายหลังได้ไหม

Unified Memory ไม่ได้ออกแบบให้ผู้ใช้เพิ่มหรือเปลี่ยนภายหลังแบบ RAM ของพีซี ควรเลือกและประเมินตามคอนฟิกที่มากับเครื่อง

### Mac mini M4 เพิ่ม SSD ภายหลังได้ไหม

Mac mini ไม่มีช่องอัปเกรด Storage สำหรับผู้ใช้ทั่วไปแบบคอมประกอบ ควรประเมินตามความจุที่ระบบรายงาน หากเครื่องเคยดัดแปลงหรือซ่อม Storage ควรแจ้งประวัติและตรวจความเสถียรเป็นพิเศษ

### M4 Pro ทุกเครื่องมี CPU 14-core และ GPU 20-core หรือไม่

ไม่ใช่ รุ่นมาตรฐานใช้ CPU 12-core และ GPU 16-core ส่วน CPU 14-core/GPU 20-core เป็นตัวเลือกคอนฟิกเพิ่มเติม จึงต้องตรวจจากข้อมูลเครื่องจริง

### Mac mini M4 ใช้ Thunderbolt รุ่นใด

รุ่น M4 ใช้ Thunderbolt 4 จำนวน 3 พอร์ตด้านหลัง ส่วน M4 Pro ใช้ Thunderbolt 5 จำนวน 3 พอร์ต ด้านหน้าของทั้งสองรุ่นเป็น USB-C ที่รองรับ USB 3 สูงสุด 10Gb/s

### ตรวจ MDM โดยไม่ล้างเครื่องได้ไหม

สามารถตรวจ Profile หรือ Device Management ที่ปรากฏในระบบได้เบื้องต้น แต่ Automated Device Enrollment บางกรณีจะเห็นชัดระหว่าง Setup Assistant หลังลบเครื่องและเชื่อมต่ออินเทอร์เน็ต การตรวจให้มั่นใจจึงควรทำร่วมกับผู้ขายหลังตกลงซื้อขาย

### ล้างเครื่องแล้ว MDM จะหายไหม

ไม่เสมอ หากเครื่องยังผูกกับ Apple School Manager, Apple Business หรือระบบจัดการขององค์กร Remote Management อาจกลับมาหลังเชื่อมต่ออินเทอร์เน็ต เจ้าขององค์กรต้องปลดหรือ Release เครื่องอย่างถูกต้อง

### ต้องออกจากบัญชี Apple ก่อนให้ร้านตรวจไหม

ยังไม่ควรลบข้อมูลก่อนเก็บหลักฐานสเปกและทดสอบเครื่อง แต่ควรมั่นใจว่าสามารถออกจากบัญชี Apple และปิด Find My ได้ เมื่อตกลงขายแล้วผู้ขายควรดำเนินการเองต่อหน้า หรือทำตามขั้นตอนที่ตกลง

### Apple Diagnostics ตรวจได้ครบทุกอย่างไหม

ไม่ครบทุกอย่าง Apple Diagnostics ช่วยตรวจปัญหาฮาร์ดแวร์บางส่วน แต่ยังควรทดสอบพอร์ต Wi‑Fi Bluetooth Ethernet HDMI เสียง การต่อจอ และการใช้งานจริงแยกต่างหาก

### ใช้เวลาประเมินราคานานเท่าไหร่

ขึ้นอยู่กับความครบถ้วนของข้อมูลและคอนฟิก หากส่ง About This Mac, Storage, รูปสภาพ ประกัน และอุปกรณ์ครบ จะตรวจสอบได้ง่ายกว่าการส่งเพียงรูปตัวเครื่อง แต่ไม่ควรกำหนดเวลาตายตัวสำหรับทุกรายการ
