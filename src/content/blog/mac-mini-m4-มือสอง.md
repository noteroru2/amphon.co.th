## ทำไม Mac mini M4 ถึงเป็นรุ่นยอดนิยมในตลาดมือสอง

Apple ได้เปิดตัว Mac mini M4 โดยปรับเปลี่ยนดีไซน์ใหม่หมดเป็นครั้งแรกในรอบสิบปี ให้มีขนาดเล็กลงเหลือเพียง 5x5 นิ้ว มีการย้ายพอร์ตเชื่อมต่อมาไว้ด้านหน้าตัวเครื่องเพื่อความสะดวก และอัปเกรดชิปประมวลผลเป็น Apple M4 และ M4 Pro ที่รองรับระบบ Apple Intelligence

ด้วยจุดเด่นเรื่องสเปกเริ่มต้นที่ให้ RAM (Unified Memory) มาถึง 16GB เป็นมาตรฐาน และประสิทธิภาพต่อราคาที่คุ้มค่า ทำให้ Mac mini M4 กลายเป็นเครื่องที่ซื้อง่ายขายคล่อง มีสภาพคล่องในตลาดมือสองสูงมาก ไม่ว่าจะเป็นรุ่นชิป M4 มาตรฐานสำหรับงานทั่วไป หรือรุ่น M4 Pro สำหรับงานตัดต่อวิดีโอ 8K และงานโปรแกรมมิ่ง

## รุ่นและสเปกหลักของ Mac mini M4

ก่อนที่จะประเมินราคาขายหรือซื้อขาย Mac mini M4 มือสอง ผู้ขายและผู้ซื้อควรทำความเข้าใจคอนฟิกูเรชันสเปกที่มาจากโรงงานของ Apple ดังนี้

### 1. รุ่นชิป Apple M4
- **CPU / GPU**: 10-core CPU (4 Performance / 6 Efficiency) และ 10-core GPU
- **Unified Memory**: เริ่มต้น 16GB, สามารถเพิ่มเป็น 24GB หรือ 32GB
- **Storage (SSD)**: เริ่มต้น 256GB, 512GB, 1TB หรือ 2TB
- **พอร์ตเชื่อมต่อ**: ด้านหน้ามี 2x USB-C (USB 3) และช่องต่อหูฟัง 3.5mm / ด้านหลังมี 3x Thunderbolt 4, HDMI และ Gigabit Ethernet (ตัวเลือก 10Gb Ethernet)

### 2. รุ่นชิป Apple M4 Pro
- **CPU / GPU**: 12-core CPU / 16-core GPU หรือ 14-core CPU / 20-core GPU
- **Unified Memory**: เริ่มต้น 24GB, สามารถอัปเกรดเป็น 48GB หรือ 64GB
- **Storage (SSD)**: เริ่มต้น 512GB, 1TB, 2TB, 4TB หรือ 8TB
- **พอร์ตเชื่อมต่อ**: ด้านหน้ามี 2x USB-C / ด้านหลังมี 3x **Thunderbolt 5** (ส่งถ่ายข้อมูลสูงสุด 120Gbps), HDMI และ Ethernet

## ราคามือสองขึ้นอยู่กับปัจจัยอะไรบ้าง

ราคาขายต่อของ Mac mini M4 ในตลาดมือสองถูกประเมินจากหลายองค์ประกอบด้วยกัน ได้แก่

1. **รุ่นชิปประมวลผล (M4 vs M4 Pro)**: รุ่น M4 Pro จะมีฐานราคาสูงกว่าอย่างชัดเจนจากความต้องการของกลุ่มผู้ใช้งานระดับโปร
2. **ขนาด Unified Memory (RAM)**: เนื่องจาก Mac mini M4 ไม่สามารถถอดอัปเกรด RAM ภายหลังได้ เครื่องที่มี RAM 24GB, 32GB หรือ 64GB จะรักษามูลค่าได้ดีกว่ารุ่น 16GB
3. **ความจุ SSD**: เครื่องความจุ 512GB ขึ้นไปได้รับความนิยมมากกว่ารุ่น 256GB
4. **ประกันศูนย์และ AppleCare+**: หากเครื่องยังมีประกัน AppleCare+ เหลืออยู่ โดยเฉพาะแบบต่ออายุรายปีหรือครอบคลุมอุบัติเหตุ จะเพิ่มมูลค่าและความซื้อง่ายขายคล่องอย่างมาก
5. **สภาพตัวเครื่องภายนอก**: ไม่มีรอยบุบ รอยตกกระแทก รอยขีดข่วนบนเคสอะลูมิเนียม หรือคราบสนิมบริเวณพอร์ตเชื่อมต่อ
6. **อุปกรณ์ครบกล่อง**: สายไฟพาวเวอร์แท้ (Power Cord) กล่องเดิมที่มี Serial Number ตรงกับเครื่อง และใบเสร็จรับเงิน (ถ้ามี)

หากคุณต้องการเช็กราคาส่งมอบเครื่อง Mac mini ทุกรุ่น สามารถดูรายละเอียดเพิ่มเติมได้ที่หน้าบริการ [รับซื้อ Mac mini](/บริการ/รับซื้อ-mac-mini) หรือหน้ารวมอุปกรณ์ Mac [รับซื้อ iMac และ Mac mini](/บริการ/รับซื้อ-imac-mac-mini)

## จุดที่ต้องตรวจเช็กสำหรับผู้ซื้อและผู้ขาย Mac mini M4 มือสอง

เพื่อให้แน่ใจว่า Mac mini M4 มือสองทำงานได้สมบูรณ์ 100% ควรทดสอบตามรายการเช็กลิสต์ต่อไปนี้

### 1. ระบบไฟและการเปิดติด (Power & Boot Test)
กดปุ่มเปิดเครื่องที่อยู่ใต้ฐานเครื่อง Mac mini M4 ตรวจดูว่าพัดลมหมุนเงียบ ไฟสถานะติด และระบบสามารถ Boot เข้าสู่หน้าสถิต macOS Setup Assistant หรือ Desktop ได้อย่างราบรื่น

### 2. พอร์ตเชื่อมต่อและสัญญาณ (Connectivity & Ports)
- ทดสอบเสียบพอร์ต USB-C ด้านหน้าทั้ง 2 ช่อง
- ทดสอบพอร์ต Thunderbolt 4 (หรือ Thunderbolt 5 ใน M4 Pro) ด้านหลังทั้ง 3 ช่อง
- ต่อสาย HDMI ออกจอภาพภายนอก ตรวจดูสัญญาณภาพและเสียง
- ทดสอบการเชื่อมต่อ Wi-Fi 6E และ Bluetooth 5.3
- ทดสอบพอร์ต Ethernet เสียบสาย LAN เพื่อยืนยันการรับส่งข้อมูล

### 3. ระบบระบายความร้อนและเสียงพัดลม (Thermals & Fan)
แม้ Mac mini M4 จะประหยัดพลังงานสูงมาก แต่ผู้ซื้อควรสังเกตว่าพัดลมระบายความร้อนหมุนด้วยเสียงปกติ ไม่มีความร้อนสะสมสูงผิดปกติขณะใช้งาน

### 4. การรัน Apple Diagnostics
กดเปิดเครื่องแล้วกดปุ่ม Power ค้างไว้จนขึ้นตัวเลือกตัวเลือก Boot จากนั้นกด `Command (⌘) + D` เพื่อรัน Apple Diagnostics ตรวจหาข้อผิดพลาดของฮาร์ดแวร์เบื้องต้น

## ข้อควรระวังเรื่อง Activation Lock และ Apple Account

จุดที่สำคัญที่สุดสำหรับการขาย Mac mini มือสอง คือการปลดล็อคเจ้าของเดิมออกให้หมด เพื่อไม่ให้เครื่องกลายเป็น "เครื่องติดล็อค" ที่ใช้งานต่อไม่ได้

1. **ออกจาก Apple Account (iCloud)**: เข้าไปที่ System Settings -> คลิกชื่อ Apple Account ด้านบน -> เลือก Sign Out
2. **ปิด Find My Mac**: ยืนยันว่าการค้นหา Mac ถูกปิดใช้งานเรียบร้อยแล้ว
3. **ล้างเครื่องด้วย Erase All Content and Settings**: เข้า System Settings -> General -> Transfer or Reset -> Erase All Content and Settings เพื่อลบข้อมูลและคืนค่าโรงงาน

หากต้องการศึกษาขั้นตอนการเตรียม Mac ก่อนขายอย่างละเอียด สามารถอ่านต่อได้ที่บทความ [วิธีล้างเครื่อง MacBook ก่อนขาย](/blog/วิธีล้างเครื่อง-macbook-ก่อนขาย) ซึ่งใช้หลักการลบข้อมูลของระบบ macOS เดียวกัน

## MDM (Mobile Device Management) ล็อคบริษัทคืออะไร

สำหรับ Mac mini M4 ที่มาจากองค์กรหรือบริษัท ผู้ขายและผู้ซื้อต้องตรวจสอบว่าตัวเครื่องไม่ได้ผูกอยู่กับระบบ **MDM (Mobile Device Management)** หรือ Apple Business Manager ของบริษัทเดิม

เครื่องที่ติด MDM แม้จะทำการ Erase Machine แล้ว เมื่อเชื่อมต่ออินเทอร์เน็ตในการตั้งค่าครั้งใหม่ ระบบจะขึ้นหน้าต่างให้กรอกรหัสพนักงานขององค์กร ทำให้ผู้ซื้อทั่วไปไม่สามารถใช้งานได้ หากเป็นเครื่องส่วนตัวที่ซื้อจาก Apple Store หรือตัวแทนจำหน่ายทั่วไป จะไม่มีปัญหานี้
