## คอมบริษัทเก่า ขายยังไง

เมื่อองค์กรเปลี่ยนเครื่องหรือปิดสาขาย่อย คอมตั้งโต๊ะและโน๊ตบุ๊คจำนวนมากควรถูกจัดการเป็นล็อต **อำพล เทรดดิ้ง** รับประเมินคอมองค์กรโดยดูรุ่น สเปก จำนวน สภาพ และนโยบายการลบข้อมูลของบริษัท

ราคาจากรายการ/รูปเป็นราคาเบื้องต้น ราคาสุดท้ายยืนยันหลังตรวจจริง และชำระเงินหลังผู้ขายยอมรับราคาสุดท้าย

### เตรียมข้อมูลล็อตก่อนติดต่อร้าน

- นับจำนวนเครื่องแยกประเภท (ตั้งโต๊ะ / โน๊ตบุ๊ค / จอ / อื่น ๆ)
- จดรุ่น CPU RAM สตอเรจโดยประมาณ หรือถ่ายป้ายสเปก
- ระบุเครื่องที่เปิดไม่ติดหรือมีตำหนิหนักแยกจากเครื่องใช้งานได้
- ยืนยันว่าใครมีอำนาจอนุมัติการจำหน่ายสินทรัพย์และนัดตรวจ

### ความปลอดภัยของข้อมูลองค์กร

ก่อนส่งมอบ ควรลบข้อมูลตามนโยบาย IT ของบริษัท เช่น Secure Erase หรือถอดไดรฟ์ที่เก็บข้อมูลสำคัญ หากต้องการให้ร้านช่วยประสานขั้นตอนหลังตกลงราคา ให้สอบถามก่อนนัด ไม่ควรส่งเครื่องที่ยังล็อกโดเมนหรือยังมีข้อมูลลูกค้าอยู่โดยไม่แจ้ง

### ลำดับงานที่มักใช้กับล็อตองค์กร

1. ส่งรายการและรูปตัวอย่างทาง Line [@webuy](https://line.me/ti/p/~@webuy) หรือโทร [064-257-9353](tel:+66642579353)
2. รับราคาประเมินเบื้องต้น
3. นัดสำรวจ/ตรวจหน้างานหรือนำตัวอย่างมาที่หน้าร้านอุบลตามความเหมาะสม
4. ยืนยันราคาสุดท้ายหลังตรวจ แล้วจึงส่งมอบและรับชำระเงินตามที่ตกลง

หน้าร้านอยู่ที่ **740/8 ถนนชยางกูร อุบลราชธานี** การนัดรับล็อตใหญ่ทำเป็นรายนัดตามจำนวนและพื้นที่ ไม่รับประกันเข้ารับทุกวันทุกจุด

### คำถามที่พบบ่อย

**คอมเปิดไม่ติดในล็อตรวมได้ไหม?**
ส่งแยกรายการอาการมาได้ ร้านประเมินตามชิ้นส่วนและสภาพจริง

**ต้องมีใบกำกับหรือเอกสารจำหน่ายสินทรัพย์ไหม?**
ขึ้นกับนโยบายองค์กร แนะนำให้เตรียมผู้มีอำนาจอนุมัติและเอกสารภายในให้พร้อมก่อนนัดส่งมอบ
