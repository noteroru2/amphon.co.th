## ล็อตแบบไหนส่งประเมินได้

### รุ่นเดียวกันหลายเครื่อง
ระบุสเปกหลัก จำนวน และแยกเครื่องที่สภาพต่างออกจากกลุ่ม

### ผสมหลายรุ่น
แบ่งตาม Brand/Model หรือ CPU Platform

### Desktop + Notebook
ส่งรายการเดียวได้ แต่แบ่งประเภทให้ชัด

### เครื่องดีปนเครื่องเสีย
ใช้สถานะ Working / Defect / No power / Untested

### เครื่องไม่มี Storage
แจ้งจำนวนที่ถอด SSD/HDD แล้ว

## Inventory List สำหรับคอมยกล็อต

- ลำดับ/กลุ่ม
- ประเภท
- Brand/Model
- CPU
- RAM
- SSD/HDD
- GPU
- สภาพ
- อุปกรณ์
- จำนวน
- หมายเหตุ

## อย่าใช้จำนวนเครื่องเป็นกฎตายตัว

การแบ่งว่า 5 เครื่องเป็นล็อตเล็ก 50 เครื่องเป็นล็อตใหญ่ หรือจำนวนใดต้องเข้าตรวจหน้างาน ไม่ใช่กฎที่ใช้ได้กับทุกกรณี วิธีดำเนินงานควรดูจำนวน ขนาด/น้ำหนัก มูลค่า ความหลากหลาย สภาพ พื้นที่ เวลาเข้าหน้างาน และเงื่อนไขขนย้ายร่วมกัน
