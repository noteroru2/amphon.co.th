## Socket Intel LGA, AMD AM4 และ AM5 ตรวจต่างกันอย่างไร

- **Intel LGA หลายรุ่น:** ตัว CPU มีจุดสัมผัสแบบแผ่น การงอของขามักเกี่ยวข้องกับ **ซ็อกเก็ตบนเมนบอร์ด** มากกว่าขาที่ตัว CPU ต้องตรวจรอยไหม้ ผิวสัมผัส ขอบ PCB และรอยกด
- **AMD AM4:** CPU จำนวนมากมี **ขาโลหะที่ตัว CPU** หากขางอ ขาหักหรือมีคราบติดขาต้องแจ้งพร้อมภาพใกล้ ไม่ควรดัดหรือแซะเอง
- **AMD AM5:** CPU มี **จุดสัมผัสแบบแผ่น** ส่วนขาเชื่อมต่ออยู่ในซ็อกเก็ตเมนบอร์ด จึงต้องตรวจหน้าสัมผัสและโครงส่วนขอบ ไม่ใช้เกณฑ์ “ขา AMD ต้องไม่งอ” เหมารวมทุกเจเนอเรชัน

ถ้าหน้าสัมผัสมีรอยไหม้ คราบกัดกร่อนหรือเศษโลหะ ให้หยุดทดลองต่อไฟและส่งรูปให้ช่างดูก่อนเพื่อหลีกเลี่ยงความเสียหายกับบอร์ดที่ใช้ทดสอบ

## ตรวจ CPU มือสอง 7 จุดที่เกี่ยวกับราคารับซื้อ

1. **รหัสรุ่นจริง:** ดูตัวอักษรบนกระดองและข้อมูลจากระบบเมื่อใช้งานได้ ไม่ใช้ชื่อที่ผู้ขายจำคร่าว ๆ
2. **Socket/ความเข้ากันได้:** ต้องใช้เมนบอร์ด BIOS และ RAM ที่รองรับรุ่นนั้น ไม่ถือว่าบูตไม่ติดเพราะ CPU เสียทันที
3. **หน้าสัมผัส/ขา:** ตรวจงอ บิ่น หลุด มีคราบ ความเสียหายทางไฟฟ้าและรอยไหม้
4. **การเข้า BIOS/ระบบ:** ตรวจว่าเมนบอร์ดรู้จัก CPU ถูกต้อง สามารถบูตตามระบบที่เข้ากันได้
5. **ความเสถียร:** หากมีชุดทดสอบที่พร้อมใช้งาน ดูอาการค้าง รีสตาร์ต Error หรือ Throttling ภายใต้โหลดเหมาะสม
6. **อุณหภูมิ:** ประเมินร่วมกับชุดระบายความร้อน การติดตั้งและโหลด ไม่ตั้งค่าเพดานเดียวกับ CPU ทุกตระกูล
7. **ประกันและประวัติ:** กล่อง ใบเสร็จ S/N ระยะประกันที่ตรวจสอบได้ เคย Overclock หรือซ่อมหรือไม่

**บูตเข้า Windows ได้อย่างเดียวไม่ได้ยืนยัน CPU สมบูรณ์ทุกสถานการณ์** และผลทดสอบที่ผิดปกติอาจมาจากเมนบอร์ด RAM ชุดระบายความร้อนหรือ PSU ต้องแยกสาเหตุก่อนตีราคา

## Intel รหัส F/K/KF และ AMD รหัส G ส่งผลต่อการใช้งานอย่างไร

รหัสต่อท้ายมีความหมายต่อคุณสมบัติและตลาด เช่น **Intel F** โดยทั่วไปเป็นรุ่นที่ไม่มีกราฟิกในตัวที่เปิดใช้งานได้ ส่วน **K/KF** เป็นรหัสของกลุ่มรุ่นที่รองรับคุณสมบัติแตกต่างตามแพลตฟอร์ม และ AMD รุ่นที่มีรหัส **G** ในซีรีส์ที่เกี่ยวข้องอาจมาพร้อมกราฟิกในตัวที่ต่างจากรุ่นไม่มี G

คำตอบเรื่องฟีเจอร์ต้องดูชื่อรุ่นเต็มจากผู้ผลิตอีกครั้ง เพราะกฎตัวอักษรไม่ได้ใช้เหมือนกันทุกตระกูล ผู้ขายที่มีเพียง CPU ไม่จำเป็นต้องทดสอบภาพจากพอร์ตบนเมนบอร์ดหากรุ่นนั้นไม่มีกราฟิกในตัว
