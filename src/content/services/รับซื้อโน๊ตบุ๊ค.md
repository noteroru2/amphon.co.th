## อยากขาย Notebook เริ่มส่งข้อมูล 4 อย่าง

1. รูปเครื่องและรูปตำหนิ รวมถึงหน้าจอขณะเปิดใช้งานถ้าเปิดติด
2. ยี่ห้อและรุ่นเต็ม พร้อม CPU, RAM, SSD และการ์ดจอเท่าที่ทราบ
3. อาการใช้งาน แบตเตอรี่ ประวัติซ่อม และที่ชาร์จหรืออุปกรณ์ที่รวมขาย
4. จังหวัดที่เครื่องอยู่และจำนวนเครื่อง

ไม่รู้สเปกก็เริ่มสอบถามได้ ส่งรูปสติกเกอร์รุ่นใต้เครื่องหรือหน้า System Information มาก่อน หากเปิดไม่ติดให้แจ้งอาการและส่งรูปตัวเครื่อง ไม่จำเป็นต้องเดาข้อมูลที่ไม่แน่ใจ ทีมงานจะขอรายละเอียดเพิ่มเติมตามที่จำเป็น

## ราคารับซื้อ Notebook คิดจากอะไร

การแจ้งเพียง “โน๊ตบุ๊ค i5” ยังไม่พอระบุราคา เพราะ CPU ต่าง Generation และรุ่นย่อยอาจมีมูลค่าต่างกัน ร้านพิจารณาจากข้อมูลต่อไปนี้ร่วมกัน

| ข้อมูล | สิ่งที่ควรแจ้ง |
| --- | --- |
| รุ่นและสเปก | รุ่นเต็ม CPU, GPU, RAM และ SSD/HDD |
| จอภาพ | ความละเอียด Refresh Rate จุดดำ เส้น รอยกด หรือจอแตก |
| แบตเตอรี่ | เก็บไฟได้แค่ไหน ใช้ได้เฉพาะเสียบปลั๊กหรือไม่ และมีอาการบวมหรือไม่ |
| สภาพเครื่อง | บานพับ ฐานเครื่อง คีย์บอร์ด Trackpad และพอร์ต |
| อุปกรณ์ | ที่ชาร์จแท้ กำลังวัตต์ กล่อง ใบเสร็จ และอุปกรณ์ที่รวมขาย |
| ประวัติ | การซ่อม การเปลี่ยนอะไหล่ และประกันที่เหลือ |

ความต้องการของตลาดในวันที่ประเมินมีผลด้วย จึงไม่ควรใช้ราคาซื้อใหม่หรือชื่อ CPU อย่างเดียวเป็นราคารับซื้อ

## โน๊ตบุ๊คเก่า เสีย หรือไม่มีที่ชาร์จ ยังขายได้ไหม

- จอแตก จอเป็นเส้น หรือมีจุดดำ: ส่งรูปให้เห็นตำหนิและรุ่นเครื่อง เพราะค่าอะไหล่ต่างกันตามรุ่น
