เครื่องประเภทนี้อาจเป็น Tower, Small Form Factor, Mini PC หรือ All-in-One หากเป็น All-in-One ควรถ่ายทั้งหน้าจอ ขอบจอ ด้านหลัง และฐานเครื่อง เพราะจอเป็นส่วนหนึ่งของตัวเครื่องและมีผลต่อการประเมินโดยตรง

หากมีการอัปเกรดหลายครั้ง สเปกปัจจุบันสำคัญกว่าสเปกตอนซื้อครั้งแรก จึงควรถ่ายรูปภายในเคสและหน้าจอที่แสดงสเปกจริง ไม่จำเป็นต้องถอดอะไหล่ออกจากเครื่องหากไม่ชำนาญ

Gaming PC มักมีมูลค่ากระจายอยู่ในหลายชิ้นส่วน โดยเฉพาะ GPU, CPU, Mainboard, RAM, SSD, PSU และระบบระบายความร้อน รุ่นการ์ดจอและสภาพการใช้งานจึงสำคัญกว่าการแจ้งเพียงว่า “คอมเกมมิ่ง”

หากเป็นเครื่องเล่นเกมโดยเฉพาะ ให้ดู [รับซื้อ Gaming PC](/บริการ/รับซื้อ-gaming-pc) เพื่อดูรายการข้อมูลสำหรับ GPU, PSU, Cooling และอาการขณะเล่นเกม

### Workstation และคอมทำงานเฉพาะทาง

เครื่องสำหรับงาน 3D, CAD, Render, กราฟิก, ตัดต่อวิดีโอ หรือประมวลผลเฉพาะทาง อาจใช้ CPU หลายคอร์, RAM สูง, GPU ที่มี VRAM มาก, Storage หลายลูก หรือการ์ดเฉพาะงาน

## ส่งข้อมูลอะไรเพื่อประเมินราคาคอมได้ใกล้เคียงขึ้น

การเขียนเพียงว่า “คอม i5 RAM 16GB” ยังไม่เพียงพอ เพราะ CPU รุ่นเดียวกันในคนละ Generation และการ์ดจอคนละรุ่นอาจทำให้มูลค่าต่างกันมาก ข้อมูลที่ควรส่งมีดังนี้

### 1. รูปตัวเครื่องด้านหน้า

ถ่ายให้เห็นเคส สภาพภายนอก Port Panel ปุ่มเปิด และรอยตำหนิที่เห็นได้ชัด

### 2. รูปด้านหลัง

ใช้ดูพอร์ตบน Mainboard, พอร์ตของการ์ดจอ, PSU และการติดตั้งอุปกรณ์บางส่วน

### 3. รูปภายในเคส

หากเปิดฝาได้อย่างปลอดภัย ให้ถ่ายภาพรวมที่เห็น Mainboard, GPU, RAM, CPU Cooler, Storage และสายไฟ ไม่ต้องถอดชิ้นส่วนออกมาเพื่อถ่าย

### 4. CPU

ส่งชื่อรุ่นเต็ม เช่น Intel Core หรือ AMD Ryzen พร้อมเลขรุ่น ไม่ควรแจ้งเพียง i5, i7, Ryzen 5 หรือ Ryzen 7

### 5. GPU

หากมีการ์ดจอแยก ควรส่งชื่อรุ่นเต็มและความจุ VRAM ถ้าทราบ หากไม่มี GPU แยกให้แจ้งว่าใช้ Integrated Graphics

### 6. RAM

ระบุความจุรวม ประเภท DDR และจำนวนแถวถ้าทราบ เช่น 16GB แบบ 8GB × 2

### 7. SSD และ HDD

แจ้งประเภทและความจุของแต่ละลูก รวมถึงบอกว่ามีข้อมูลสำคัญที่ต้องสำรองหรือไม่

### 8. Mainboard

สำคัญมากสำหรับคอมประกอบ เพราะ Socket, Chipset และ Feature มีผลต่อการใช้งานต่อ ถ้าไม่ทราบรุ่นสามารถส่งรูปบริเวณ Mainboard ได้

### 9. PSU

ควรแจ้งยี่ห้อ รุ่น กำลังวัตต์ และอายุโดยประมาณ โดยเฉพาะเครื่องที่มี GPU แยกหรือใช้ชุดน้ำ

### 10. Case และระบบระบายความร้อน

ถ้ามีชุดน้ำ พัดลมจำนวนมาก เคสขนาดใหญ่ หรืออุปกรณ์เฉพาะ ควรถ่ายให้เห็นสภาพและแจ้งอาการผิดปกติ เช่น ปั๊มดัง พัดลมไม่หมุน หรือไฟบางจุดไม่ทำงาน

### 11. อาการและประวัติซ่อม

แจ้งอาการตามจริง เช่น เปิดไม่ติด ไฟเข้าแต่ไม่ขึ้นภาพ Blue Screen เล่นเกมแล้วดับ พอร์ตเสีย จอเป็นเส้น หรือเคยซ่อม GPU, Mainboard, PSU มาก่อน

### 12. อุปกรณ์ที่ขายพร้อมกัน

จอ คีย์บอร์ด เมาส์ UPS ลำโพง Wi-Fi Adapter กล่องอะไหล่ หรืออุปกรณ์อื่นควรแยกรายการ เพื่อให้ประเมินตามของที่มีจริง

### 13. จำนวนเครื่องและจังหวัด

ใช้สำหรับวางแผนขั้นตอนตรวจและส่งมอบหลังผ่านการประเมินเบื้องต้น

## วิธีเช็กสเปกคอมก่อนส่งประเมิน

หากเครื่องเปิดได้ สามารถเริ่มจากเครื่องมือใน Windows โดยไม่ต้องติดตั้งโปรแกรมเพิ่มเติม

### Task Manager

เปิด Task Manager แล้วดูแท็บ Performance เพื่อดู CPU, RAM, Disk และ GPU เบื้องต้น ถ่ายภาพแต่ละหัวข้อที่เกี่ยวข้อง

### System Information

ใช้ดูรุ่น CPU, Mainboard และข้อมูลระบบบางส่วน เหมาะกับเครื่องแบรนด์หรือเครื่องที่ไม่ทราบ Configuration เดิม

### Device Manager

ช่วยตรวจชื่อ GPU, Storage, Network และอุปกรณ์บางประเภท

### Settings > System > About

ใช้ดู CPU, RAM และข้อมูลเครื่องเบื้องต้นได้รวดเร็ว

สำหรับคอมประกอบที่ต้องการข้อมูลละเอียดขึ้น อาจใช้โปรแกรมตรวจ Hardware ที่ผู้ขายใช้อยู่แล้ว แต่ไม่จำเป็นต้องติดตั้งซอฟต์แวร์ที่ไม่รู้จักเพียงเพื่อส่งประเมิน

อ่านคู่มือเพิ่มเติมได้ที่ [วิธีเช็กสเปกคอมก่อนขาย](/blog/วิธีเช็กสเปกคอมก่อนขาย)

## ราคาประเมินคอมพิวเตอร์ขึ้นกับอะไร

ราคาของคอมมือสองไม่ได้คำนวณจากราคาซื้อใหม่เพียงอย่างเดียว แต่ต้องดูว่าชิ้นส่วนและเครื่องทั้งชุดยังมีตลาดอย่างไรในวันที่ประเมิน

### CPU และ Platform

CPU มีผลต่อความสามารถในการใช้งานต่อ แต่ต้องดูทั้งรุ่น Socket, Mainboard ที่ใช้ และโอกาสอัปเกรด ไม่ควรประเมินจากคำว่า Core i5 หรือ Ryzen 5 เพียงอย่างเดียว

### GPU

GPU มีผลมากใน Gaming PC และ Workstation แต่รุ่นเดียวกันก็ยังต้องดูสภาพ การทำงาน พัดลม อุณหภูมิ พอร์ต และประวัติซ่อม

อ่านเพิ่มเติมได้ที่ [การ์ดจอมีผลต่อราคาคอมมือสองแค่ไหน](/blog/การ์ดจอมีผลต่อราคาคอมมือสองแค่ไหน)

### RAM

ดูทั้งความจุ ประเภท DDR จำนวนแถว ความเร็ว และการทำงานปกติ ความจุสูงขึ้นไม่ได้แปลว่ามูลค่าเพิ่มในสัดส่วนเท่ากันทุกเครื่อง

### SSD และ HDD

ดูชนิด ความจุ สุขภาพของ Drive และความเหมาะสมกับเครื่อง หาก Drive มีข้อมูลส่วนตัว ผู้ขายควรสำรองและจัดการข้อมูลก่อนส่งมอบ

### Mainboard

Mainboard มีผลต่อ Platform, Port, Expansion และความสามารถในการใช้งานร่วมกับ CPU/RAM รุ่นนั้น ๆ หากมีพอร์ตเสีย เคยซ่อม หรือมีอาการบูตผิดปกติควรแจ้ง

### PSU

PSU มีผลต่อความน่าเชื่อถือของเครื่อง โดยเฉพาะ Gaming PC และเครื่องสเปกสูง ควรแจ้งรุ่นและกำลังวัตต์ ไม่ควรประเมินจากตัวเลข Watt อย่างเดียว

### Case และ Cooling

สภาพเคสไม่ใช่ปัจจัยเดียว แต่เคสแตก ฝาหาย พอร์ตหน้าเสีย ชุดน้ำรั่ว หรือระบบระบายความร้อนผิดปกติอาจเพิ่มต้นทุนในการนำไปใช้งานต่อ

### สภาพการใช้งานจริง

เปิดติดหรือไม่ ใช้งานต่อเนื่องได้หรือไม่ มีภาพลาย Blue Screen เครื่องดับ ความร้อนผิดปกติ พอร์ตเสีย หรือเสียงพัดลมผิดปกติ ล้วนมีผลต่อการตรวจ

### ประกัน กล่อง และใบเสร็จ

อาจช่วยยืนยันรุ่น อายุ และประวัติสินค้า แต่ไม่ใช่ปัจจัยหลักเท่าสเปกและสภาพจริง

### ตลาดมือสองในช่วงนั้น

Hardware บางรุ่นมีความต้องการต่อสูง ขณะที่บางรุ่นแม้ราคาซื้อใหม่เดิมสูงแต่ตลาดปัจจุบันแคบ การประเมินจึงต้องอิงข้อมูลตลาดในวันที่ติดต่อ ไม่ควรยึดราคาจากตารางเก่าหรือราคาตอนซื้อ

## คอมเปิดไม่ติดหรือมีชิ้นส่วนเสียยังส่งประเมินได้ไหม

ส่งข้อมูลมาให้พิจารณาได้ แต่ควรบอกอาการตามจริงและไม่ควรเดาว่าเสียชิ้นไหนหากยังไม่ได้ตรวจ

### ไฟไม่เข้า

อาจเกี่ยวกับ PSU, สายไฟ, Mainboard หรืออุปกรณ์อื่น ควรส่งรูป PSU และภายในเครื่องถ้าปลอดภัย

### ไฟเข้าแต่ไม่ขึ้นภาพ

อาจเกี่ยวกับ GPU, RAM, Mainboard, CPU หรือจอและสายสัญญาณ ควรแจ้งว่ามีพอร์ตภาพบน Mainboard หรือ GPU และเคยเกิดอาการแบบใด

### เปิดติดแล้วดับหรือรีสตาร์ต

อาจเกิดจากความร้อน PSU RAM Storage Driver หรือ Hardware อื่น ไม่ควรฟันธงสาเหตุเอง

### GPU มีภาพลายหรือจอดับ

ควรส่งรูปหรือวิดีโออาการ พร้อมรุ่น GPU และประวัติซ่อมหากมี

### ถอดชิ้นส่วนออกแล้ว

แจ้งให้ชัดว่าขาดอะไร เช่น ไม่มี GPU, ไม่มี SSD, ไม่มี RAM หรือไม่มี PSU เพราะการประเมินจะอิงจากชิ้นส่วนที่มีอยู่จริง

การส่งประเมินไม่ได้หมายความว่าจะรับซื้อได้ทุกกรณี โดยเฉพาะเครื่องที่เสียหายรุนแรง มีความเสี่ยงด้านไฟฟ้า หรือไม่สามารถตรวจสอบที่มาของสินค้าได้

## ขายทั้งเครื่องหรือขายแยกอะไหล่

ทั้งสองแบบมีข้อดีต่างกันและไม่มีคำตอบเดียวสำหรับทุกเครื่อง

### ขายทั้งเครื่อง

เหมาะกับผู้ขายที่ต้องการจบรายการในครั้งเดียว ไม่ต้องถอดชิ้นส่วน ไม่ต้องทดสอบแยก และลดความเสี่ยงจากการขนย้ายอะไหล่หลายรายการ

### ขายแยกชิ้นส่วน

อาจเหมาะเมื่อเครื่องขาดบางส่วนหรือมีชิ้นส่วนบางรายการที่ต้องการขายแยก แต่ต้องใช้เวลาในการถอด ทดสอบ บรรจุ และจัดการหลายรายการ

- [จอคอม](/บริการ/รับซื้อจอคอม)

## การจัดการข้อมูลก่อนขายคอม

คอมพิวเตอร์อาจมีข้อมูลส่วนตัว เอกสารบริษัท บัญชี เบราว์เซอร์ รูปภาพ หรือไฟล์งาน ควรจัดการข้อมูลก่อนส่งมอบ

1. สำรองไฟล์สำคัญ
2. ออกจากบัญชี Microsoft, Google, Adobe, Steam หรือบริการอื่นที่ใช้งาน
3. ตรวจว่ามี BitLocker หรือระบบเข้ารหัสดิสก์หรือไม่
4. หากเป็นเครื่องบริษัท ให้ประสานฝ่าย IT หรือผู้ดูแลข้อมูล
5. ถอดอุปกรณ์เก็บข้อมูลที่ไม่ต้องการขายออกก่อนประเมิน โดยแจ้งทีมงานว่า Storage ใดไม่รวม
6. รีเซ็ตหรือล้างข้อมูลหลังยืนยันรายการขายและสำรองข้อมูลครบแล้ว

หากยังต้องใช้เครื่องเพื่อแสดงสเปก ไม่จำเป็นต้องล้างระบบก่อนส่งรูปประเมิน แต่ควรหลีกเลี่ยงการส่งภาพที่มีข้อมูลส่วนตัวปรากฏอยู่

## ขั้นตอนขายคอมกับอำพล เทรดดิ้ง

### ขั้นที่ 1 — ส่งรูปและสเปก

ส่งรูปตัวเครื่องและข้อมูล CPU, GPU, RAM, Storage พร้อมอาการและอุปกรณ์ทาง LINE

### ขั้นที่ 2 — ตรวจข้อมูลและแจ้งราคาเบื้องต้น

ทีมงานตรวจรุ่น สเปก สภาพจากข้อมูลที่ส่งมา และอาจขอรูปเพิ่มหากยังแยกรุ่นไม่ได้

### ขั้นที่ 3 — ตกลงวิธีตรวจเครื่อง

เมื่อราคาเบื้องต้นอยู่ในช่วงที่รับได้ จึงคุยว่าจะนำเครื่องเข้าหน้าร้าน นัดหมาย หรือจัดส่งอย่างไรตามสินค้าและพื้นที่

### ขั้นที่ 4 — ตรวจสภาพจริง

ตรวจ Hardware, การเปิดใช้งาน, พอร์ต, Storage, GPU, ระบบระบายความร้อน และอุปกรณ์ตามที่แจ้ง

### ขั้นที่ 5 — ยืนยันราคาสุดท้าย

หากสภาพจริงตรงกับข้อมูลที่ใช้ประเมิน ราคาจะยืนยันตามเงื่อนไขที่ตกลง หากมีความแตกต่างจะอธิบายก่อน ผู้ขายไม่จำเป็นต้องขายหากราคาไม่ตรงใจ

### ขั้นที่ 6 — จัดการข้อมูลและชำระเงิน

หลังยืนยันขาย ผู้ขายจัดการบัญชีและข้อมูลที่เหลือ ส่งมอบอุปกรณ์ และรับชำระตามวิธีที่ตกลง
