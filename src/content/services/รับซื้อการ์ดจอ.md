## วิธีดูรุ่น GPU และ VRAM ให้ตรงก่อนขาย

หากติดตั้งใช้งานในคอมอยู่ สามารถถ่ายภาพ **ชื่อการ์ดจาก Device Manager หรือ GPU-Z** พร้อมภาพ VRAM (ถ้าเปิดได้) แล้วถ่ายสติกเกอร์รหัสรุ่นบนตัวการ์ดและภาพด้านหน้า–หลังให้ครบ โปรแกรมตรวจช่วยระบุข้อมูลที่รายงานจากระบบ แต่ไม่ยืนยันการ์ดแท้หรือสภาพสมบูรณ์ทั้งหมดเพียงอย่างเดียว

หากถอดการ์ดออกแล้ว ไม่จำเป็นต้องประกอบเครื่องใหม่เพื่อขอประเมินเบื้องต้น ให้ส่งภาพชื่อรุ่นบนสติกเกอร์ ชิ้นส่วนที่เห็นภายนอก กล่อง/ใบเสร็จและเลขประกันเท่าที่มี พร้อมระบุว่า **ยังไม่ทดสอบ** หากการ์ดมีรอยไหม้หรือความเสียหายทางไฟฟ้าไม่ควรต่อไฟเพื่อทดลองเอง

## รายการตรวจ GPU ที่ร้านควรพิจารณาก่อนรับซื้อ

| จุดตรวจ | อาการที่ต้องระวัง | หลักฐานที่มีประโยชน์ |
| --- | --- | --- |
| ภาพและพอร์ต | ไม่ออกภาพ ภาพแตก ลายจอ พอร์ตเสีย | ภาพหน้าจอ/วิดีโอจากพอร์ตที่ทดสอบได้ |
| ไดรเวอร์ | Device Error, ไดรเวอร์ล้มเหลว, จอดับ | ภาพ Device Manager/เครื่องมืออ่านข้อมูลและอาการ |
| VRAM | รายงาน VRAM ไม่ตรงรุ่น มี Artifact ภายใต้โหลด | รุ่นจริง ข้อมูล GPU-Z และผลตรวจที่เหมาะสม |
| พัดลม | ไม่หมุนในช่วงที่ควรทำงาน เสียงแกว่ง สั่น | ภาพ/วิดีโอขณะใช้งานอย่างปลอดภัย |
| อุณหภูมิ | ร้อนผิดปกติ Thermal Throttling ดับหรือรีสตาร์ต | ค่าอุณหภูมิ GPU/Hotspot และสภาพแวดล้อมทดสอบ |
| สภาพ PCB และขั้วต่อ | สนิม คราบชื้น รอยไหม้ พินหรือขอบการ์ดเสีย | รูปด้านหน้า–หลัง สติกเกอร์และขั้วต่อ |
| ประกันและการซ่อม | เคยเปลี่ยนพัดลม ซิลิโคน แผ่นระบายความร้อน หรือ BIOS | ใบเสร็จ ประวัติซ่อมและสถานะประกัน |

การทดสอบไม่ได้หมายความว่าการ์ดจะไม่เสียในอนาคต และการ์ดที่ไม่ออกภาพต้องแยกสาเหตุจาก **PSU, RAM, Mainboard และสายจอ** ก่อนสรุปว่าเสียที่ GPU อย่างเดียว

## เทสการ์ดจอใช้โปรแกรมอะไร และต้องดูผลแบบไหน

ถ้ามีระบบพร้อมทดสอบ การใช้ **3DMark, OCCT หรือ FurMark** เป็นเพียงเครื่องมือบางส่วนในการตรวจภาระงาน การ์ดอาจผ่านการทดสอบช่วงสั้นแต่มีปัญหาภายใต้เกมจริงหรือการใช้งานต่อเนื่อง จึงควรพิจารณาทั้งภาพออก อาการค้าง ไดรเวอร์ ความร้อน เสียงพัดลม และผลเทียบรุ่น

**ไม่มีเกณฑ์ตายตัวว่า GPU ทุกตัวต้องต่ำกว่า 85°C หรือ Hotspot ต่ำกว่า 90°C** เพราะอุณหภูมิที่เหมาะสมและเซ็นเซอร์แตกต่างกันตามชิป รุ่นระบบระบายความร้อน ห้องและโหลดที่ทดสอบ ทีมงานควรใช้ข้อกำหนดของรุ่นนั้นและสภาพการทำงานจริง ไม่ตั้งตัวเลขเดียวสำหรับทุก GPU

หากกำลังเกิดไฟกระพริบ มีกลิ่นไหม้ หรือพัดลมติดขัดผิดปกติ ควรหยุดทดสอบแทนการฝืน Stress Test และไม่ควรให้ลูกค้าแกะซิงก์หรือซ่อมเองเพื่อพิสูจน์อาการ

## การ์ดจอใช้ขุดเหรียญหรือเปิดเครื่องตลอดยังขายได้ไหม

ส่งประเมินได้เป็นกรณี โดยแจ้งประวัติการใช้งานตามจริง เช่น เล่นเกม ทำงานเรนเดอร์ ใช้ขุดเหรียญ เคยเปิดตลอดเวลา เคยเปลี่ยน BIOS หรือเคยเปลี่ยนแผ่น Thermal Pad/ซิลิโคน

**การ์ดจอที่สะอาดหรือชื้นฝุ่นน้อยไม่ได้พิสูจน์ว่าไม่เคยขุดเหรียญ** และการ์ดที่เคยขุดก็ไม่ได้แปลว่าเสียทั้งหมด ต้องดูอาการจริง พัดลม ภาคจ่ายไฟ ความร้อน ประกันและผลการทดสอบประกอบ

## ถ้าแกะซิงก์หรือเปลี่ยนซิลิโคน ประกันยังเหลือไหม

ต้องตรวจนโยบายของ **ผู้ผลิตการ์ด ผู้จัดจำหน่าย และเงื่อนไขประกัน** ตามรุ่นและประเทศที่ซื้อ ไม่ควรสรุปว่าเปิดซิงก์แล้วประกันหมดทุกกรณี ให้แจ้งว่าเคยแกะหรือซ่อมอะไร มีอะไหล่เดิมและใบเสร็จหรือไม่

สำหรับการ์ดที่มีความเสียหายหนัก เช่น ขั้วไฟไหม้ PCB บิ่น อุปกรณ์หายหรือมีคราบกัดกร่อน ต้องประเมินความเสี่ยงเป็นรายชิ้น ไม่ใช้ราคาการ์ดทดสอบผ่าน

## ปัจจัยที่ใช้ประเมินราคารับซื้อ GPU

1. **รุ่นและ VRAM จริง:** แยกชิป รุ่นย่อย และความจุ เช่น RTX 3060 8GB/12GB ไม่ใช่ชิ้นเดียวกัน
2. **แบรนด์และชุดระบายความร้อน:** รุ่น 2/3 พัดลม ขนาดการ์ด และความต้องการตลาดในวันประเมิน
3. **ประกัน:** ระยะเวลาที่เหลือและการเคลมที่ตรวจสอบได้ ไม่บวกราคาอัตโนมัติจากสติกเกอร์อย่างเดียว
4. **การทำงาน:** ผ่านภาพออก ไดรเวอร์ และการทดสอบที่เหมาะสมหรือยังไม่ได้ทดสอบ
5. **ประวัติ:** เคยขุด ซ่อม เปลี่ยนชิ้นส่วน หรือประสบความเสียหายจากน้ำ
