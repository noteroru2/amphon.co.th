## รับซื้อโน๊ตบุ๊คบริษัทและเครื่องพนักงานเก่า ส่งรายการประเมินก่อนขาย

Notebook พนักงานมีรายละเอียดต่างจากคอมตั้งโต๊ะ เพราะต้องดู **จอ แบตเตอรี่ Adapter/Dock บอดี้ Keyboard พอร์ต Storage และสถานะระบบองค์กร** เพิ่มจาก CPU/RAM/SSD

หน้านี้สำหรับบริษัทที่เรียกคืนเครื่องพนักงาน เปลี่ยน Device Refresh ปลดเครื่องออกจาก Asset Register หรือรวบรวม Notebook จากหลายแผนก โดยใช้ **Asset List / Inventory List** เป็นแกนหลัก

หากเป็น Notebook หลายเครื่องโดยไม่มีบริบทองค์กรชัด ใช้ [รับซื้อโน๊ตบุ๊คยกล็อต](/บริการ/รับซื้อโน๊ตบุ๊คยกล็อต) หากเป็นทรัพย์สินหลายหมวดของบริษัท ใช้ [รับซื้อสินค้าไอทีบริษัท](/บริการ/รับซื้อสินค้าไอทีบริษัท) และสำหรับ Notebook มือสองทั่วไปใช้ [รับซื้อโน๊ตบุ๊ค](/บริการ/รับซื้อโน๊ตบุ๊ค)

หากมีเครื่องจำนวนมาก ไม่จำเป็นต้องถ่ายทุกเครื่องตั้งแต่แรก เริ่มจาก Inventory List และรูปตัวแทนของแต่ละกลุ่มได้

## ระบบองค์กรที่ต้องตรวจ

### MDM / Endpoint Management
ฝ่าย IT ควรถอนตามนโยบายและตรวจว่าเครื่องไม่ถูกควบคุมจากระบบเดิมก่อนส่งมอบ

### Domain / Account
ออกจากระบบและบัญชีที่เป็นขององค์กรตามขั้นตอนที่ถูกต้อง

### BitLocker / Encryption
จัดการ Recovery Key และการเข้ารหัสตามนโยบายก่อนส่งมอบ

### Apple / Activation หากมี MacBook
เครื่องที่ผูก Activation Lock หรือบัญชีเจ้าของต้องปลดโดยผู้มีสิทธิ์

### Storage
หากบริษัทเก็บ SSD ไว้ ให้แจ้งว่าเครื่องไม่มี Storage ตั้งแต่ตอนประเมิน

## สภาพ Notebook ที่ควรแยก

- ใช้งานปกติ
- มีตำหนิ
- เปิดไม่ติด
- ไม่มี Adapter
- ถอด SSD/RAM
- Untested

## Adapter และ Dock

Notebook องค์กรมักมี Adapter และ Docking Station จำนวนมาก ควรแยกว่าจับคู่กับเครื่องใดหรือเป็นสต็อกส่วนกลาง ไม่ควรสมมติว่า Adapter ทุกตัวเพิ่มราคากับทุกเครื่อง
