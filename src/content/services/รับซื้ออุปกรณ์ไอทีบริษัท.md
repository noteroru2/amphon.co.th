## รับซื้ออุปกรณ์ไอทีบริษัท ส่งรุ่น จำนวน และสภาพประเมินก่อนขาย

หน้านี้เป็น Child Page สำหรับ **อุปกรณ์สำนักงานไอทีและอุปกรณ์ประกอบ** ที่ไม่ใช่คอม/Notebook หลัก และไม่ใช่ Infrastructure project ขนาดใหญ่

หากบริษัทมีทรัพย์สินหลายหมวดรวมกัน ดูรายละเอียดที่ [รับซื้อสินค้าไอทีบริษัท](/บริการ/รับซื้อสินค้าไอทีบริษัท) หากรายการหลักคือ Server, NAS, Storage, Switch, Router หรือ Firewall ให้ดู [รับซื้อ Server และ Network](/บริการ/รับซื้อ-server-network)

## กลุ่มอุปกรณ์ที่ส่งประเมินได้

### Monitor
ส่งรุ่น ขนาด Resolution พอร์ต ขาตั้ง สภาพ Panel และจำนวน

### UPS
ส่งรุ่น VA/kVA อายุแบต สถานะ Alarm อุปกรณ์ Rack/Bypass และจำนวน

### Docking / KVM
ส่ง Part Number, Power Adapter, Cable และจำนวน

### Printer / Scanner
ส่งรุ่น Counter/Page Count ถ้าทราบ สถานะ Error และ Consumable ที่รวม อุปกรณ์บางรุ่นอาจไม่อยู่ในกลุ่มรับซื้อ จึงควรส่งรุ่นก่อน

### POS / Barcode / Receipt Printer
ส่งรุ่น Adapter และอุปกรณ์ที่รวม ไม่ควรสรุปว่ารับทุกประเภทโดยไม่ดูรุ่น

### Conference / Office Peripheral
Video conference, projector และอุปกรณ์เฉพาะสำนักงานบางชนิดส่งรูปและ Part Number สอบถามได้

## อุปกรณ์ Network ควรไปหน้าไหน

หากมี Switch/Router/AP เพียงเล็กน้อยปนกับ Office equipment สามารถใส่ในรายการรวมได้ แต่ถ้า Network/Server เป็นสินค้าหลัก ให้ใช้ [รับซื้อ Server และ Network](/บริการ/รับซื้อ-server-network) เพราะต้องดู Port, Module, SFP, PSU, License/Subscription, Rack kit และ Configuration state

## ราคาขึ้นกับอะไร

**Monitor** — Panel, Resolution, ขนาด, ขาตั้ง, Dead Pixel/เส้น

**UPS** — รุ่น, VA/kVA, Battery, Alarm, Rack accessory

**Printer** — รุ่น, Technology, Counter, Error, Consumable

**Dock/KVM** — Part Number, Adapter, Port, compatibility

**Peripheral** — ความต้องการตลาดและความครบของชุด
