## รุ่น Mac mini ที่รับพิจารณา

### Mac mini M4 และ M4 Pro ปี 2024

Mac mini ปี 2024 เปลี่ยนเป็นตัวเครื่องขนาดเล็กลงและมีพอร์ตด้านหน้า รุ่น M4 และ M4 Pro ต้องแยกให้ถูก เพราะชิป ตัวเลือก Memory พอร์ต Thunderbolt และมูลค่าตลาดต่างกัน

ข้อมูลที่ควรส่ง:

- ระบุว่าเป็น M4 หรือ M4 Pro
- จำนวนคอร์ CPU/GPU หากเป็นสเปกสั่งเพิ่ม
- Unified Memory เช่น 16GB, 24GB หรือ 48GB
- SSD เช่น 256GB, 512GB, 1TB หรือมากกว่า
- พอร์ต Ethernet ว่าเป็นรุ่นมาตรฐานหรือ 10Gb Ethernet ถ้าทราบ
- รูปด้านหน้า ด้านหลัง ด้านบน และฐานเครื่อง
- สายไฟ กล่อง และหลักฐานประกันถ้ามี

คำค้น “Mac mini M4 มือสอง” อาจหมายถึงทั้งคนหาซื้อและคนต้องการขาย หน้านี้เน้นสำหรับเจ้าของเครื่องที่ต้องการประเมินเพื่อขาย หากต้องการศึกษาราคาตลาดและจุดตรวจเครื่องเพิ่มเติม อ่าน [Mac mini M4 มือสอง](/blog/mac-mini-m4-มือสอง)

### Mac mini M2 และ M2 Pro ปี 2023

รุ่น M2 และ M2 Pro มีตัวถังคล้ายกัน แต่จำนวนพอร์ต Thunderbolt และสเปกพื้นฐานต่างกัน ควรส่งหน้า About This Mac แทนการดูจากรูปภายนอกอย่างเดียว

สเปก 8GB/256GB, 16GB/512GB และรุ่น CTO มีตลาดต่างกัน รุ่นที่ Memory หรือ SSD สูงไม่ได้หมายความว่าจะได้ส่วนต่างคืนเท่าราคาที่จ่ายเพิ่มตอนซื้อ เพราะราคามือสองยังขึ้นกับความต้องการของสเปกนั้นและราคาสินค้าใหม่ในช่วงประเมิน

### Mac mini M1 ปี 2020

Mac mini M1 ยังเป็นรุ่นที่มีผู้ใช้จำนวนมาก แต่ราคาขึ้นกับ Memory 8GB หรือ 16GB, SSD, สภาพ และอุปกรณ์ ควรตรวจพอร์ตทั้งหมดและแจ้งว่ามีประวัติซ่อมหรือไม่

รุ่น M1 ไม่มีแบตเตอรี่เหมือน MacBook จึงไม่ต้องส่ง Battery Cycle แต่ควรทดสอบการเปิดเครื่อง ความเสถียร Wi-Fi, Bluetooth, HDMI, USB และ Thunderbolt

### Mac mini Intel

รับพิจารณารุ่น Intel ตามปีและสเปก เช่น รุ่นปี 2018 รวมถึงรุ่นเก่าบางช่วง เครื่อง Intel ต้องดู CPU, RAM, SSD, ระบบปฏิบัติการที่รองรับ และประวัติการอัปเกรดหรือซ่อม

Mac mini Intel บางรุ่นสามารถเปลี่ยน RAM หรือ Storage ได้ต่างจาก Apple Silicon จึงควรส่งภาพ System Information และแจ้งว่าเป็นอุปกรณ์เดิมจากโรงงานหรืออัปเกรดภายหลัง

### Mac mini M3 มีหรือไม่

ในรายชื่อรุ่นทางการของ Apple มี Mac mini ชิป M1 ปี 2020, M2/M2 Pro ปี 2023 และ M4/M4 Pro ปี 2024 แต่ไม่มี Mac mini รุ่นชิป M3 หากผู้ขายไม่แน่ใจ ควรเปิด **About This Mac** หรือส่ง Serial Number เพื่อระบุรุ่นก่อน อย่าอ้างอิงจากชื่อที่ผู้ขายรายเดิมพิมพ์ไว้เพียงอย่างเดียว

## ปัจจัยที่มีผลต่อราคา Mac mini มือสอง

### 1. ชิปและรุ่นย่อย

M4, M4 Pro, M2, M2 Pro, M1 และ Intel มีประสิทธิภาพ ตลาด และอายุผลิตต่างกัน รุ่น Pro หรือสเปกคอร์สูงต้องตรวจชื่อชิปและจำนวนคอร์ให้ตรง ไม่ควรประเมินจากปีอย่างเดียว

### 2. Unified Memory หรือ RAM

Mac mini Apple Silicon ใช้ Unified Memory ที่เลือกตั้งแต่ตอนซื้อและผู้ใช้ทั่วไปไม่สามารถเพิ่มภายหลังได้ สเปก Memory จึงเป็นข้อมูลสำคัญ โดยเฉพาะเครื่องที่สูงกว่ารุ่นเริ่มต้น

อย่างไรก็ตาม Memory มากกว่าไม่ได้รับประกันว่าราคาจะเพิ่มตามต้นทุนเดิมทั้งหมด เพราะต้องดูความต้องการของผู้ซื้อปลายทางและราคาของรุ่นใกล้เคียงในตลาด

### 3. SSD และพื้นที่จัดเก็บข้อมูล

SSD 256GB, 512GB, 1TB หรือมากกว่านั้นมีผลต่อราคา โดยเฉพาะเมื่อเป็นสเปก CTO ควรส่งหน้าจอ Storage หรือ System Information เพื่อยืนยันความจุจริง ไม่ควรดูจากกล่องเพียงอย่างเดียว เพราะกล่องอาจไม่ตรงเครื่อง

### 4. สภาพตัวเครื่องและฐานด้านล่าง

Mac mini มักวางอยู่กับที่ แต่ยังเกิดรอยจากการวางของบนเครื่อง การขูดฐาน การกระแทกมุม หรือคราบจากสภาพแวดล้อมได้ ควรถ่ายในแสงธรรมชาติและไม่ใช้ฟิลเตอร์แต่งภาพ

จุดที่ควรถ่าย:

- ฝาด้านบน
- มุมทั้งสี่
- ฐานเครื่อง
- รอบช่องระบายอากาศ
- พอร์ตด้านหน้าและด้านหลัง
- จุดที่มีรอยบุบ คราบ หรือรอยขีดลึก

### 5. การทำงานของพอร์ต

Mac mini ต้องพึ่งพาจอและอุปกรณ์ภายนอก พอร์ตจึงมีผลต่อการใช้งานโดยตรง ควรทดสอบ HDMI, USB-C/Thunderbolt, USB-A ในรุ่นที่มี, Ethernet, ช่องหูฟัง และพอร์ตด้านหน้าในรุ่น M4

การที่เสียบไฟแล้วเปิดติดไม่ได้ยืนยันว่าพอร์ตทั้งหมดปกติ หากมีพอร์ตหลวม ภาพไม่ออก อ่านอุปกรณ์ไม่ได้ หรือ Ethernet มีปัญหา ควรแจ้งก่อนประเมิน

### 6. Wi-Fi, Bluetooth และความเสถียร

ควรทดลองเชื่อม Wi-Fi และอุปกรณ์ Bluetooth เปิดใช้งานต่อเนื่อง และสังเกตอาการดับ รีสตาร์ท ค้าง หรือพัดลมผิดปกติ หากเคย Kernel Panic หรือซ่อมบอร์ด ควรแจ้งตามจริง

### 7. สายไฟ กล่อง และอุปกรณ์

Mac mini ขายตัวเครื่องแยกจอได้ตามปกติ สิ่งที่ควรมีคือสายไฟที่เหมาะกับรุ่น กล่องเดิมและ Serial ที่ตรงเครื่องช่วยตรวจสอบและแพ็กขนส่ง แต่ไม่มีกล่องก็ยังส่งประเมินได้

Magic Keyboard, Magic Mouse, Trackpad หรือจอภาพเป็นอุปกรณ์แยก หากต้องการขายพร้อมกันควรแยกรุ่น สภาพ และ Serial ของแต่ละชิ้น

### 8. ประกันและหลักฐานการซื้อ

ประกันที่ตรวจสอบได้และใบเสร็จอาจช่วยเพิ่มความมั่นใจ โดยเฉพาะเครื่องอายุสั้น แต่ราคายังขึ้นกับสเปกและสภาพจริง ไม่ควรส่งภาพใบเสร็จที่เปิดเผยข้อมูลส่วนบุคคลเกินจำเป็นในแชทสาธารณะ

### 9. Apple Account, Find My และ Activation Lock

เครื่องที่ส่งมอบต้องสามารถออกจาก Apple Account และปิด Find My ได้ เจ้าของควรเป็นผู้ดำเนินการหรือยืนยันต่อหน้า หากไม่สามารถปลด Activation Lock ได้ จะไม่สามารถประเมินเป็นเครื่องพร้อมขายต่อได้

### 10. ราคาตลาดในวันที่ประเมิน

ราคาสินค้าใหม่ โปรโมชั่น รุ่นทดแทน และจำนวนเครื่องในตลาดมีผลต่อ Mac mini มือสอง จึงไม่ควรยึดตารางราคาคงที่หลายเดือนโดยไม่ตรวจสเปกและตลาดปัจจุบัน

คลิกเมนู Apple  แล้วเลือก **About This Mac** หรือ **เกี่ยวกับ Mac เครื่องนี้** ถ่ายภาพให้เห็นชื่อชิปและ Memory จากนั้นเปิดข้อมูลเพิ่มเติมเพื่อดู Storage

ควรปิดหรือเบลอข้อมูลที่ไม่จำเป็น แต่ Serial Number ช่วยระบุรุ่นได้ หากไม่ต้องการส่ง Serial เต็มในครั้งแรก สามารถส่งชื่อรุ่น ชิป Memory และ SSD ก่อน แล้วให้ทีมงานขอข้อมูลเพิ่มเติมเฉพาะเมื่อจำเป็น

### ดู Storage

เปิด System Settings > General > Storage หรือ System Information แล้วถ่ายให้เห็นความจุรวม ไม่ควรแจ้งจากพื้นที่ว่างคงเหลือ เพราะพื้นที่ว่างไม่ใช่ความจุ SSD ของเครื่อง

### ตรวจรุ่นจากกล่อง

กล่องมี Part Number และ Serial Number แต่ต้องตรวจว่า Serial ตรงกับตัวเครื่อง อย่าใช้ข้อมูลกล่องของเครื่องอื่นมาประเมิน

### เครื่องเปิดไม่ติด

ถ่าย Serial Number ที่ฐานหรือกล่อง รูปพอร์ต และแจ้งอาการอย่างละเอียด เช่น ไม่มีไฟ ภาพไม่ออก เปิดแล้วดับ หรือมีเสียงผิดปกติ การประเมินเครื่องเสียจะแยกจากเครื่องที่เปิดใช้งานได้ปกติ

## เช็กลิสต์ทดสอบก่อนส่งรูปประเมิน

- เปิดเครื่องและเข้า macOS ได้
- About This Mac แสดงรุ่นตรงกับที่แจ้ง
- HDMI แสดงภาพ
- พอร์ต USB-C/Thunderbolt ใช้งานได้

- พัดลมไม่มีเสียงผิดปกติ

ไม่จำเป็นต้องรันโปรแกรมหนักหรือแกะเครื่อง หากไม่มั่นใจให้แจ้งผลที่ทดสอบได้จริงแทนการคาดเดา

## Mac mini สภาพไหนส่งประเมินได้

### สภาพใช้งานปกติ

ส่งสเปก รูป และอุปกรณ์ได้ทันที เป็นกลุ่มที่ประเมินเบื้องต้นได้ชัดที่สุด

### ไม่มีกล่อง

ขายได้ในหลายกรณี ควรมีสายไฟและแพ็กตัวเครื่องอย่างปลอดภัย หากต้องจัดส่งให้ตกลงวิธีแพ็กกับทีมงานก่อน

### มีรอยบุบหรือรอยขีด

ถ่ายตำหนิระยะใกล้และภาพรวม ไม่ควรส่งเฉพาะมุมที่สวย ราคาจะดูว่าตำหนิกระทบโครงสร้าง พอร์ต หรือการระบายอากาศหรือไม่

### พอร์ตเสียหรือเครื่องไม่เสถียร

รับพิจารณาตามอาการ แต่ราคาและเงื่อนไขต่างจากเครื่องปกติ ควรแจ้งพอร์ตที่เสีย อาการดับ ค้าง หรือประวัติซ่อมให้ครบ

### เปิดไม่ติด

ส่งรุ่น Serial รูปสภาพ และอาการล่าสุดเพื่อพิจารณามูลค่าซากหรืออะไหล่ได้ในบางกรณี ไม่ควรระบุว่าใช้งานปกติหากไม่ได้ทดสอบ

### ติด Find My หรือ Activation Lock

ต้องให้เจ้าของปลดก่อนส่งมอบ หากจำรหัสไม่ได้ ควรดำเนินการกู้คืนบัญชีกับ Apple ตามช่องทางของเจ้าของ ไม่ควรล้างเครื่องก่อนมั่นใจว่าสามารถปิด Activation Lock ได้

## วิธีเตรียม Mac mini ก่อนส่งมอบ

### 1. สำรองข้อมูลก่อน

สำรองไฟล์ไปยัง Time Machine, External Drive หรือ Cloud ที่คุณใช้งาน ตรวจว่าข้อมูลสำคัญเปิดได้จากปลายทางแล้วจึงเริ่มล้างเครื่อง

### 2. ออกจากบัญชีและปิด Find My

เจ้าของต้องสามารถยืนยัน Apple Account ของตนเองและปิด Find My ได้ เพื่อไม่ให้เครื่องติด Activation Lock หลังล้างข้อมูล

### 3. ใช้ Erase All Content and Settings เมื่อเครื่องรองรับ

Mac ที่รองรับสามารถใช้เมนู **System Settings > General > Transfer or Reset > Erase All Content and Settings** โดยสำรองข้อมูลก่อนทุกครั้ง ฟังก์ชันนี้ขึ้นอยู่กับรุ่นชิปและเวอร์ชัน macOS

หากเมนูนี้ไม่มี ไม่ควรสุ่มลบพาร์ทิชันเองโดยไม่เข้าใจขั้นตอน สามารถสอบถามวิธีเตรียมเครื่องก่อนนัด หรือใช้คู่มืออย่างเป็นทางการของ Apple

### 4. หยุดที่หน้าตั้งค่าเริ่มต้น

หลังล้างเครื่องและยืนยันว่า Activation Lock ถูกปลดแล้ว ควรหยุดที่หน้าต้อนรับ ไม่ต้องลงชื่อเข้า Apple Account ใหม่

### 5. ทำความสะอาดและรวบรวมอุปกรณ์

ใช้ผ้านุ่มแห้งหรือหมาดเล็กน้อยเช็ดภายนอก ไม่ฉีดน้ำยาลงในพอร์ตโดยตรง เตรียมสายไฟ กล่อง และเอกสารที่ต้องการส่งมอบ

## ขั้นตอนขาย Mac mini กับอำพล เทรดดิ้ง

### 1. ส่งข้อมูลประเมิน

ส่ง About This Mac, Storage, รูปเครื่องทุกด้าน สายไฟ กล่อง ตำหนิ ประวัติซ่อม และจังหวัดที่สินค้าอยู่

### 2. รับราคาเบื้องต้น

ทีมงานตรวจรุ่นและข้อมูล หากมีเฉพาะคำว่า “Mac mini M4” อาจต้องขอ Memory, SSD และรุ่นย่อยเพิ่มก่อนประเมิน

### 3. ตกลงวิธีตรวจและส่งมอบ

หน้าร้านหลักอยู่จังหวัดอุบลราชธานี ลูกค้าสามารถสอบถามนำเครื่องเข้าตรวจ หรือตกลงนัดรับ/จัดส่งตามพื้นที่ ประเภทสินค้า มูลค่า และตารางงานที่ยืนยันล่วงหน้า

### 4. ตรวจเครื่องจริง

ตรวจ Serial, สเปก, พอร์ต, Wi-Fi, Bluetooth, สภาพ, อุปกรณ์ และสถานะบัญชี หากข้อมูลต่างจากที่แจ้ง ทีมงานจะอธิบายก่อนยืนยันราคาใหม่

### 5. ตัดสินใจขายและรับเงิน

เมื่อผู้ขายรับทราบผลตรวจและตกลงราคา จึงชำระเงินตามวิธีที่ตกลง หากราคาไม่ตรงใจสามารถไม่ขายได้

## Mac mini ต่างจาก MacBook และ iMac ตอนประเมินอย่างไร

Mac mini ไม่มีจอ แบตเตอรี่ คีย์บอร์ด และ Trackpad ในตัว จึงไม่ต้องประเมิน Battery Cycle หรือสภาพจอเหมือน MacBook แต่ต้องให้น้ำหนักกับพอร์ต การเชื่อมต่อ สายไฟ และการแสดงผลผ่านจอภายนอก

หากสินค้าที่ต้องการขายเป็นประเภทอื่น เลือกหน้าที่ตรงกว่า:

- [รับซื้อ MacBook](/บริการ/รับซื้อ-macbook) สำหรับ MacBook Air และ MacBook Pro
- [รับซื้อ iMac](/บริการ/รับซื้อ-imac) สำหรับเครื่อง All-in-One ที่มีจอในตัว
- [รับซื้อ Apple](/บริการ/รับซื้อ-apple) สำหรับภาพรวมสินค้า Apple หลายประเภท
- [รับซื้อจอคอม](/บริการ/รับซื้อจอคอม) หากมีจอมอนิเตอร์ขายพร้อมเครื่อง
- [Mac mini M4 มือสอง](/blog/mac-mini-m4-มือสอง) สำหรับบทความตรวจรุ่นและข้อมูลตลาดของ M4/M4 Pro

## คำถามที่พบบ่อยเกี่ยวกับ Mac mini มือสอง

### Mac mini ขายเฉพาะตัวเครื่องได้ไหม

ได้ ไม่จำเป็นต้องมีจอ คีย์บอร์ด หรือเมาส์ แต่ควรมีสายไฟและต้องทดสอบออกภาพกับจอได้

### ไม่มีใบเสร็จขายได้ไหม

ส่งประเมินได้ แต่ต้องตรวจ Serial, สถานะบัญชี และความเป็นเจ้าของตามความเหมาะสม หากมีใบเสร็จควรปิดข้อมูลส่วนบุคคลที่ไม่จำเป็นก่อนส่ง

### สเปก CTO ดูจากที่ไหน

ดูจาก About This Mac, System Information และ Storage กล่องเดิมช่วยตรวจเพิ่ม แต่ควรยืนยันกับข้อมูลในเครื่อง

### Mac mini M4 16GB/256GB กับ 24GB/512GB ราคาต่างกันไหม

ต่างกันได้เพราะ Memory และ SSD ไม่เท่ากัน แต่ส่วนต่างขึ้นกับตลาด ณ วันที่ประเมิน ไม่ได้คำนวณจากราคาสั่งเพิ่มเดิมแบบตรงตัว

### เครื่องเคยซ่อมบอร์ดรับซื้อไหม

รับพิจารณาตามงานซ่อมและอาการ ควรแจ้งว่าซ่อมอะไร ที่ใด และมีอาการหลังซ่อมหรือไม่ การปิดบังประวัติอาจทำให้ราคาหน้างานเปลี่ยนมาก

### ส่ง Mac mini จากต่างจังหวัดได้ไหม

ตกลงกับทีมงานก่อน ควรสำรองข้อมูล ปลด Find My แพ็กเครื่องแยกจากสายไฟ และใช้กล่องที่มีวัสดุกันกระแทกรอบด้าน
