## รับซื้อ Server Network NAS UPS และอุปกรณ์ห้อง IT ประเมินตามรุ่นและสภาพ

Server และอุปกรณ์ Network ไม่ควรประเมินจากรูปภายนอกหรือชื่อแบรนด์เพียงอย่างเดียว เพราะมูลค่าขึ้นกับ **Configuration, Part Number, Drive, RAM, Controller, Module, PSU, Rail, License/Subscription และอุปกรณ์ที่รวมอยู่จริง**

บริการนี้ครอบคลุม Server, NAS, Storage, UPS, Switch, Router, Firewall, Access Point และอุปกรณ์ห้อง IT ที่ต้องตรวจรายละเอียดเฉพาะด้าน

หากบริษัทมีคอมพนักงาน จอ Printer มือถือและสินค้าอื่นรวมด้วย ให้เริ่มจาก [รับซื้อสินค้าไอทีบริษัท](/บริการ/รับซื้อสินค้าไอทีบริษัท)

## Server

ข้อมูลสำคัญ:
- Brand/Model
- Service Tag / Serial / Part Number
- Form factor
- CPU และจำนวน Socket
- RAM
- RAID/HBA Controller
- Drive Bay
- HDD/SSD/NVMe ที่รวม
- Caddy/Tray
- PSU
- NIC/HBA
- Rail Kit
- Bezel
- สถานะ Boot
- Error/Alarm

หากถอด Drive ออกตามนโยบายข้อมูล ให้แจ้งว่า **No Drive** ตั้งแต่ต้น

ดู [รับซื้อ Server](/บริการ/รับซื้อ-server)

## NAS / Storage

ควรส่ง Model, Bay count, Drive ที่รวม, RAM, Expansion unit, PSU, Tray/Caddy, Network interface, Boot status, Error และ Account/management status ที่ต้องปลด

Storage ที่ไม่มี Drive ยังส่งประเมินได้ แต่ต้องประเมินจาก Chassis/Controller/Hardware ที่เหลือ

ดู [รับซื้อ NAS](/บริการ/รับซื้อ-nas)

## Network

### Switch
ส่งรุ่น Port count, PoE, Uplink, Module/SFP, PSU และสถานะ Boot

### Router
ส่ง Part Number, Module, PSU และอุปกรณ์ที่รวม

### Firewall
ควรแจ้งสถานะ Hardware และ License/Subscription เท่าที่ทราบ สิทธิ์บางประเภทอาจผูกกับบัญชีหรือสัญญาและไม่โอนพร้อมเครื่อง

### Access Point
ระบุรุ่น จำนวน Mount/Adapter/Injector และ Controller dependency ถ้ามี

ดู [รับซื้ออุปกรณ์ Network](/บริการ/รับซื้ออุปกรณ์-network)

## UPS

ข้อมูล:
- Model
- VA/kVA
- Input/Output
- Rack/Tower
- Battery age
- Battery pack
- Alarm
- Bypass
- Network card
- Rail
- จำนวน

UPS มีน้ำหนักและแบตเตอรี่ จึงต้องวางแผนการขนย้ายตามรุ่นและจำนวน ไม่ควรรับรองการนัดรับโดยไม่เห็นข้อมูลหน้างาน

ดู [รับซื้อ UPS](/บริการ/รับซื้อ-ups)

## Rack และอุปกรณ์ประกอบ

Rail Kit, Caddy/Tray, PDU, Cable arm, SFP, Transceiver และ Module อาจมีผลต่อความครบของรายการ ควรถ่ายแยกและระบุจำนวน

Rack Cabinet ขนาดใหญ่ต้องแจ้งขนาด สถานที่ ชั้น ลิฟต์ และเงื่อนไขการถอดออกก่อนวางแผนขนย้าย

## ข้อมูลใน Server / NAS

องค์กรควรจัดการข้อมูลตามนโยบายของตนก่อนส่งมอบ เช่น ถอด Drive เก็บไว้ ล้างข้อมูลตามมาตรฐานภายใน ทำ Inventory/Serial reconciliation ถอนระบบบริหาร/Account และตรวจ License/Subscription

หน้านี้ไม่อ้างบริการ Certified Data Destruction หรือ Compliance Certificate หากไม่มีการยืนยันบริการและกระบวนการจริงเป็นลายลักษณ์อักษร

## การประเมิน Infrastructure

- Configuration
- Completeness
- Working state
- License/Subscription
- Logistics

Software entitlement ไม่ควรถูกนับเป็นมูลค่า Hardware โดยอัตโนมัติ ต้องตรวจสิทธิ์การโอน

## ขั้นตอน

1. ส่ง Inventory List
2. ส่งรูป Label/Part Number
3. ระบุ Drive/Module ที่รวม
4. แจ้งสถานะข้อมูลและพื้นที่
5. ประเมินเบื้องต้น
6. วางแผนตรวจ/ส่งมอบ
7. ตรวจ Configuration จริง
8. ยืนยันราคา
