## ข้อมูลที่ควรส่งสำหรับคอมประกอบ

### CPU

ส่งชื่อรุ่นเต็ม เช่น Intel Core หรือ AMD Ryzen พร้อมเลขรุ่น ไม่ควรแจ้งเพียง i5, i7, Ryzen 5 หรือ Ryzen 7

หากมีการ Overclock หรือปรับค่าเฉพาะ ควรแจ้งว่าปัจจุบันใช้งานแบบใดและมีอาการไม่เสถียรหรือไม่

### Mainboard

ระบุยี่ห้อ รุ่น และ Chipset ถ้าทราบ เช่นดูจากสกรีนบนแผงวงจร กล่อง หรือโปรแกรม System Information

Mainboard มีผลต่อ Socket, RAM, Storage, Expansion และพอร์ต จึงไม่ควรละเลยแม้ผู้ขายจะให้ความสำคัญกับ CPU/GPU มากกว่า

### GPU

ถ้ามีการ์ดจอแยก ให้ส่งรุ่นเต็ม ยี่ห้อผู้ผลิต สภาพพัดลม และอาการขณะใช้งาน หากมีภาพลาย จอดับ Driver crash หรือพัดลมผิดปกติควรแจ้งตามจริง

### RAM

ระบุ DDR, ความจุรวม จำนวนแถว และความเร็วถ้าทราบ หากเป็นชุดคนละรุ่นหรือคนละความเร็วควรแจ้ง เพราะมีผลต่อการตรวจเสถียรภาพของเครื่อง

### SSD และ HDD

ระบุประเภทและความจุทุกลูก หากมี Drive ที่ไม่รวมขาย ให้บอกตั้งแต่ต้นเพื่อไม่ให้เกิดความเข้าใจผิดตอนตรวจ

### PSU

ระบุยี่ห้อ รุ่น กำลังวัตต์ และมาตรฐานถ้าทราบ แต่ไม่ควรประเมินคุณภาพจากตัวเลข Watt หรือ 80 Plus เพียงอย่างเดียว สภาพ อายุ การใช้งาน และความเหมาะสมกับ Hardware ต้องดูร่วมกัน

### Case

แจ้งรุ่นหรือขนาดโดยประมาณ พร้อมถ่ายรอยแตก ฝาข้าง อะไหล่ที่หาย พอร์ตหน้า USB/Audio และสภาพกระจกถ้ามี

### Cooling

ระบุ Air Cooler หรือ Liquid Cooling ถ้ามีชุดน้ำควรถ่าย Pump, Radiator, Tube และ Fan พร้อมแจ้งเสียงผิดปกติ รอยซึม หรืออายุการใช้งานที่ทราบ

### อุปกรณ์เสริม

Wi-Fi card, Capture card, RGB controller, Fan hub, Sound card หรือการ์ดเสริมอื่นควรแยกรายการให้ชัดว่ารวมขายหรือไม่

## วิธีถ่ายรูปคอมประกอบให้ประเมินง่าย

1. ถ่ายด้านหน้าเคสเต็มตัว
2. ถ่ายด้านหลังให้เห็น GPU output, Mainboard I/O และ PSU
3. ถ่ายภายในเคสจากมุมกว้าง
4. ถ่าย GPU ด้านข้างให้เห็นรุ่นหรือฉลากถ้าเข้าถึงได้โดยไม่ถอดการ์ด
5. ถ่าย Mainboard บริเวณที่มีชื่อรุ่น
6. ถ่าย PSU label หากมองเห็นได้โดยไม่แกะเครื่อง
7. ถ่าย Storage หรือกล่องเดิมหากมีหลายลูก
8. ถ่ายตำหนิใกล้ ๆ
9. ถ้าเครื่องเปิดได้ ถ่าย Task Manager, System Information หรือโปรแกรมที่แสดง Hardware จริง

ไม่จำเป็นต้องถอด GPU, RAM หรือ Cooler ออกจากเครื่องเพื่อถ่ายรูป หากไม่ชำนาญ การถอดอุปกรณ์เพื่อขอราคาอาจเพิ่มความเสี่ยงต่อ Hardware โดยไม่จำเป็น

## ปัจจัยที่มีผลต่อราคาคอมประกอบ

### มูลค่าของชิ้นส่วนหลัก

คอมประกอบหนึ่งเครื่องอาจมีมูลค่ากระจายอยู่ที่ CPU, GPU, Mainboard, RAM, Storage และ PSU จึงต้องดูทั้งชุด ไม่ใช่ยึดเพียง GPU หรือ CPU ชิ้นเดียว

### ความสมดุลของ Platform

เครื่องที่มี Hardware ทำงานร่วมกันได้เหมาะสมและยังใช้งานต่อได้ง่ายอาจมีความน่าสนใจกว่าเครื่องที่ผสมชิ้นส่วนหลายยุคหรือมีข้อจำกัดในการอัปเกรด แต่การประเมินต้องดูตลาดจริงในช่วงนั้น

### สภาพ GPU

สำหรับเครื่องเล่นเกม GPU มีน้ำหนักสูง แต่ต้องดูการทำงานจริง พอร์ต Fan ความร้อน เสียง และประวัติซ่อม ไม่ใช่ดูชื่อรุ่นอย่างเดียว

### RAM และ Storage

ความจุและชนิดมีผลต่อการใช้งานต่อ แต่ต้องดูสุขภาพและความต้องการจริง ไม่ควรสรุปว่ามาตรฐานใหม่กว่าจะมีมูลค่าสูงกว่าทุกกรณี

### PSU

PSU ที่มีข้อมูลรุ่นชัด สภาพดี และเหมาะกับ Hardware ช่วยลดความเสี่ยงในการใช้งานต่อ แต่ PSU เก่าหรือไม่ทราบรุ่นอาจต้องประเมินอย่างระมัดระวัง

### Cooling

ชุดน้ำหรือ Cooler ราคาแพงไม่ได้เพิ่มมูลค่าเต็มตามราคาซื้อเดิม ต้องดูอายุ สภาพ ความเข้ากันได้ และความเสี่ยงจากการใช้งานต่อ

### Case และงานประกอบ

Case สวยหรือมีอุปกรณ์ตกแต่งช่วยเรื่องความครบของชุด แต่ Hardware หลักและสภาพการทำงานยังสำคัญกว่า RGB หรือรูปลักษณ์เพียงอย่างเดียว

### ประวัติซ่อมและอาการ

เครื่องเคยซ่อม GPU, Mainboard, PSU หรือมีอาการ intermittent ควรแจ้ง เพราะมีผลต่อความเสี่ยงและการตรวจจริง

## คอมไม่มี GPU แยกยังขายได้ไหม

ได้ในหลายกรณี โดยเฉพาะเครื่องที่ใช้ CPU ซึ่งมีกราฟิกในตัว หรือเครื่องที่ขายเป็น Platform สำหรับนำไปติดตั้ง GPU ภายหลัง

สิ่งที่ต้องดูแทน GPU ได้แก่

- CPU
- Mainboard
- RAM
- SSD/HDD
- PSU
- Case
- Cooling
- สภาพการเปิดใช้งาน

หากถอด GPU ออกไปขายแยก ควรแจ้งว่าราคาเบื้องต้นที่ต้องการให้ประเมินคือ “เครื่องไม่รวม GPU” เพื่อไม่ให้เข้าใจผิดกับรูปเก่าที่อาจยังเห็นการ์ดอยู่ในเคส

---

## คอมประกอบมีชิ้นส่วนเสียยังส่งประเมินได้ไหม

### PSU มีปัญหา

หากสงสัยว่า PSU เสีย ควรหยุดใช้งานหากมีเสียง กลิ่นไหม้ หรืออาการไฟผิดปกติ ไม่ควรเปิดซ้ำหลายครั้งเพื่อทดสอบเอง

### Mainboard บูตไม่ผ่าน

แจ้งว่าไฟเข้าไหม มี Debug LED หรือเสียง Beep อย่างไร เคยเปลี่ยน RAM/GPU ทดสอบหรือไม่ ไม่จำเป็นต้องถอดอุปกรณ์หลายชิ้นหากไม่ชำนาญ

### GPU ภาพลายหรือ Driver crash

ส่งรูป/วิดีโออาการและรุ่น GPU พร้อมแจ้งว่าปัญหาเกิดตลอดหรือเฉพาะเมื่อเล่นเกม

### RAM มีปัญหา

แจ้งว่ามีกี่แถวและแถวใดสงสัยมีอาการ หากถอด RAM บางแถวออกแล้วใช้งานได้ควรบอก

### ชุดน้ำผิดปกติ

หากมีรอยรั่ว ซึม หรือ Pump มีเสียงผิดปกติ ควรหยุดใช้งานและไม่เคลื่อนย้ายเครื่องโดยไม่ระวัง

การส่งข้อมูลเพื่อประเมินไม่ได้หมายความว่าร้านจะรับซื้อเครื่องที่เสียทุกกรณี ต้องดูความคุ้มค่าและความปลอดภัยของเครื่องจริง

## ขายทั้งเครื่องหรือแยกชิ้นส่วน

ผู้ขายคอมประกอบมักถามว่าควรขายทั้งชุดหรือแยกขาย Hardware การตัดสินใจควรดูเป้าหมายของผู้ขายและสภาพเครื่อง

### ขายทั้งชุด

เหมาะกับผู้ที่ต้องการลดขั้นตอน ไม่ต้องถอด Hardware ไม่ต้องหากล่องแต่ละชิ้น และไม่ต้องรับความเสี่ยงจากการทดสอบและจัดส่งหลายรายการ

### แยกขาย

อาจเหมาะเมื่อมีบางชิ้นไม่รวมขาย หรือเครื่องไม่ครบชุด แต่การแยกขายต้องใช้เวลาและต้องทดสอบแต่ละชิ้น

อย่าตัดสินจากสูตรว่า “แยกขายได้เงินมากกว่าเสมอ” หรือ “ขายทั้งชุดดีที่สุดเสมอ” เพราะตลาดของแต่ละชิ้นเปลี่ยนได้ และบางชิ้นมีค่าขนส่งหรือความเสี่ยงสูง

## Gaming PC กับคอมประกอบต่างกันอย่างไร

Gaming PC จำนวนมากเป็นคอมประกอบ แต่คอมประกอบไม่ได้เป็น Gaming PC ทุกเครื่อง

**คอมประกอบ** เน้นวิธีประเมินจากชิ้นส่วนและ Configuration

**Gaming PC** เน้นบริบทการเล่นเกม GPU การจ่ายไฟ ความร้อน Cooling และอาการที่เกิดเมื่อโหลดหนัก

หากเครื่องมี GPU แยกและถูกใช้งานเล่นเกมเป็นหลัก หน้า [รับซื้อ Gaming PC](/บริการ/รับซื้อ-gaming-pc) จะให้รายละเอียดเฉพาะทางมากกว่า แต่หากโจทย์คือการขาย Custom PC ที่ประกอบจากหลายชิ้นหรือถอด Hardware ออกบางส่วน หน้านี้จะตรงกว่า

## ขั้นตอนประเมินคอมประกอบ

1. **ส่งรูปและรายการสเปก**  
   เริ่มจาก CPU, Mainboard, GPU, RAM, Storage, PSU, Case และรูปภายในเครื่อง

2. **ตรวจข้อมูล**  
   ทีมงานแยกรุ่น Hardware และอาจขอรายละเอียดเพิ่มเฉพาะชิ้นที่ยังระบุไม่ได้

3. **แจ้งราคาเบื้องต้น**  
   อิงจากชิ้นส่วน สภาพ และตลาดในช่วงที่ประเมิน

4. **ตกลงวิธีตรวจเครื่อง**  
   หากราคาเบื้องต้นตรงใจ จึงสรุปการนำเข้าหน้าร้าน นัดหมาย หรือจัดส่ง

5. **ตรวจ Hardware จริง**  
   ตรวจการเปิดใช้งาน สเปกตรงกับข้อมูลหรือไม่ GPU, RAM, Storage, พอร์ต, PSU และ Cooling

6. **ยืนยันราคาและชำระเงิน**  
   หลังตรวจและตกลงราคาสุดท้ายแล้วจึงดำเนินการชำระตามวิธีที่ตกลง
