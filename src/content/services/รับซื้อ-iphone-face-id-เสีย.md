| อาการที่ผู้ขายแจ้ง | สิ่งที่ทดสอบได้เบื้องต้น | สิ่งที่ยังยืนยันไม่ได้ |

## วิธีแยกอาการด้วยตัวเองโดยไม่แกะเครื่อง

1. ตรวจว่ามีฟิล์ม เคส หรือสิ่งสกปรกบังบริเวณกล้อง TrueDepth หรือไม่ แล้วทำความสะอาดอย่างอ่อนโยนตามคำแนะนำผู้ผลิต
2. ดูข้อความใน **การตั้งค่า → Face ID และรหัส** โดยไม่ต้องถ่ายหรือส่งรหัสผ่านหน้าจอล็อก
3. เปิดแอปกล้องทดสอบกล้องหน้าและกล้องหลัง เพื่อแยกอาการที่สังเกตได้
4. หากเครื่องเพิ่งเปลี่ยนจอ กล้องหรือเคยซ่อม ให้ดูหน้า **การตั้งค่า → ทั่วไป → เกี่ยวกับ → Parts and Service History** เฉพาะรุ่น/เวอร์ชันที่รองรับ
5. หากเคยตกหนัก โดนน้ำ หรือระบบแสดงคำเตือนความเสียหาย ให้แจ้งก่อน ไม่ควรแกะกล้องหรือถอดสายแพเพื่อทดสอบเอง

หากเมนูแสดงข้อความเตือน ให้ถ่ายภาพข้อความเท่านั้นโดย **ไม่เปิดเผย Apple Account, รหัสปลดล็อก, รหัส OTP หรือข้อมูลใบหน้า** ดูคำแนะนำจาก [Apple: Face ID ไม่ทำงาน](https://support.apple.com/th-th/118243) ประกอบได้

## ทำไม Face ID เสียแล้วราคาประเมินต่างจากเครื่องปกติ

การประเมินเริ่มจาก **มูลค่ารุ่นและความจุเดียวกันในสภาพที่ทดสอบผ่าน** แล้วดูผลกระทบต่อการใช้งาน ความเสี่ยงและแนวทางซ่อมที่เป็นไปได้จากรุ่นนั้นจริง

- **ปัญหาเฉพาะ Face ID หรือมีอาการร่วม:** จอแตก แบตเสื่อม กล้องเสีย พอร์ตมีปัญหา และประวัติโดนน้ำเพิ่มความเสี่ยง
- **ประวัติซ่อม/เปลี่ยนอะไหล่:** ตรวจการทำงานจริงและประวัติอะไหล่ที่ระบบแสดงได้ ไม่ใช้คำว่าเคยซ่อมแล้วไม่มีมูลค่าเสมอไป
- **ผลตรวจที่ยืนยันได้:** เครื่องตรวจผ่านฟังก์ชันอื่นต่างจากเครื่องเปิดไม่ติดหรือไม่สามารถตรวจได้
- **ความพร้อมขายต่อ:** ความต้องการตลาดของรุ่นนั้นและต้นทุนตรวจเพิ่มมีผลต่อการเสนอราคา

**ไม่มีสูตรหักค่า Face ID เป็นเงินตายตัว** และไม่ได้หมายความว่าต้องซ่อมด้วยวิธีเดียวกันทุกโมเดล บางเครื่องอาจมีหลายความเสียหายร่วมกันจนไม่คุ้มรับซื้อ
