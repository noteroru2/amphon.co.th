## รับซื้อแรมมือสอง (RAM) คอมพิวเตอร์และโน๊ตบุ๊ค DDR3 DDR4 DDR5 ประเมินตามสภาพจริง

**อำพล เทรดดิ้งรับซื้อแรมมือสอง (RAM)** ทั้ง DDR3, DDR4 และ DDR5 สำหรับคอมพิวเตอร์ตั้งโต๊ะ โน๊ตบุ๊ค และ Server บางประเภท หากมีแรมที่ถอดออกหลังอัปเกรดเครื่อง เปลี่ยนคอมใหม่ ปิดร้านเกม หรือเคลียร์อุปกรณ์ของบริษัท สามารถส่งรูปสติกเกอร์ รุ่น ความจุ บัส จำนวนแผง และสภาพเพื่อประเมินเบื้องต้นได้

## RAM แบบไหนที่รับพิจารณา

### RAM คอมพิวเตอร์ตั้งโต๊ะหรือ Desktop DIMM

รับพิจารณา RAM สำหรับคอมประกอบ คอมสำนักงาน Gaming PC และ Workstation ทั้งแบบแผงเปลือยและแบบมีฮีตซิงก์ เช่น

- DDR3, DDR4 และ DDR5
- ความจุ 4GB, 8GB, 16GB, 32GB หรือมากกว่าตามรุ่น
- แผงเดี่ยวและชุดคู่ เช่น 8GB x 2 หรือ 16GB x 2
- RAM Gaming ที่มีฮีตซิงก์หรือไฟ RGB
- Value RAM และ OEM RAM ที่ติดมากับเครื่องแบรนด์
- รุ่นที่รองรับ Intel XMP หรือ AMD EXPO ตามข้อมูลบนผลิตภัณฑ์

RAM ที่ดูคล้ายกันอาจมีรายละเอียดต่างกัน เช่น บัส ค่า CL แรงดัน รหัสชิป และการจัดชุดจากโรงงาน จึงควรถ่ายรูปให้เห็นสติกเกอร์เต็มแผงแทนการแจ้งเพียงว่า “DDR4 16GB”

### RAM โน๊ตบุ๊คและ Mini PC หรือ SO-DIMM

รับพิจารณาแรมแผงสั้นสำหรับโน๊ตบุ๊ค Mini PC และคอม All-in-One บางรุ่น โดยเฉพาะ DDR4 และ DDR5 ที่มีข้อมูลรุ่นชัดเจน

กรณีถอดแรมเดิมออกหลังอัปเกรด ควรแจ้งด้วยว่าแผงนั้นมากับเครื่องรุ่นใดและทดสอบล่าสุดเมื่อใด หากขายพร้อมโน๊ตบุ๊คทั้งเครื่อง อาจส่งประเมินผ่านหน้า [รับซื้อโน๊ตบุ๊ค](/บริการ/รับซื้อโน๊ตบุ๊ค) เพื่อพิจารณามูลค่ารวมของเครื่องได้ตรงกว่า

### RAM Server และ Workstation

RAM Server ต้องแยกให้ชัดว่าเป็น UDIMM, ECC UDIMM, RDIMM หรือ LRDIMM เพราะไม่สามารถใช้แทนกันได้ทุกระบบ ข้อมูลสำคัญมักอยู่บนสติกเกอร์ เช่น Part Number, Rank, ความจุ, ความเร็ว และผู้ผลิต

หากเป็นล็อตจาก Server หลายเครื่อง ควรส่ง Inventory List หรือภาพแยกตามรหัสรุ่น ไม่ควรรวมแผงต่างชนิดแล้วแจ้งเพียงน้ำหนัก เพราะแรมที่ทดสอบผ่านและยังมีตลาดใช้งานอาจมีมูลค่าต่างจากแผงเสียหรือแผงรุ่นเก่ามาก

## DDR3 DDR4 และ DDR5 ประเมินต่างกันอย่างไร

### DDR3

DDR3 ยังพบในคอมรุ่นเก่า โน๊ตบุ๊คเก่า เครื่อง POS และคอมสำนักงานที่ใช้งานเฉพาะทาง บางรุ่นยังขายต่อได้ โดยเฉพาะแผงที่มีความจุเหมาะสม สภาพดี และมีจำนวนเป็นล็อต แต่แผงความจุต่ำหรือรุ่นที่ตลาดใช้งานน้อยอาจมีมูลค่าจำกัด

หากมี DDR3 หลายแผง ควรจัดกลุ่มตามความจุ บัส และชนิด Desktop/Notebook ก่อนถ่ายรูป จะช่วยให้ตรวจสอบได้เร็วกว่าเทรวมกันในภาพเดียว

### DDR4

DDR4 เป็นกลุ่มที่ยังพบมากทั้งในคอมประกอบ โน๊ตบุ๊ค เครื่องสำนักงาน และ Server หลายรุ่น ความต้องการไม่ได้เท่ากันทุกแผง แรม 8GB ทั่วไป แรมชุดคู่ 16GB x 2 แรม Gaming บัสสูง และ ECC RDIMM อาจมีตลาดคนละกลุ่มและประเมินจากเกณฑ์ต่างกัน

ข้อมูลที่ควรส่งคือความจุต่อแผง บัส ค่า CL ถ้ามี รุ่นเต็ม จำนวนแผง และระบุว่าเป็นชุดเดิมจากกล่องเดียวกันหรือเป็นแผงที่นำมาจับคู่ภายหลัง

### DDR5

DDR5 ใช้กับคอมและโน๊ตบุ๊ครุ่นใหม่มากขึ้น แต่คำว่า DDR5 อย่างเดียวไม่เพียงพอต่อการประเมิน เพราะยังต้องดูความจุ บัส Timing โปรไฟล์ XMP/EXPO รุ่นฮีตซิงก์ และความเข้ากันได้ของชุด

หากเป็นชุดคู่ ควรถ่ายให้เห็นรหัสทั้งสองแผงและกล่องเดิม ถ้าเป็น RAM ที่ถอดจากโน๊ตบุ๊ค ควรถ่ายสติกเกอร์เต็มแผงเพื่อแยก SO-DIMM จาก Desktop DIMM ให้ถูกต้อง

> รุ่นใหม่กว่าไม่ได้แปลว่าราคาสูงกว่าเสมอ ราคาขึ้นอยู่กับสเปกจริง สภาพ จำนวน ประกัน และราคาตลาดของรุ่นนั้นในวันประเมิน

## ปัจจัยที่ใช้ประเมินราคา RAM มือสอง

### 1. ชนิดและ Generation

ต้องรู้ก่อนว่าเป็น DDR3, DDR4 หรือ DDR5 และเป็น RAM สำหรับ Desktop, Notebook หรือ Server การใช้ชนิดผิดกลุ่มอาจทำให้ประเมินคลาดเคลื่อนมาก

### 2. ความจุต่อแผงและจำนวนแผง

ความจุ 8GB, 16GB หรือ 32GB มีตลาดต่างกัน รวมถึงจำนวนแผงและรูปแบบชุด เช่น 16GB แผงเดียวกับ 8GB x 2 ไม่ได้มีมูลค่าเท่ากันโดยอัตโนมัติ

### 3. บัส ค่า Timing และโปรไฟล์

บัสและค่า CL ช่วยระบุรุ่นย่อย แต่ไม่ควรพิจารณาแยกจากแพลตฟอร์ม ความจุ และตลาดของสินค้านั้น รุ่นบัสสูงที่เป็นสเปกเฉพาะอาจขายได้ดีในบางช่วง แต่บางรุ่นมีผู้ใช้จำกัด

### 4. เป็นชุด Kit เดิมหรือแผงแยก

ชุดคู่ที่มาจากกล่องเดียวกันและมีรหัสตรงกันมักตรวจสอบง่ายกว่าแผงที่นำมาจับคู่ภายหลัง ผู้ขายควรแจ้งตามจริงว่าเป็น Kit เดิมหรือไม่

### 5. สภาพภายนอก

ทีมงานจะดูขาทองเหลือง สติกเกอร์ ฮีตซิงก์ รอยงอ รอยบิ่น คราบสนิม คราบน้ำ รอยไหม้ และความผิดปกติของชิ้นส่วนบนแผง ไม่ควรขัดหน้าสัมผัสด้วยวัสดุหยาบหรือใช้น้ำยาที่ไม่เหมาะสมก่อนส่งตรวจ

### 6. ผลทดสอบและความเสถียร

RAM ที่เปิดติดไม่ได้แปลว่าทดสอบผ่านทั้งหมด ควรแจ้งว่าเคยใช้งานปกติหรือมีอาการจอฟ้า รีสตาร์ท เครื่องไม่บูต หรือพบ Error จากโปรแกรมทดสอบ หากไม่เคยทดสอบ ให้แจ้งว่า “ไม่ทราบผล” แทนการรับรองว่าใช้งานปกติ

### 7. กล่อง ประกัน และสติกเกอร์

กล่องเดิม ใบเสร็จ และหลักฐานประกันอาจช่วยเพิ่มความน่าสนใจ แต่เงื่อนไขประกันแตกต่างกันตามแบรนด์ ตัวแทนจำหน่าย และสภาพสติกเกอร์ จึงไม่ควรสรุปว่ามีคำว่า Lifetime แล้วประกันยังใช้ได้ทุกกรณี

### 8. ราคาตลาดและต้นทุนตรวจรับ

ราคาสินค้ามือหนึ่ง โปรโมชั่น และความต้องการ RAM มือสองเปลี่ยนได้ ราคาเบื้องต้นจึงอ้างอิงวันที่ส่งประเมิน ไม่ใช่ราคาคงที่ตลอดอายุหน้าเว็บ

## แรมสภาพแบบไหนขายได้

### ใช้งานปกติและทดสอบผ่าน

เป็นกลุ่มที่ประเมินได้ง่ายที่สุด ควรส่งผลทดสอบหรือแจ้งเครื่องที่เคยใช้งาน พร้อมภาพสติกเกอร์และสภาพจริง

### ไม่มีกล่อง

ส่งประเมินได้ กล่องไม่ใช่เงื่อนไขบังคับ แต่ควรแพ็กแผงในถุงป้องกันไฟฟ้าสถิตหรือวัสดุที่เหมาะสม ไม่ควรวางแรมเปลือยรวมกับโลหะหรืออุปกรณ์แข็ง

### สติกเกอร์ลอกหรือข้อมูลอ่านไม่ครบ

ยังพิจารณาได้บางกรณี แต่การระบุรุ่นและตรวจประกันจะยากขึ้น ควรถ่ายทั้งสองด้านและส่งข้อมูลจาก BIOS, CPU-Z หรือโปรแกรมอ่าน SPD เพิ่มถ้าเครื่องยังเปิดได้

### มีคราบ รอยสนิม หรือฮีตซิงก์บุบ

ควรถ่ายตำหนิให้เห็นชัด ราคาจะขึ้นอยู่กับว่ากระทบเฉพาะความสวยงามหรือมีความเสี่ยงต่อวงจรและการใช้งาน ไม่ควรปิดบังคราบน้ำหรือรอยซ่อม

### เปิดไม่ติด จอฟ้า หรือไม่ทราบผลทดสอบ

ส่งอาการมาประเมินได้ แต่ต้องแยกจากสินค้าที่รับรองว่าทดสอบผ่าน หากเป็นแผงเสียหรือมีจำนวนมาก อาจประเมินในกลุ่มซากอะไหล่หรืออิเล็กทรอนิกส์เพื่อรีไซเคิลตามความเหมาะสม

## ส่งรูปอะไรบ้างเพื่อให้ประเมินได้ตรงรุ่น

1. **ภาพด้านที่มีสติกเกอร์รุ่น** ให้เห็น Part Number ความจุ บัส และข้อมูลสำคัญครบ
2. **ภาพอีกด้านของแผง** เพื่อดูสภาพวงจรและฮีตซิงก์
3. **ภาพรวมทุกแผง** ให้เห็นจำนวนจริง
4. **ภาพรหัสของแต่ละแผง** หากขายเป็นคู่หรือหลายชุด
5. **ภาพกล่องและสติกเกอร์ประกัน** ถ้ามี
6. **ผลทดสอบหรือภาพหน้าจอสเปก** เช่น BIOS หรือโปรแกรมอ่านข้อมูล RAM
7. **คำอธิบายอาการ** หากมีจอฟ้า เปิดไม่ติด หรือเคยซ่อม
8. **จังหวัดและวิธีส่งมอบที่สะดวก** เพื่อพิจารณารูปแบบนัดรับหรือจัดส่ง

```text
ตำหนิ: ฮีตซิงก์มีรอยเล็กน้อย
พื้นที่: จังหวัด...
```

## คำถามที่พบบ่อยเกี่ยวกับการขาย RAM มือสอง

### ขาย RAM แผงเดียวได้ไหม

ได้ ไม่จำเป็นต้องขายเป็นคู่ แต่ควรส่งรุ่นเต็ม ความจุ บัส และผลทดสอบของแผงนั้นให้ครบ

### RAM OEM หรือแรมเขียวรับซื้อไหม

รับพิจารณาตามรุ่นและตลาด แรม OEM ไม่ได้ถูกปฏิเสธเพียงเพราะไม่มีฮีตซิงก์ แต่ราคาขึ้นอยู่กับสเปก ความจุ และความต้องการจริง

### RAM คนละยี่ห้อแต่สเปกเท่ากันขายเป็นคู่ได้ไหม

สามารถส่งประเมินพร้อมกันได้ แต่ไม่ควรเรียกว่า Kit เดิมหากไม่ได้มาจากชุดเดียวกัน ทีมงานจะประเมินตามข้อมูลของแต่ละแผง

### ไม่มีโปรแกรมทดสอบ RAM ทำอย่างไร

แจ้งว่าไม่ทราบผลทดสอบและบอกว่าเครื่องล่าสุดเปิดติดหรือมีอาการใด ทีมงานจะพิจารณาเงื่อนไขตรวจรับตามข้อมูลที่มี

### RAM Server ต้องส่งอะไรเพิ่ม

ควรส่ง Part Number, ความจุ, Rank, ชนิด ECC/RDIMM/LRDIMM ถ้าทราบ จำนวนแผง และรุ่น Server ที่ถอดออกมา

### ส่ง RAM ทางขนส่งได้ไหม

ตกลงวิธีจัดส่งกับทีมงานก่อน ควรใช้ถุงป้องกันไฟฟ้าสถิต ห่อกันกระแทก และใส่กล่องแข็งแรง ไม่ควรใช้เทปติดบนสติกเกอร์หรือแผงโดยตรง
